# 구멍 있는 곡면 클램프 해석

편집 가능한 FreeCAD 원통 두 개와 차집합으로 만든 단일 고체 예제입니다.
FreeCAD FEM·Gmsh·CalculiX로 메시와 정적 변위를 구하고 ParaView에서 결과를 봅니다.
조립 운동이나 접촉 기능을 먼저 설정할 필요는 없습니다. 클램프 사이의 접촉이나
조립체 하중 전달을 나타내는 모델은 아닙니다.

## 모델 만들기

[Windows 설치 안내](../../docs/INSTALL_KO.md#cad와-후처리-열기)에 따라
FreeCAD 1.1.4, Gmsh, CalculiX와 ParaView를 연결합니다. 예제는 이 무료 Windows
프로그램을 사용하며 WSL이나 유료 서비스가 필요하지 않습니다.

1. FreeCAD의 **매크로 → 매크로…**에서 이 폴더의
   `CreateSolidClamp.FCMacro`를 열어 실행합니다. `create_clamp.py`도 같은 폴더에 둡니다.
2. **새 빈 저장 폴더**를 선택합니다. 매크로는 형상·재료·조건을 만들고 Gmsh로 메시를
   생성한 뒤 `curved-clamp.caepre`와 계산용 입력을 저장합니다. 솔버는 실행하지 않습니다.
3. 생성이 끝나면 모델 트리의 **구멍 있는 곡면 클램프**를 펼쳐 **클램프 외경**과
   **관통 구멍**을 선택합니다. 기본 원통의 반지름과 높이를 FreeCAD 속성에서 편집할 수 있습니다.

기본 치수는 외경 16 mm, 구멍 지름 5 mm, 높이 14 mm입니다. 재료는 선형 등방성
탄성체로 E = 210000 MPa, ν = 0.3입니다. 아랫면을 고정하고 윗면 법선의 반대 방향으로
힘을 설정합니다. C3D10 메시의 최소·최대 크기는 1.5·2.5 mm입니다.
생성에 실패하면 오류와 가능한 작업 사본이 저장 폴더에 남습니다. 오류를 확인하고 새 폴더에서
다시 시작하세요. 실패한 입력으로 계산을 계속하지 않습니다.

## 편집하고 계산하기

처음 매크로를 실행한 FreeCAD 문서를 닫은 뒤 **전처리**에서 저장한
`curved-clamp.caepre`를 여세요. 저장소에서 시작할 때는 다음 기존 실행기를 쓸 수 있습니다.

```powershell
.\scripts\start_cae_pre.ps1 -Source "C:\cae\clamp\curved-clamp.caepre"
```

경로는 실제 저장 위치로 바꿉니다. FreeCAD가 자동 선택되지 않으면 설치 안내에 따라
`-FreeCADExe`로 설치된 실행 파일을 지정하세요.

1. **해석 설정**의 **메시**, **재료**, **영역과 조건**에서 대상과 값을 확인하고 변경을 적용합니다.
   형상을 바꾸면 메시를 다시 생성하고 실제 고정면·하중면을 확인하여 다시 지정하세요.
   예전 메시나 면 조건이 새 형상에 그대로 맞는 것으로 간주하지 않습니다.
2. 모델 트리에서 **SolverCcx**를 선택하고 아래 **계산 → 기본 해석 → FreeCAD에서 계산…**을
   누릅니다. FreeCAD의 기존 솔버 작업창에서 **Write .inp File → Run CalculiX**를 순서대로
   실행합니다. 우측 작업 패널이 접혀 있으면 **작업** 패널을 펼치세요.
   솔버 실행 파일을 찾지 못하면 FreeCAD FEM의 CalculiX 환경설정에서 설치 경로를 확인합니다.
3. 계산이 끝나고 결과를 읽으면 트리에서 **Results** 결과 객체를 선택합니다.
   **선택 결과를 ParaView에서 열기**를 누릅니다. 설치된 ParaView를 찾지 못하면
   `paraview.exe`를 직접 고릅니다. 같은 CAE 연구 작업공간에 연결된 후처리가 열립니다.
   FreeCAD 솔버 계산 자체에는 서비스나 MCP가 필요하지 않으며, 후처리의 프로젝트 저장과
   연구 기능에는 현재 로컬 서비스 연결을 그대로 사용합니다. **프로젝트 저장**으로 편집한 모델을 보관합니다.

입력과 작업 이력을 함께 보존하려면 **계산 관리** 탭을 사용합니다.
해석을 선택한 뒤 **입력 파일 생성…**으로 입력을 확인하거나 **입력 보존 후 계산**을 누릅니다.
입력 생성만으로 계산이 시작되지는 않습니다. **계산 목록…**에서 같은 작업의 완료 상태와 오류를
확인하고 **후처리에서 열기**로 이어갑니다. 이 관리 경로에는 기존 로컬 서비스 연결이 필요합니다.

새로 연결한 메시에는 원 형상을 함께 보존하며, 같은 형상·배치·노드·요소 순서를 유지한
이 클램프의 새 작업 사본을 저장하고 새 FreeCAD에서 메시를 다시 읽는 것까지 확인했습니다.
메시 생성과 계산은 반복하지 않았습니다. 이는 예전 파일의 메시 연결을 자동 승인한 결과는 아닙니다.
원 형상 근거가 없는 예전 저장 파일은 `Source geometry changed`로 막힐 수 있습니다.
이 경우 검사를 건너뛰거나 이전 계산을 새 입력의 결과로 사용하지 마세요. CAD와 이전 결과를
보존하고 원 형상과 메시의 대응을 확인한 뒤 새 메시 연결을 준비해야 합니다.

## 결과 보고 저장하기

기본 경로는 FreeCAD가 선택한 결과만 새 VTU로 내보내 CAE 후처리가 연결된 ParaView를 엽니다.
기존 로컬 서비스와 같은 작업공간을 사용하며 후처리의 측정·비교와 연구 연결 기능을 이어 쓸 수 있습니다.
색상 항목에서 `Displacement Magnitude` 또는 `Displacement`의
성분을 선택합니다. FreeCAD 1.1.4의 공식 내보내기는 변위를 **m**, 응력을 **Pa**로 기록합니다.
이 예제에서 최대 변위 약 3.60839 × 10⁻⁸ m는 0.0000360839 mm와 같습니다.
메시 좌표는 mm이므로 변형 형상 확대를 할 때는 좌표와 변위 단위부터 맞춰야 합니다.
원값은 자동 환산하거나 덮어쓰지 않습니다.

**Macros → CAE Save project**로 후처리 프로젝트를 저장합니다. 다음에는 **후처리**에서
저장 폴더의 `project.json`을 열어 이어갑니다. 원 VTU도 보관하세요. 새 VTU 위치는 전처리의
안내에 표시됩니다. 원자료를 옮겼다면 **원파일 다시 연결…**을 사용합니다.
FreeCAD와 후처리 프로젝트는 각각 저장하고 닫습니다. 이 경로가 원 계산 작업과의 관계를
자동 등록하는 것은 아닙니다.

일반 VTU 열기는 단위를 자동 선언하지 않습니다. 비교할 때 **물리량 확인…**에서 좌표 mm,
변위 m, 응력 Pa 등 실제 선택 배열의 단위와 물리량을 명시하세요. 이름만 보고 mm로 간주하거나
숫자를 자동 환산하지 않습니다. 후처리가 열리지 않으면 로컬 서비스 연결과 설치 경로를 확인하고,
내보낸 VTU 옆 `launch.stderr.log`와 `launch.stdout.log`에서 오류를 확인하세요. 원 결과는 남아 있습니다.

**계산 관리**를 통해 연 후처리에서는 `U_magnitude_mm` 또는 `UX_mm`, `UY_mm`, `UZ_mm`를
선택하며 이 배열의 단위는 mm입니다. 이 경로도 같은 후처리 프로젝트 저장과 연구 기능을 사용합니다.
[화면별 안내](../../docs/SCREEN_GUIDE_KO.md#후처리에서-결과-보고-비교하기)에
저장과 재연결 순서가 있습니다.

공식 동작 참고: [FreeCAD 1.1.4 결과 내보내기의 단위 변환](https://github.com/FreeCAD/FreeCAD/blob/1.1.4/src/Mod/Fem/App/FemVTKTools.cpp#L854).

## 설정 하중과 실제 입력

힘 설정값은 **100 N**입니다. 확인한 메시의 원 native 입력에 분배된 절점 하중 합은
**[0, 0, -99.7336210423518] N**이며, 설정값 크기와 약 **0.266379 N** 차이가 납니다.
FreeCAD는 CAD 면적으로 힘을 나눈 뒤 이산 메시의 면적 가중치로 절점에 분배합니다.
곡선 경계의 이산 면적 근사 때문에 합계가 설정값과 정확히 같지 않을 수 있습니다.
이 예제는 하중을 몰래 정규화하지 않습니다. 치수나 메시를 바꾸면 실제 합계도 다시 확인하세요.
생성 폴더의 `fem-result.json`에는 설정값과 원 입력의 절점 하중 합을 각각 기록합니다.

실제 확인한 기본 모델은 3415절점·1886요소이며, 위 원 분배하중으로 CalculiX가 정상 종료했습니다.
최대 변위는 약 **0.0000360839 mm**입니다. 이는 해당 입력의 실행 결과이며 메시 수렴·강도·안전성
승인을 뜻하지 않습니다. 공학적 적합성은 미확인입니다. 조립 자세 모델과 접촉·비선형 해석의
확인은 이 단일 고체 정적 예제에 포함하지 않습니다.
