# CAD 변수 연결 복구 예제

`public_models.py`는 FreeCAD Python 콘솔에서 호출할 수 있는 공개 시험 모델
생성기다. `sketch_solid(App, Part, Sketcher)`는 편집 가능한 원형 스케치와 돌출,
`property_solid(App)`는 Length 속성을 가진 직육면체를 만든다. 가져온 BRep에서
스케치를 복원하는 예제는 아니다.

1. CAD/FE의 연구 변수 패널에서 **치수 새로 찾기**를 누른다. 스케치 반지름 또는
   직육면체 Length를 선택하고 솔리드와 시험 값 12 mm를 지정한다.
2. **형상 영향 확인**으로 원래 값 10 mm와 모델이 복원됐는지 확인한다. 이름과
   범위 8–16 mm를 정하고 변수를 등록한다.
3. 스케치에서는 앞의 보조 수평 구속을 지워 순서가 바뀌어도 반지름 변수가
   유지되는지 확인한다. 이후 등록된 반지름 구속을 삭제하고 새 Radius 구속을
   추가한다. 속성 모델에서는 직육면체를 삭제하고 새 직육면체를 만든다.
4. 치수를 새로 찾으면 이전 변수 행은 **연결 복구 필요**로 남는다. 그 행에서
   **치수 연결 복구…**를 누르고 새 대상을 직접 선택한다. 형상 영향을 확인하고
   **취소**하면 이전 등록을 유지한다. **연결 적용**하면 이름·범위·모드·메모를
   유지하며 연결만 바꾼다. 새 변수를 추정하거나 자동 연결하지 않는다.
5. 연결 적용 후 값을 14 mm로 편집하고 저장한다. 문서를 닫고 새 창에서 프로젝트를 열어
   같은 등록과 실제 치수를 확인한다. 미해결 등록이 남은 상태는 초안으로 저장할
   수 있지만 그 변수가 필요한 후보 생성·변수 변경 실행은 실행 전 검사에서
   거절한다.

기존 Sketcher 안정 이름이 같으면 구속 순서 변경은 견딘다. 삭제 후 **동일한 이름으로
새로 만든** 구속의 원본 여부는 FreeCAD의 기존 등록 정보만으로 구별하지 못한다.
이 예제는 다른 이름의 치수를 사용해 명시 복구를 확인한다. 지원은 mm 연속 길이
치수이며 표현식 종속·참조 구속·중복 이름은 먼저 FreeCAD에서 수정해야 한다.

2026-10-14 Windows FreeCAD 1.1.4에서 위 두 공개 모델의 등록, 복구 취소,
연결 적용, 14 mm 재편집, `.caepre` 저장과 문서를 닫은 뒤 재열기를 확인했다.
스케치는 앞 구속 삭제로 인덱스가 바뀌어도 등록된 이름을 유지했다. 돌출 부피는
반지름 10→14 mm에 1570.7963→3078.7608 mm³, 직육면체 부피는 Length 10→14 mm에
120→168 mm³였다. 형상 영향 판정은 pinned worker의 기존 임계치를 재사용한다.
해석기·메셔·AI 서비스 호출은 없었고, Qt 화면 렌더는 실제 FreeCAD Qt에서 수행했지만
OS 마우스 입력이나 일반 CAD 복원까지 확인한 것은 아니다.

근거는 로컬 `runs/product-development/20261014/cad-variable-repair/`에 있다.
대역 검사 `tests/test_pre_parameter_repair.py`는 누락/중복, 취소/적용, stale proof,
적용 실패 rollback과 strict 후보 실행 거절을 별도로 확인한다. 긴 Windows staging
경로의 기존 저장 결함은 별개 실패 기록에 남기고 최종 확인은 짧은 export root를 썼다.
