# NS1 공개 입력

이 폴더의 숫자는 연결 확인용 합성 입력이며 실험 물성이나 검증된 해석 결과가 아니다.
`j2_example.tsv`의 첫 열은 진응력 MPa, 둘째 열은 등가 소성변형률 [1]이다.
표 머리글 없이 복사하여 Pre 재료 표에 붙여넣는다. 기본 탄성값의 시험 입력 예시는
E=210000 MPa, 포아송비=0.3이다. 공칭응력/전체변형률의 변환 자료로 사용하지 않는다.

`create_single_solid.py`는 편집 가능한 10×10×20 mm 단일 Box 형상을 만들고
같은 프로세스에서 저장본을 다시 열어 치수와 객체 형식을 확인한다.
FreeCADCmd.exe로 실행하거나 native Python 콘솔에서 `create(output_path)`를 호출한다.
이 원격 개발에서는 FreeCAD가 없어 생성 스크립트 실행은 미확인이다.
기존 파일은 덮어쓰지 않는다. 메시·물성·조건·계산은 생성하지 않는다.

두 물체 접촉은 이미 저장소에 있는 `examples/contact/two-feet.FCStd`를 사용한다.
형상을 바꾼 경우 README의 옛 Face 번호를 자동으로 재사용하지 말고 현재 면을 선택한다.

실제 사용자 모델, 입력 준비, 실패 복구 및 Windows 확인 순서는
[한글 사용법](../../../docs/NS1_USER_MODEL_KO.md)을 따른다.
제품의 실행 경로는 이 예제 이름이나 치수로 분기하지 않는다.
