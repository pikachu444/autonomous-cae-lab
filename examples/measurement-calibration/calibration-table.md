# 연습용 교정 설정

동일한 합성 전압을 V와 mV로 표현한 두 파일에 대응한다. 실제 교정 인증서가 아니다.

| 항목 | V 입력 파일 | mV 입력 파일 |
|---|---|---|
| 입력 열 | voltage_V | voltage_mV |
| 입력 단위 | V | mV |
| 입력 영점 | 0.1 V | 100 mV |
| 계수 | 100 N/V | 0.1 N/mV |
| 출력 오프셋 | 2 N | 2 N |
| 출력 물리량과 단위 | 힘, N | 힘, N |
| 유효 교정 입력 범위 | 0.1~5.1 V | 100~5100 mV |
| 센서 입력 범위 | 0~6.2 V | 0~6200 mV |
| 시각 열과 단위 | time_s, s | time_s, s |

적용 순서는 입력 영점 빼기 → 계수 곱하기 → 출력 오프셋 더하기다.
V 입력은 `힘[N] = 100[N/V] × (전압[V] − 0.1[V]) + 2[N]`,
mV 입력은 `힘[N] = 0.1[N/mV] × (전압[mV] − 100[mV]) + 2[N]`로 비교한다.
유효 교정 범위와 센서 범위는 영점을 빼기 전의 원 입력 기준이며 서로 다른 범위다.

이 연습에서는 범위 양 끝을 포함한다. 5.4 V는 교정 범위 밖이지만 센서 범위 내다.
6.4 V는 교정 범위와 센서 범위를 모두 벗어나며 센서 포화 예시로 표시한다.
실제 센서가 포화 시 어떤 값을 기록하는지는 이 합성 파일로 검증하지 않았다.

교정 원자료와 실물 장비, 유효기간, 인증, 불확실성은 제공되지 않았다.
미제공 불확실성을 0으로 입력하지 않는다. 기대 힘값과 행별 상태는 [README](README.md)에 있다.
