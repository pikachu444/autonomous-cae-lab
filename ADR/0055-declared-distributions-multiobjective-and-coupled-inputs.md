# ADR0055 — Declared distributions, multiobjective campaigns and coupled inputs

Status: accepted for the bounded software paths below; wider engineering gates remain open.

## Problem and decision

The common research flow already runs frozen model/condition LHS and DE campaigns.
It needs explicit input distributions, competing response objectives and selected
coupled PDE inputs without creating another optimizer or an example-specific
execution entry point.

Core now saves an optional declared independent-uniform probability analysis on
the same completed seeded DOE report. Every original sample, native response,
invalid outcome, unit and source pin is retained. The exact SciPy/NumPy LHS design
is replayed; adaptive DE observations cannot be relabeled as uniform samples.
Signed scalar thresholds produce a ratio conditioned on valid numerical rows.
Excluded outcomes remain unknown. LHS observations are stratified and dependent:
there is no invented iid binomial interval or measured failure probability.

Core also wraps the existing single-objective DE with explicit epsilon-constraint
children. A durable parent fixes objectives, directions, units, limits, scales,
seed, child contexts and a whole evaluation budget. Children retain the original
experiment IDs and response vectors. Componentwise non-dominance uses eligible
original responses; it is a finite archive, not a global Pareto or physics claim.
Ambiguous child intent is refused rather than adopted or replayed.

The coupled PDE Domain owns selected two-component regional diffusion/reaction,
source and boundary admission. It admits one selected mesh without requiring an
analytical input or mesh sweep. The adapter translates these declarations and
exports original signed u0/u1 fields. Core binds explicitly declared symmetric
input locations together, keeping all other context frozen. PDE proposals and
results retain their `pde` family namespace/output directory when using common
DOE/DE. Frozen checks demand the same unambiguous family in both records; they do
not guess a family from a currently installed adapter. Old canonical benchmarks
and sealed historical fields retain their original sources and reference rules.

## Boundaries, alternatives and requirement impact

OpenScience interprets questions, hypotheses and retained evidence. Numerical
candidates still come from the existing LHS/DE engines. New MOO MCP declarations
do not expand the approved research profile's fourteen-tool admission, selected
`openai-codex/gpt-5.6-sol`, or existing ChatGPT authentication. Human HTTP controls
use the same Core operations. Reports are opened in a full-width workspace so
their condition and response tables can be read together.

Rejected alternatives: a new LLM optimizer; scalarization that hides original
responses/units; probability from adaptive search; fabricated confidence or
physical qualification; mandatory remeshing; a fictitious CAD parent for PDE;
and a model-family conversion merely to make a frozen check pass.

R18/R31 distribution/UQ and multiobjective software and R16/R31 coupled-input
ports advance within these limits. Actual measured inverse identification,
Sobol designs, general solver-to-solver coupling, SSH/HPC, broad FE/contact and
reconnect/ownership acceptance remain separate open gates. All 52 requirements
and Phase 1–7 remain in scope. UNKNOWN and NOT_RELEASED are unchanged.

## Verification and limitations

Record `20261007-phase7-extension-r01` separates native producers, final readers,
source controls, actual HTTP/browser flows and provider failures. Actual MOO
executes seventeen original native cases; full 3,417 time samples and epsilon/
Pareto membership agree with independent retained-input comparisons. Actual
coupled sign-conjugate cases agree at all 81 two-component nodes. A corrected
common coupled DOE executes two additional frozen candidates, verifies both
symmetric coefficient locations in the native input and preserves full topology.
The earlier failed campaign and its completed first native child remain intact.

The browser creates and reopens a saved UQ report over the original eight native
DOE cases. Independent signed threshold count is 4/8; finite empirical moments
match without replacing invalid/unknown values. This is declared synthetic
numerical propagation, not measured product failure probability. Full-field
reference errors for selected PDE remain null/invalid; solver completion does
not supply an analytical or engineering verdict. Read latency remains open.

Windows record replacement controls are actual filesystem controls. The official
runtime's separate ownership-release failure is not repaired by those controls:
the selected runtime's server starts, but its MCP activation gate fails. A direct
configured stdio initialization/list-tools/EOF diagnostic succeeds without a
provider call or tool invocation. The official source contains a release-marker
cleanup race; its exact timing in the failed run is not proven. Runtime candidate
build and actual approved interpretation remain separate acceptance work.
