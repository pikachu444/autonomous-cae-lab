# ADR0024: Explicit PDE research scope and same-record field inspection

Date2026-10-03. Accepted implementation direction; actual admission/research/
GUI qualification is separate. Packet: docs/PDE_RESEARCH_FIELDS_PACKET.md.

## Decision and reason

Connect implemented qualified PDE families to the OpenScience control plane
through an explicit PDEFields research scope inside existing Research purpose,
and add a read-only native-field inspector to the common verified Results view.
Existing Core operations/envelopes/Domain verdicts/adapters/artifact API remain.
Root owns common interfaces and integration; bounded writers own guard/tests
and the pure reader/tests in separate files. Existing selected5.6Sol/auth/
project/source/lifecycle policies remain; no automatic backend or model fallback.

Existing scalar, rectangle, transient and coupled mathematical evidence grounds
the scope. Imported04e has completed its17-case local campaign but activates
only after independent21-field raw/native audit closes. Vector numerical
REJECTED remains diagnostic-only. Source/runtime registration cannot establish
mathematical or engineering qualification. Native and model/GUI proofs use
distinct exact producer revisions and new experiment stores.

## Alternatives and boundaries

Silently expanding FixtureScalar would change its historical schema1 byte/hash
scope and fourteen-tool behavior. Keep it and StructuralFamilies unchanged;
add case-sensitive PDEFields, six existing tools and schema3 research descriptor.
Time work needs an explicit retained node-value budget, not mesh-only limits.
Budgets constrain resources without changing any numerical accuracy threshold.
Generic job/optimizer/MPI/CFD/nonlinear/vector expansion needs separate admission.

An external new results service or browser-side scientific acceptance engine
would duplicate Core/artifact/Domain responsibilities. Read verified manifested
bytes using current contained artifact API and exact worker file/hash/spec/
source/revision links. Show actual nodal values/triangles/time/components and
retained boundaries/regions/mappings; legacy XDMF/H5-only is download-only.
Partial/rejected/native initial-state semantics remain; stale/tampered output
cannot retain a trusted preview. Human and AI inspect the same immutable record.

## Requirements, contracts and verification

R02/R03/R10-R13/R16/R19-R21/R25/R28/R33/R34/R37/R43-R52 advance by connecting
research choices, actual native work, reusable evidence and human inspection.
No52 requirement is removed; OpenScience owns questions/campaigns/interpretation
and numerical engines generate search candidates. Adapter owns native syntax;
Domain owns science/verdicts; Core owns records/gates/provenance and existing
public calls. This changes the bounded research descriptor and read-only UI,
not Core schema, wire operations, provider, auth or native solver implementation.

Packet freezes exact family/resource/reader contracts before source changes.
Source parity/refusal/staleness/identity/legacy tests and independent review are
required, followed by committed clean-source actual Research/same-record GUI/
owned Stop/retention. These gates stay separate from raw native math, whole CI
and physical qualification. UNKNOWN/NOT_RELEASED remain; all52/Phase4/P2.2 OPEN.
