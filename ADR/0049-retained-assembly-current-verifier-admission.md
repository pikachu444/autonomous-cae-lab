# 0049 — Reuse retained assembly evidence with explicit verifier versions

Status: accepted for the trusted operator path; public assembly research is open.

The qualified original seven-body/84-group mesh has immutable source and CAD
identities. Common contracts and execution control subsequently changed. Requiring
the original verifier dependencies forever prevented legitimate reuse; replacing
historical pins would misrepresent the original producer.

`QualifiedAssemblyMeshBundle` now accepts a separate, explicit trusted
`current_source_files` configuration. Both complete 23-entry maps are verified.
Only the two named common parent-verifier dependencies may differ. The other
21 entries, original artifacts, topology, CAD/result identity and original CAD
verifier fingerprint/input/catalog/result logic remain checked. The original CAD
verifier runs in a private capsule; its Domain bootstrap uses the pinned source
paths. This does not claim current dependencies are the historical executable.
Receipts retain both maps and their distinct verification basis.

This is operator configuration, not an LLM/research setting, uploaded model
permission or new qualification. Core owns provenance and historical evidence;
the fixture Domain owns the fixed affine reference; adapters own native import
and body-aware field extraction. Default Lab/HTTP/MCP admission is unchanged.

Alternatives rejected: overwriting original pins loses history; remeshing repeats
qualified work; relaxing membership or globally monkeypatching verification loses
the original identity. The default exact-source mode remains available.

Actual S4a r03 reused the original mesh in one Code_Aster17.4 process and passed
all56 full-field/reference checks across seven distinct bodies. No new CAD, mesh,
contact, tie, external force or provider call was generated. Original and copied
inputs remained unchanged. The admitted source/meaningful native comparison and
failed r02 source attempt are retained in
`benchmarks/records/20261006-assembly-affine-actual-r03.json`. The final integrated
four-file source suite passed422 tests; native producer and publication source
are distinct. Full native artifacts remain LOCAL_ONLY.

The same record isolates exact51 CI failures: Aster native FACTOR_57, PDE's
unchanged all-pair/component convergence rejection, and explicit installation404.
Three attempted Aster accuracy alternatives did not repair the frozen case;
their bytes/results are retained and their policy changes are not published.
The PDE verifier now preserves complete fields and actual Domain validity before
reporting a detailed expected-category mismatch; thresholds and expected success
remain unchanged. No known failed native case is replayed without new evidence.

Requirement impact: advances original assembly evidence reuse, CAD/GUI identity,
backend-independent provenance and meaningful solver acceptance. It does not
complete actual assembly contact/load transfer, general user conditions,
Phase4–7 extensions, all52 requirements or physical qualification. OpenScience
contract impact: no new tool/profile/model/provider authority; approved5.6Sol
and existing OAuth remain. Materials, strength, durability, physical validation
