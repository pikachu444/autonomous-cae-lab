ANALYSIS INPUTS
해석 시작
부모를 실제 검증한 뒤 정확한 STEP과 CAD 개정으로 새 자식 실험을 만듭니다. 목록 선택만으로 검증 완료를 주장하지 않습니다.

          

          

            
치구의 해석 조건

            
지지부 하나를 해석합니다. 바닥의 X·Y·Z 변위를 고정하고, 안장 중앙 24 mm에 −Z 방향 하중을 분포시킵니다. 볼트와 실제 롤러 접촉은 아직 포함하지 않습니다.

            
            
            
            

              
              
            

            

              

              

              

              
              
현재 재료축은 CAD X·Y·Z와 같습니다. 축 설명만 바꿔도 재료가 회전하지 않습니다. 회전 재료축은 후속 기능입니다.

            

            
            
            
초기값은 미측정 가정값입니다. 상태를 입력하는 것만으로 재료나 강도가 검증되지는 않습니다.

            
            
            
선택 모드는 크기 하나를 지정합니다. 기존 비교 모드는 큰 값부터 작은 값까지 입력합니다. 원래 실험의 방식을 유지하며 메시 비교를 자동으로 추가하지 않습니다.

            

            
          

          
가져올 메시
성긴 메시부터 촘촘한 메시 순서로 3~8개를 고르세요. MSH2.2 ASCII, 합계 96 KiB까지 지원합니다. 선택 후에도 순서를 바꿀 수 있습니다.

          
명시적 해석 설정 검토·수정
예제의 가정, 단위와 검증 한계를 확인하세요. 수정값은 새 실험에 그대로 기록됩니다. 기준 입력을 고르는 것은 이 컴퓨터에서의 새 실행 검증이 아닙니다.

          
해석의 의미
실행 성공과 검증 판정
COMPLETED
솔버가 실행을 끝냈습니다. 수치 검증의 결과는 별도로 확인합니다.
UNKNOWN
확인하지 못한 재료·강도·물리 요구사항입니다. PASS로 대체하지 않습니다.
NOT_RELEASED
현재 근거로 제품 출시·사용 승인을 부여하지 않았습니다.
RESULTS
