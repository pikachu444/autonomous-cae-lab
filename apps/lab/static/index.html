PDE · 재료 · 동해석 · 지원 해석
해석 문제 설정
부모를 실제 검증한 뒤 정확한 STEP과 CAD 개정으로 새 자식 실험을 만듭니다. 목록 선택만으로 검증 완료를 주장하지 않습니다.

          

            
직사각형의 확산·반응 문제
−∇·(k∇u) + cu = f. 좌표와 필드 단위는 1(무차원)입니다. 해석해 없이 선택한 메시 하나로 계산하며, 참조 오차·메시 수렴은 미평가로 남깁니다.

            

            

            
            
식의 x[0], x[1]은 X, Y 좌표입니다. Neumann 값은 바깥 방향의 확산 유량 k∇u·n이며 부호를 그대로 사용합니다. 최소 한 변의 Dirichlet 조건이 필요합니다.

            

            

            
수치 계산 조건

            

          

          

            
두 필드의 영역별 계수와 경계값

            
−∇·(D∇u) + Ru = f. D는 좌표축이 아닌 u0·u1 성분을 연결하는 대칭 양정 행렬이며, R은 공통 대칭 반양정 행렬입니다. 좌우 영역은 x 중간에서 연결됩니다. 모든 좌표·필드 단위는 1(무차원)입니다.

            

            
Neumann 값은 바깥 방향의 D∇u·n입니다. 한 메시의 원 u0·u1을 보존하며 열·구조 물리 연성이나 참조해를 추정하지 않습니다.

            

          

          

            
재료와 변위 이력

            
등방성 J2 소변형 모델입니다. X=0, Y=0, Z=0의 해당 성분만 구속하고 X 최대 면에 입력한 축변형률 × X 길이의 변위를 적용합니다. 전체 절점의 변위·반력과 적분점의 응력·소성변형률을 원 시각으로 보존합니다.

            

            

            

            
H는 등가 소성변형률에 따른 항복응력의 기울기입니다. 전체 변형률에 대한 인장 곡선의 기울기와 다릅니다.

            
            
            
각 행에 시간(s), 축변형률(1)을 입력하세요. 첫 행은 0, 0이며 2–32개 시점, 증가하는 시간과 |변형률| ≤ 0.01을 지원합니다. 유지·제하·역변형의 부호를 그대로 사용합니다.

            
            
            

          

          

            
동적 조건 · 초기 상태와 시간별 하중

            
기존 비회전 강체 모델에 전역 Z 방향의 시간별 체적력을 적용합니다. 입력한 가속도 × 절점 질량이 하중입니다. 변형체·일반 표면 접촉은 아직 지원하지 않습니다.

            

            

            

            
기존 단방향 선형 스프링, 스프링 질량 0.002 kg과 고정 앵커를 사용합니다. 마찰·감쇠·표면 접촉 자격은 미확인입니다.

            
            
각 행에 time_s,acceleration_z_m_s2를 입력하세요. 처음은 0초, 마지막은 종료 시각입니다. 원 솔버의 구간별 선형 하중을 적용하며 속도의 반 증분 시각은 이동하지 않습니다.

            
            
            

          

          

          

            
치구의 해석 조건

            
지지부 하나를 해석합니다. 바닥의 X·Y·Z 변위를 고정하고, 안장 중앙 24 mm에 −Z 방향 하중을 분포시킵니다. 볼트와 실제 롤러 접촉은 아직 포함하지 않습니다.

            
            
            
            

              
              
            

            

              

              

              

              
              
현재 재료축은 CAD X·Y·Z와 같습니다. 축 설명만 바꿔도 재료가 회전하지 않습니다. 회전 재료축은 후속 기능입니다.

            

            
            
            
초기값은 미측정 가정값입니다. 상태를 입력하는 것만으로 재료나 강도가 검증되지는 않습니다.

            
            
            
선택 모드는 크기 하나를 지정합니다. 기존 비교 모드는 큰 값부터 작은 값까지 입력합니다. 원래 실험의 방식을 유지하며 메시 비교를 자동으로 추가하지 않습니다.

            

            
          

          
가져올 메시
성긴 메시부터 촘촘한 메시 순서로 3~8개를 고르세요. MSH2.2 ASCII, 합계 96 KiB까지 지원합니다. 선택 후에도 순서를 바꿀 수 있습니다.

          
명시적 해석 설정 검토·수정
예제의 가정, 단위와 검증 한계를 확인하세요. 수정값은 새 실험에 그대로 기록됩니다. 기준 입력을 고르는 것은 이 컴퓨터에서의 새 실행 검증이 아닙니다.
