# 사용자 검토의 시작점

이번 결과는 Windows 데스크톱 제품의 상세 설계와 별도 Qt 시안이다.
실제 계산 기능의 구현 완료와 구별한다. 제품 개발 시작은 화면 검토 뒤의 사용자 지시를 기다린다.

## CAD·해석·Post·최적화·연구를 이어가기

FreeCAD에서 자기 모델을 편집하고 해석 영역·메시·재료·하중·구속·접촉을 선택한다.
입력 검사를 끝내 실행 대상을 고정하고 Runner에서 제출한다. 실패·취소·연결 손실은
선택한 attempt에서 확인하며 원 입력·로그와 보존 결과를 잃지 않는다.

ParaView에서 같은 실행의 결과를 열어 배열·시각·위치를 선택하고 필터·곡선·측정으로
조사한다. Numerical에서 설계 변수·목표·제약을 정의하고 후보를 비교한다. 명시 채택은
현재 원 설계와의 차이를 확인한 뒤 각 문서에 적용·저장한다. 부분 저장 실패는 해당 문서만
재시도한다. 다시 열면 새 설계와 기존 후보의 원 평가 근거가 구별돼 이어진다.

Co-STORM의 논점 지도·다자 발언·사용자 반론에서 필요한 계산 계획을 검토하고,
같은 결과 근거로 후속 토론을 이어간다. Study 판단과 다음 연구는 사용자가 직접 채택한다.
AI 미연결 상태에서도 질문·자료·과거 발언·연구 문서 편집은 독립적으로 유지한다.

[편집 가능한 전체 연결 도면](research.drawio)은 Pro D1의 기능·계약을 Codex가
작업 흐름으로 연결한 것이다. 프로그램 화면이나 실행 완료 증거를 대신하지 않는다.
Material은 이 전체 도구군의 한 부분이며 다른 도구의 완료 선행조건이 아니다.

## 시험 데이터로 재료 모델을 연구하기

Data에서 두 시험 파일을 연다. A의 s/N/mm/°C와 B의 ms/kN/µm/K를
원본 열과 변환 미리보기에서 대조한다. 시편의 게이지 길이와 초기 단면적으로
공학 변형률과 공칭 응력을 만든 뒤, 표와 곡선에서 구간을 선택한다.
품질 제외, 피팅 포함, 화면 숨김은 각각 다른 조작이다.

Material에서 시험의 횡조건과 법칙을 고른다. 계수 현재값과 Plan 시작값·범위를
같은 작업면에서 편집하되 각 문서의 미저장 표시와 저장 결과를 구별한다.
후보표에서 원자료·예측·잔차·holdout을 비교하고 보존되지 않은 결과는 추가 평가를
명시적으로 선택한다. 후보를 선택하는 것만으로 계산하거나 계수를 바꾸지 않는다.

다른 창이 재료를 수정했다면 채택 전에 이전 값·현재 값·후보를 비교한다.
검토한 변경을 초안에 적용하고 **Save Material**로 저장한다. 다시 열면 채택한 값과
원래 계산 입력을 함께 볼 수 있고, Plan의 원 입력은 명시 갱신 전까지 유지된다.

## 사용자 모델의 접촉과 형상 변경을 다루기

FreeCAD native Pre에서 면 선택 필터로 접촉의 두 집합을 고르고,
법칙·마찰·간극·법선을 설정한다. 선택한 adapter가 실제 지원하는 입력과 출력인지
검사한다. 미지원 설정은 초안으로 보존하고 해당 실행·export를 차단한다.

Post에서 같은 입력 개정의 압력·접촉력·간극·침투·미끄럼과 실제 시각을 확인한다.
형상 변경으로 면이 분할되면 이전 형상의 ghost와 새 면을 비교하고 대응을 선택한다.
취소는 새 형상 편집을 되돌리지 않는다. 대응 적용 뒤에도 이전 메시가 남아 있으면
다시 메시를 만들고 검사를 끝내야 실행할 수 있다. 이전 결과는 그대로 열 수 있다.

## 외부 결과를 비교하고 이동한 파일을 복구하기

ParaView native Post에서 결과를 열고 물리량·단위·위치·시각을 고른다.
비교 전에 물리량 의미, 기저, 실제 시각과 메시 대응을 확인한다. 영역 밖의 점과
없는 시각은 결측으로 유지한다. 기준값이 0인 점의 차분과 백분율 가용성도 구별한다.

파일이 이동했다면 동일한 내용인지 확인해 위치를 복구한다. 내용이 바뀐 파일은
새 입력 개정 또는 분기로 등록한다. 관리 분석 저장은 native Save Data와 구별하며,
종료 뒤 다시 열면 비교 설정·측정·유효 마스크와 원 결과가 이어진다.

## 나머지 독립 도구의 작업

| 시작 도구 | 끝낼 작업 | 확인할 경로 |
|---|---|---|
| PDE / Evaluation | 식·영역·조건을 편집하고 열→구조 전달과 미수렴 원인을 조사해 저장·재개 | SC-06, C08 |
| Numerical | DOE·민감도·UQ·대리모델·Pareto 후보를 비교하고 정확한 원 문서에 채택 | SC-07 |
| Runner | 선택 attempt의 입력·로그·결과를 확인하고 취소·실패·연결 손실 뒤 복구 | SC-04, SC-08, C08 |
| Expert | 자료·논점·역할을 설정하고 실제 발언·사용자 반론·편집 가능한 Plan을 연결 | SC-09, C09 |
| Study | 질문·경쟁 가설·지지/반박 근거를 비교하고 판단·다음 연구를 직접 저장 | SC-09, C09 |
| Material 구성식 / Simulation | 증분 상태·접선·FE 할당과 implicit/explicit/파괴 입력을 조사 | SC-10, SC-11 |
| Data 교정 | 원 측정→보정→같은 관측량의 비교→근거→다음 시험을 연결 | SC-12 |
