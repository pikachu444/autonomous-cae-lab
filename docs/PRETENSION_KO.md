# 볼트 체결 하중

기존 FreeCAD FEM 해석에서 실제 내부 절단면을 선택하고 조임, 절단면 길이 변화 유지, 외력의 순서로 계산합니다. 별도 장비나 AI 연결은 필요하지 않습니다. 현재 지원은 CalculiX 2.22의 C3D10 고체, 소변형 선형 탄성 정적 단계입니다.

## 모델을 열고 체결 조건 편집

1. 자기 `.caepre` 또는 FreeCAD 모델을 열고 기존 FEM 해석과 CalculiX 설정을 선택합니다. 볼트에는 원 고체와 결속된 실제 C3D10 메시가 있어야 합니다. 메시를 새로 생성하거나 임의 좌표를 용접하지 않습니다.
2. **해석 모델 → 볼트 체결 → 새 체결**에서 볼트 메시를 고릅니다. **내부 절단면 선택…**에서 실제 원 요소와 면을 선택합니다. 표의 중심은 mm, 법선은 방향 성분입니다. 전체 절단면의 한쪽만 선택합니다. 양쪽 중복 선택이나 표시용 평면은 사용할 수 없습니다.
3. **인장 축**을 원 전처리 좌표계의 XYZ 방향으로 입력합니다. 선택한 면의 법선을 사용할지는 따로 확인합니다. **조임력 [N]** 또는 **절단면 길이 변화 [mm]**를 선택하고 양의 조임값을 입력합니다. 토크에서 조임력을 추정하지 않습니다.
4. **조건 적용**으로 현재 조건을 반영합니다. **적용한 절점 강조**는 반영된 절단면의 실제 메시 절점을 표시합니다. **수정 취소**는 확인 후 미적용 편집만 버립니다. 응답이 유실됐으면 **요청 다시 확인**으로 같은 요청을 확인하며, 다시 계산하거나 변경한 초안을 덮어쓰지 않습니다.
5. **세 단계 준비…**를 누르고 기존 단계 교체를 확인한 뒤 **해석 단계 편집**에서 외력을 작성합니다. 첫 단계는 조임, 둘째는 절단면 길이 변화 고정, 셋째부터 외력입니다. 처음 두 단계의 일반 하중과 지정 변위는 0이어야 합니다. 외력은 실제 끝면의 Force 또는 기존 Displacement 단계 곡선으로 설정합니다.
6. 기존 전처리의 **입력 파일 생성** 또는 **계산**을 사용합니다. 체결 조건이 있는 해석은 전용 체결 입력 생성 명령으로 동결됩니다. 생성한 입력을 같은 계산 문서에서 열어 내용을 확인할 수 있으며, 문서를 여는 동작만으로 계산하지 않습니다.

현재 체결면은 메시를 정확히 두 부분으로 나누는 평면 내부 요소면이어야 합니다. 중간절점 불일치, 누락 면, 반대 법선, 양쪽 중복, 다른 절단면과 공유하는 절점은 입력 생성을 막습니다. 절단면 절점에 축방향 지지·하중, 다른 주기 구속 또는 접촉이 섞인 경우도 지원하지 않습니다. 지지는 실제 끝면에서 선택하세요. Fixed/Displacement는 정확한 Vertex 선택도 사용할 수 있고 Force는 기존 Face 선택을 유지합니다. 불완전한 수치 초안은 프로젝트에 저장할 수 있지만 실행은 차단됩니다.

## 유지 조건과 결과 읽기

유지는 직전 수렴 해의 참조 자유도 값을 고정하는 `*BOUNDARY,FIXED`입니다. 조임력을 계속 같은 값으로 가하는 조건이나 변위를 0으로 되돌리는 조건이 아닙니다. 이 자유도는 절단 양쪽의 상대 길이 변화이며 볼트 전체의 탄성 변형을 고정한다는 뜻도 아닙니다. [CalculiX 2.22 매뉴얼](https://www.dhondt.de/ccx_2.22.pdf), [고정 경계 구현](https://github.com/Dhondtguido/CalculiX/blob/cff1bb12ec7d24ad9048a1f54ae243a18d1a0b54/src/bounadd.f#L120-L121)

기존 계산 결과에서 이름과 단위를 확인하여 다음 곡선을 선택합니다.

| 곡선 | 의미 |
|---|---|
| 절단면 절점력 합 [N] | 검증된 한쪽 structural cut 절점의 native FORC를 선언한 인장 축으로 투영해 합한 값. 현재 제한된 선택 조건에서만 사용합니다. |
| 반대쪽 절단면 절점력 합 [N] | 반대쪽 원 절점의 같은 투영 합. 양쪽 방향과 평형을 비교합니다. |
| 지지 절점력 합 [N] | 해당 축의 지정 자유도가 있는 지지 절점의 native FORC 합. 같은 위치에 설정한 외력이 있으면 그 영향도 포함하며 자동으로 빼지 않습니다. |
| 절단면 길이 변화 [mm] | 참조 자유도 U1. 단계별 유지 여부를 확인합니다. |
| 복구 응력 면적분 축성분·법선성분 [N] | 원 SOF 응력 면적분. 절점 평형력과 다른 추정량이며 값과 부호를 그대로 보존합니다. |
| 참조 자유도 반력 [N] | 원 RP RF1. 절단면 힘과 동치로 취급하지 않습니다. |

축 투영 합은 실제 원 메시와 solver 복제 절점의 대응을 엄격히 확인한 뒤 계산합니다. 원 FORC 전체를 임의의 내부 힘이나 모멘트로 해석하지 않습니다. SOF는 복구·평균된 절점 응력의 면적분입니다. coarse 메시에서는 힘 평형값과 크게 다를 수 있으므로 두 값을 평균하거나 절댓값으로 바꾸어 강도 판정에 사용하지 마세요. [절점력 조립과 MPC 처리](https://github.com/Dhondtguido/CalculiX/blob/cff1bb12ec7d24ad9048a1f54ae243a18d1a0b54/src/resultsforc.c#L34-L132), [SOF 적분](https://github.com/Dhondtguido/CalculiX/blob/cff1bb12ec7d24ad9048a1f54ae243a18d1a0b54/src/printoutface.f#L421-L523)

단계 축은 정적 하중 매개변수이며 초 단위 실제 시간으로 해석하지 않습니다. 실패·취소한 실행의 원 출력과 상태는 보존됩니다. 수렴이 확인된 온전한 증분만 부분 결과로 읽고 SOF나 RP 출력이 없으면 값을 채우지 않습니다. 완료된 전체 해석으로 표시하지 않습니다.

## 저장과 다시 열기

FreeCAD의 기존 **프로젝트 저장**으로 모델·메시·체결 조건·해석 단계를 함께 저장합니다. 새 프로세스에서 같은 파일을 열고 **볼트 체결**에서 조건을 선택해 이어서 편집합니다. 입력을 다시 만들거나 계산할 때는 기존 v3 메시 결속의 원 BRep와 정확한 하위요소 대응을 검사합니다. 같은 형상의 직렬화 차이는 이 기존 증명으로 확인하며 저장된 참조나 해시를 바꾸지 않습니다. 근거가 없는 구버전 결속 또는 실제 형상·배치·메시 변경은 재선택/재메시가 필요합니다.

기존 계산 문서와 결과를 저장하면 원 입력·작업·결과의 관계도 유지됩니다. 조건을 바꾼 새 계산은 새 작업으로 남습니다. 실제 볼트 설계의 강도·접촉·피로·안전 승인은 이 기능의 실행 성공과 별도입니다.


## 미적용 편집 저장

조임값을 편집하다가 프로젝트를 저장하면 `1e`처럼 입력 중인 값도 같은 문서에 보관됩니다.
보관은 조건 적용과 다릅니다. 다시 열거나 다시 연결하면 그 초안을 이어서 편집할 수 있으며,
계산 전에 **조건 적용** 또는 **수정 취소**를 선택해야 합니다. 저장 확인이 늦게 도착해도
그 뒤에 입력한 내용은 지우지 않습니다. 저장에 실패하거나 작업을 취소하면 현재 편집을 유지합니다.

체결 조건이 있는 해석에서 **FreeCAD 솔버 열기**를 누르면 같은 해석의 **볼트 체결** 탭으로 이동합니다.
기본 FreeCAD 입력 작성기로 체결 조건을 생략하지 않으며, 이 이동만으로 계산을 시작하지 않습니다.
