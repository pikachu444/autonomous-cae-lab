# Autonomous CAE Lab 작업 상태 — 2026-09-30

## 현재 위치

원래 계획 중 **Core, 실제 CAD·FreeCAD, 선형 FEA, 1.5 mm 메시 benchmark,
DOE·수치 최적화, 제한된 weak-form PDE**를 로컬 Windows/WSL과 CI에서
실행했다. 범용 Autonomous CAE Laboratory의 52개 요구사항 전체가
완성된 것은 아니다. Live OpenScience 연구 루프, 고급 비선형·접촉,
explicit, 재료 검증·역문제·HPC·물리 실험은 남아 있다.

마지막 clean numerical 코드 기준은 `41a9858`이고,
[CI 36656020195](https://github.com/pikachu444/autonomous-cae-lab/actions/runs/36656020195)의
6개 작업과 217개 테스트가 통과했다. 로컬 Python 3.12.3 격리 환경과
실제 CAD·솔버 실행도 복원했다. 실행 store와 원본 해시는
`docs/NUMERICAL_CONTINUATION.md` 및 `benchmarks/records/`에 기록했다.

이후 주 세션은 선언형 공통 모델·Code_Aster, 실제 OpenScience 연계를
진행했다. Code_Aster는 실행 종료 성공 뒤에도 잘못된 경계 그룹을 발견해
acceptance 실패로 유지했다. 수정한 import guard의 독립 검토·95개
테스트와 새 실제 draft-05 해석해 비교는 통과했다. Clean source와 CI는
아직 대기 중이다. OpenScience는 이전 실행에서 실제 study·폭 등록을
저장했지만 전체 연구 루프는 아직 통과하지 못했다. 새 live04는 실제
study·변수 조회까지만 성공했고 등록이 도구 호출 없이 끝났다.

사용자가 Code_Aster 예제에 집중하는 문제를 지적해 우선순위를 바꿨다.
현재는 기존 기능을 함께 사용하는 로컬 Research/Design/Simulation/
Explore/Results 화면과 검증된 보고서·증거 ZIP을 연결한다. 구현과 실제
HTTP/browser 검증은 별도 작업으로 관리한다. 실제 HTTP CAD 성공·거부,
PDE, 기존 37개 실험과 9개 증거 묶음 검증은 통과했다. 보고서 경로의
대소문자 충돌 수정은 관련 30개 검사와 독립 검토를 통과했다. Browser
검증과 exact-source CI는 이어서 진행한다. 실패/미검증 항목을 화면에서도
감추지 않는다. 자세한 현재 기록은 `CONNECTED_ACCEPTANCE.md`에 있다.
OpenScience 사용법 질문은 화면 변경 지시가 아니었다. 이 Lab 화면과
공식 OpenScience 대화 화면을 구분해야 한다(`OPENSCIENCE_USE.md`).

## 실제 검증 결과와 한계

- Support width를 32→38 mm로 변경하고 실제 형상 변화를 확인했다.
  bounds/clearance/geometry 효과가 없는 치수의 거부와 editable FCStd 재열기를
  검증했다. 임의 CAD 전체에 같은 검증이 적용됐다고 주장하지 않는다.
- 현재 선형 FEA는 가정한 100 N/지지대, 가정 물성, 고정 바닥, 표면 하중이다.
  부모 CAD STEP과 solver 입력 STEP 해시가 동일하다.
- 기존의 노드별 균등 하중이 메시마다 공간 하중 분포를 바꾸는 문제를
  독립 검토에서 확인했다. 면적 가중 방식으로 수정했고, CalculiX 숫자
  필드 길이로 실패한 CI를 수정한 후 재실행했다. 이전 evidence는 보존했다.
- 이전 38 mm 모델의 3→2 mm 최대 변위 변화는 **2.3361%**이다.
  DOE 유효 설계 3개는 **1.8660%, 1.3669%, 3.8451%**로 기존 5% 예비 기준을
  통과했고 반력 균형도 통과했다. 나머지 1개는 CAD 관계 위반으로 solver를
  실행하지 않았다. 이후 1.5 mm 변경률 **0.881709%**가 통과했다.
- 실제 adaptive search의 최선 관측 폭은 29.7324647 mm, 체적 감소는
  23.3750%, 변위는 0.005961796 mm다. 1세대 예산 종료이며 수렴하지
  않았으므로 최적값 인증은 하지 않는다.
- 제한된 Poisson PDE의 L2 오차는 0.00135043625, 최종 수렴률은
  1.99349, 실제 선형 residual은 약 3.89e-14다. 이는 수학적 benchmark이며
  물리 모델·HPC 검증 완료를 뜻하지 않는다.
- 하중 적분은 선형 삼각분할 근사다. 실제 롤러 접촉이나 정확한 quadratic
  surface integration, 응력 수렴과 강도 승인까지 증명한 것이 아니다.

최종 판정은 **`NOT_RELEASED`**다. 실제 물성, 기계 인터페이스, 강도,
물리 하중 시험, 피로/내구성의 미검증 항목은 `UNKNOWN`으로 유지한다.

## 저장소와 새 세션

저장소는 사용자가 제공한
[pikachu444/autonomous-cae-lab](https://github.com/pikachu444/autonomous-cae-lab)이다.
현재 public이며, 회사/private 사용 결정은 미결이다. 기존 Project의 전체
대화는 이 환경에서 조회하지 못해 복구한 파일·코드·테스트에 근거해 상태를
기록했다. 현재 실제 설치한 OpenScience는 Synthetic Sciences의
@synsci/openscience 2.0.146이며, 조회하지 못한 과거 대화는 확인한 것으로
취급하지 않는다.

`AGENTS.md`는 재개 시 읽을 순서와 경계를, `PROJECT_SCOPE.md`는 초기
52개 항목 전체의 정규화된 요구사항과 상태를, `HANDOFF.md`는 검증 커밋,
로컬 설치·재개 명령, blocker와 다음 acceptance를 기록한다. 대화 기억을
영구적으로 보장하는 대신 저장소로 상태를 복원하도록 했다.

코드 clone만으로 실행 중인 cloud process, 설치한 solver나 raw 결과 ZIP이
이전되지는 않는다. CI raw artifact는 30일 보관되며 해당 검증 ZIP은
2026-10-29 UTC경 만료되므로 별도 장기 보관이 남아 있다.
