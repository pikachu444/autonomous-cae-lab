## 실제 검증 결과와 한계

- Support width를 32→38 mm로 변경하고 실제 형상 변화를 확인했다.
  bounds/clearance/geometry 효과가 없는 치수의 거부와 editable FCStd 재열기를
  검증했다. 임의 CAD 전체에 같은 검증이 적용됐다고 주장하지 않는다.
- 현재 선형 FEA는 가정한 100 N/지지대, 가정 물성, 고정 바닥, 표면 하중이다.
  부모 CAD STEP과 solver 입력 STEP 해시가 동일하다.
- 기존의 노드별 균등 하중이 메시마다 공간 하중 분포를 바꾸는 문제를
  독립 검토에서 확인했다. 면적 가중 방식으로 수정했고, CalculiX 숫자
  필드 길이로 실패한 CI를 수정한 후 재실행했다. 이전 evidence는 보존했다.
- 수정 후 38 mm 모델의 3→2 mm 최대 변위 변화는 **2.3361%**이다.
  DOE 유효 설계 3개는 **1.8660%, 1.3669%, 3.8451%**로 기존 5% 예비 기준을
  통과했고 반력 균형도 통과했다. 나머지 1개는 CAD 관계 위반으로 solver를
  실행하지 않았다. 최적값을 찾았다는 결과는 없다.
- 하중 적분은 선형 삼각분할 근사다. 실제 롤러 접촉이나 정확한 quadratic
  surface integration, 응력 수렴과 강도 승인까지 증명한 것이 아니다.

최종 판정은 **`NOT_RELEASED`**다. 실제 물성, 기계 인터페이스, 강도,
물리 하중 시험, 피로/내구성의 미검증 항목은 `UNKNOWN`으로 유지한다.

## 저장소와 새 세션

저장소는 사용자가 제공한
[pikachu444/autonomous-cae-lab](https://github.com/pikachu444/autonomous-cae-lab)이다.
현재 public이며, 회사/private 사용 결정은 미결이다. 기존 Project의 전체
대화는 이 환경에서 조회하지 못해 복구한 파일·코드·테스트에 근거해 상태를
기록했고, OpenScience 제품 식별은 provisional이다.

`AGENTS.md`는 재개 시 읽을 순서와 경계를, `PROJECT_SCOPE.md`는 초기
52개 항목 전체의 정규화된 요구사항과 상태를, `HANDOFF.md`는 검증 커밋,
로컬 설치·재개 명령, blocker와 다음 acceptance를 기록한다. 대화 기억을
영구적으로 보장하는 대신 저장소로 상태를 복원하도록 했다.

코드 clone만으로 실행 중인 cloud process, 설치한 solver나 raw 결과 ZIP이
이전되지는 않는다. CI raw artifact는 30일 보관되며 해당 검증 ZIP은
2026-10-29 UTC경 만료되므로 별도 장기 보관이 남아 있다.
