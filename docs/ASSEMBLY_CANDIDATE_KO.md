# 선택 자세를 해석 모델로 사용하기

운동의 저장 결과에서 프레임을 고르고 **해석 모델 만들기**를 누릅니다. 원 조립과 원 결과는 그대로 두고, 반복 배치마다 별도의 해석 부품이 있는 편집 모델을 엽니다.

**사용 가능**으로 표시된 모델에서 부품을 고른 뒤 **메시 설정**, **재료 지정**, **하중·구속**을 사용합니다. 다른 반복 부품으로 바꾸었을 때 모델 선택과 편집 대상도 그 부품인지 확인합니다. 원 조립의 기준 고정은 해석 구속으로 가져오지 않습니다.

**준비 실패**, **취소됨**, **중단됨**인 사본은 완성된 해석 모델이 아닙니다. 첫 부품이 정상으로 보이더라도 메시·재료·하중 버튼을 켜지 않습니다. 만들어진 CAD는 **원부품 편집**이나 native 트리에서 수정할 수 있고, 파일 저장도 가능합니다. 운동 창의 **원 조립 사본 열기**에서 다시 만들 수 있습니다. 실패 사본을 지우거나 성공 상태로 바꾸지 않습니다.

저장 후 다시 열면 같은 부품의 메시·재료·면 조건을 읽고 편집을 이어갑니다. 재료 값, 전역·국부 메시 크기와 조건 면을 바꾸면 기존 **적용** 동작으로 반영한 뒤 저장합니다. 크기 설정을 적용한 것만으로 메시가 다시 만들어지지는 않습니다. 새 크기의 메시가 필요하면 **메시 생성**을 명시적으로 실행합니다.

**원부품 편집**은 복사된 CAD를 수정합니다. 같은 CAD를 공유하는 반복 부품에도 변경이 반영됩니다. 원 조립은 바뀌지 않습니다. CAD를 바꾼 뒤 과거 메시나 면 조건이 맞지 않으면 다시 생성하거나 면을 직접 지정해야 합니다. 읽기·검사 과정에서 오래된 연결을 자동 승인하지 않습니다.

지원 형상은 기존과 같이 유효한 양의 단일 솔리드입니다. 동일 위치에 있는 반복 부품도 서로 다른 대상입니다. 모델의 **사용 가능**은 선택 자세 전달이 정상이라는 뜻이며, 재료·메시·조건 설정 완료나 FEM 계산 성공을 뜻하지 않습니다. 빈 재료 등 미완성 입력도 초안으로 저장할 수 있습니다.

Windows FreeCAD에서 네 중첩·반복 부품의 실제 Gmsh 메시와 개별 재료·면 조건을 저장하고 새 프로세스로 다시 열었습니다. 재열기 후 재료·크기 설정·조건 면을 수정해 저장하고 다시 읽는 동작도 확인했습니다. 이 확인에서 새 솔버 계산이나 공학적 승인은 수행하지 않았습니다. 개발 확인 절차는 `examples/assembly-candidate/README_KO.md`에 있습니다.
