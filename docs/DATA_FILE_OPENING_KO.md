# 여러 시험 파일 열기

Data의 파일 메뉴에서 **여러 시험 파일 열기**를 선택하고 CSV·TXT·DAT 파일을
여러 개 고릅니다. 각 원본은 별도 Data 문서와 창으로 열립니다. 창마다 열·단위와
구분자, 시험 조건을 지정한 뒤 설정 적용과 가져오기를 실행하세요.

한 파일을 열지 못해도 다른 파일은 열리고 실패한 파일 이름과 이유가 표시됩니다.
이미 편집하던 창의 원본과 미적용 입력은 그대로 남습니다. 파일을 여는 것만으로
자료 가져오기 계산이나 피팅을 시작하지 않습니다. 원파일을 덮어쓰지 않습니다.

여러 창을 나란히 놓아 서로 다른 열 순서와 단위를 지정할 수 있습니다. 저장은
해당 창의 Data 문서에 적용됩니다. 원본과 저장 결과의 정확한 참조를 유지하며
파일 여러 개를 합친 하나의 자료로 바꾸지 않습니다.

현재 파일당 크기 제한은 기존 업로드와 같은 16 MiB입니다. 이 기능은 여러
독립 시험 자료의 직접 진입입니다. 처리 단계 이력과 자료 묶음 편집은 계속 개발합니다.
