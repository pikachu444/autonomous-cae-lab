## 수용 상태

이 문서는 실제 Pro가 작성한 코드와 Windows 통합의 사용 계약이다. 원 작성 환경에서는 FreeCAD/CalculiX/ParaView/Windows/Qt 화면을 실행하지 않았다. 이후 Windows 제한 확인은 아래와 같으며, 실제 솔버 계산이 필요한 예제는 **미실행**이다. 모의 원자료와 대역 객체의 통과를 제품 수치 수용으로 세지 않는다. native generalized 회전 DOF, 완전한 MPC/이산 구속 반력, 곡선 빔은 이 인도로 완료되지 않는다. `BOUNDARIES.md`와 `PRIMARY_SOURCES.md`를 함께 읽는다.

2026-10-15 Windows에서는 설치 Qt6.9.1로 셸 영역·빔 출력·원결과 표를 정상/좁은 크기에서
표시하고, 미완성 `1e` 원문과 영역 편집 취소를 확인했다. 작은 합성 원자료를 쓴 Qt 이벤트
검사이며 실제 계산 결과나 OS 입력 수용은 아니다. CSV는 표의 실제 물리량·단위·좌표계를
기록하고 원 단계/증분/하중 좌표를 별도로 보존한다. 유도 회전과 지지 응답 표에서는
응력/변형률·기저 선택기가 비활성화된다.

기존 FreeCAD1.1.4에서 곡면 셸의 두 영역 생성·속성 적용·native writer/입력 준비를 한 번
확인했다. 솔버는 실행하지 않았다. 처음 checker가 초기에 저장한 FCStd를 잘못 열어 셸
편집 기록 없는 상태를 성공으로 처리한 오류를 고쳤다. 실제 저장 `.caepre`의 검증된 member를
새 owner에서 읽으면 두께 2/3 mm·오프셋 0/0.25·면/요소 대상과 적용 기록은 그대로 복원된다.
첫 확인에서는 binding 검사가 메시/참조 형상 변경을 보고해 실행 준비 복귀를 차단했다.
이 실패와 원 모델은 보존했다. 후속 교정 뒤 같은 저장본을 새 FreeCAD에서 다시 열었을 때
원 형상·메시·초안·할당이 유지되고 해석 준비 상태로 복귀했다. 자동 재결합이나 재적용은
하지 않았다. 이 확인에서 솔버 계산과 새 저장본 재열기는 반복하지 않았다.
영역별 0 압력도 허용하며 모든 영역이 0인 경우와 기존 단일 영역의 0 압력은 계속 거절한다.
교정의 범위와 남은 제약은 [저장 연결 확인](C1_CORRECTION_KO.md)을 따른다.

특히 B32R/RECT는 내부 50점이다. 공식 ccx 2.22 `printoutint.f`에는 50점 COORD 경로의 배열 크기와 분기 조건에 관한 정적 소스 문제가 있다. 설치 Windows 바이너리의 상태는 확인하지 못했다. 새 원결과 reader는 실제 DAT 좌표를 확장 RECT 위치와 대조하고 불일치를 거절한다. 이 거절을 우회하거나 계산한 좌표를 native COORD로 바꾸면 안 된다. 별도 3D 출력의 native 수용은 이 관문을 실제로 통과한 증거가 필요하다.

## 셸: 단일 영역을 유지하거나 명시적으로 여러 영역 편집

기존 셸 패널에서 기존 분석과 면 메시를 연다. 과거 단일 영역 draft에 `regions`를 자동 삽입하지 않는다. 기존 균일 두께/offset/축, 적용 및 계산 흐름은 그대로 유지된다.

여러 영역이 필요하면 새 **영역 편집** 동작을 선택한다. 대화상자는 현재 초안을 복사해 편집한다. 각 행에는 표시 이름, 참여 S8 요소, native 두께/압력 객체, 두께 [mm], offset [두께 비], 압력 [MPa], 국부축의 전역 성분, 법선 방향이 있다. 내부 JSON/schema/hash를 사용자가 입력할 필요는 없다. 실제 native 요소 선택 대화상자에는 현재 요소 번호와 중심 좌표가 나온다. native에서 선택한 면의 영역을 가져올 때는 실제 Face 참조와 완전한 S8 참여 여부를 검사한다.

영역은 참여 요소 전체를 정확히 한 번 덮어야 한다. 누락·겹침, 동일 native section/pressure 객체의 중복 사용, 참조 상실, 다른 분석에 속한 객체는 실행 오류다. 해당 행/요소를 표시한다. 겹친 요소를 다른 행에서 옮기는 동작도 사용자의 명시적 선택이어야 한다. 잘못 입력한 `-`, 빈 문자열, 두께 0 등의 **원문 초안은 저장 가능**하며, 그 저장을 유효한 Apply로 표시하지 않는다.

법선 반전 동작은 영역의 orientation과 offset을 함께 뒤집는다. 기본으로 선택된 물리적 압력 방향 유지 옵션은 압력 부호도 반전한다. 이 옵션을 명시 해제하면 압력 부호를 유지해 물리적 하중 방향이 달라진다. 동일한 물리 기준면과 하중을 유지하는 기본 경로는 기존 계약을 따른다. 숫자 자체를 변경할 의도와 법선만 반전할 의도를 구별한다. native 미확정 속성 편집 중 반전 계약을 충족하지 못하면 오류를 표시한다. preview의 요소 중심 법선/기저는 계산 전 기하 정보다. solver가 실제 확장한 평균 법선·knot 위치와 동일하다고 주장하지 않는다.

**초안 저장 → 명시 Apply → freeze → 기존 Runner/Run** 순서다. 영역 대화상자 확인은 초안 편집이지 계산 명령이 아니다. 취소는 호스트 초안을 변경하지 않는다. 영역 행을 삭제해도 native 객체를 몰래 삭제하지 않는다. 이전 객체가 분석에 남아 중복 할당을 일으키면 사용자가 분석 트리에서 명시적으로 분리해야 한다.

native에서 두께·압력·축/방향 또는 대상 참조를 변경했으면 **native 영역 불러오기/비교**로 가져온다. stale 적용 stamp를 자동 갱신하지 않는다. 여러 native section을 단일 draft로 납작하게 만들지 않는다. 단일 draft에서 이미 여러 native 객체가 발견되면 명시적으로 여러 영역을 불러오고, 겹침/누락을 행에서 고친다. 현재 구현은 공통 등방 탄성 재료 한 개를 유지한다. 여러 재료나 적층 할당을 임의 선택하지 않는다.

메시/형상/참조가 바뀌면 기존 rebind preview와 명시적 방향 확인을 거친다. preview 이후 편집한 새 원문 영역 값은 늦게 도착한 응답으로 덮지 않는다. 후보 모델에 M4 metadata가 있으면 기존 READY 입구와 writer 후 검사를 통과해야 실행할 수 있다. 이 경우에도 일반 열람·수정·초안 저장은 허용한다.

## 빔: 이번 실행의 출력 방식과 단면 방향

기존 직선 Seg3/B32R·RECT 편집기를 그대로 사용한다. 폭/높이 [mm], 회전 [도], 끝 힘 [N], 끝 모멘트 [Nmm], 끝 변위 [mm], 회전 경계조건 [도]를 편집하고 Apply한다. 기존 native 축 식과 설치 meshtools 비교, 비축정렬 회전/모멘트 진단 관문을 제거하지 않았다.

새 출력 설정은 다음 두 경로 중 **이번 실행 하나**를 선택한다.

- **단면력**: 기존 OUTPUT=2D/SECTION FORCES이다. 이 FRD의 STRESS 이름은 MPa 응력 텐서가 아니다.
- **별도 3D 원응력**: OUTPUT=3D의 확장 절점 U/RF/S/E와 DAT 내부 S/E/COORD를 읽는다. 자동으로 두 번 계산하지 않는다. 원 기계 입력이 같은 단면력 결과가 필요하면 사용자가 두 번째 실행을 명시적으로 선택한다.

각 실행의 input/snapshot/result 폴더와 pins는 분리한다. `beam_output.compare_runs(left_model, left_run_id, right_model, right_run_id)`는 실제 직렬화된 기계 입력이 같은지 읽기 전용으로 비교할 뿐 결과를 하나의 run으로 합치지 않는다. 출력 모드·관측 파생 옵션만 바꾸어도 별도 실행의 ID는 별도로 보존한다.

요소별 단면 방향은 **기하가 동일한 직선 B32R/RECT의 분할 영역**에 한한다. 모든 참여 요소에 정확히 하나의 방향 영역을 지정한다. 이 모드에서는 끝 조건을 전역 좌표로 입력하고 별도 3D 출력을 사용한다. 기본/다른 영역의 native 방향 객체를 중복 사용하지 않는다. 서로 다른 native 축이 실제 확장 형상에서 확인되지 않으면 reader는 통과시키지 않는다. 곡선·꺾인 중심선, 임의 단면, 해석되지 않은 공유 절점 평균 축으로 일반화하지 않는다.

저장/새 Owner 재열기에서 원 좌표·연결 순서·중간 절점 역할·CAD 참조가 정확히 같고 번호만 유일하게 바뀌었다면 기존 beam_mesh_binding 대응을 재사용한다. 조회 단계는 문서를 변경하지 않는다. 현재 실제 번호를 보여 주는 선택기와 저장 참조 번호를 정확한 대응으로만 연결한다. 새 Apply에서 현재 번호로 새 모델/입력을 고정한다. 실제 형상 변화나 모호한 대응은 계속 차단한다.

출력 reference/방향 회전각도 활성 QLineEdit 원문으로 기존 pending_snapshot에 합친다. 기존 끝 조건 delegate의 활성 셀 원문, 동일/다른 receipt, Escape, 늦은 저장 완료 처리 코드는 유지한다. 저장 성공 응답이 다른 snapshot의 새 편집을 지우는 별도 저장 계층을 만들지 않았다.

## 원결과의 네 가지 물리 의미

셸 결과 패널의 **저장된 원 위치·적분점 열기**는 보존된 `shell_inspection.json`을 검증한 후 전용 Qt 표를 연다. 빔은 기존 저장 결과 열기에서 3D 모드를 판별하여 새 원결과 창으로 들어간다. 창 열기·시각/성분/기저 선택은 해석·재메시·재지정 동작이 아니다.

| 표 | 원자료/위치 | 의미 |
|---|---|---|
| 셸 상·하면 | `.12d` 연결과 FRD 확장 절점 좌표/값 | native extrapolated/averaged 표면 복원값. 표면 IP가 아니다. |
| 셸 내부 | DAT의 원 요소/IP, S/E/COORD | S8의 27 내부점. 다중 영역 새 출력은 vertex CELLS이며 POINTS 보간 측정이 아니다. |
| 빔 확장 절점 | `.12d`의 B32R RECT→C3D20RBR topology와 FRD | 실제 확장 체적의 복원/평균 응력·변형률 및 원 절점 관측 U/RF. |
| 빔 내부 | DAT의 정확한 원 요소/IP/COORD | B32R RECT의 50점. 빠진 관측을 0 또는 계산 위치로 채우지 않는다. |

전역 S/E를 사용자 선언 요소 기저로 변환할 수 있다. 변환값은 원 전역 텐서와 원 위치, 기저 출처에 연결된다. 곡면 셸의 요소 중심 기저 또는 빔 선언 단면축은 **native IP 재료축**이라는 이름을 쓰지 않는다. tensor off-diagonal과 engineering gamma를 구별한다. 출력 배열의 단위·association·recovery·shear convention·source block/part를 유지한다. 원 실행 시각/정적 하중 parameter를 현재 모델의 시각으로 바꾸지 않는다.

유도 회전 표는 실제 확장 단면 절점의 U를 등가중 미소 강체 운동으로 최소제곱 투영한 값 [rad]이다. 원 절점/좌표/U, 정의, 가정, rank, condition number, RMS/최대 잔차를 보존한다. 단면 뒤틀림이 없어졌다고 가정하지 않으며, 원 generalized rotational DOF는 **UNAVAILABLE**이다.

지지 집합은 현재 직선 빔의 실제 끝 1/2로 지정한다. 빈 집합, 중복 집합/끝, 중복 확장 절점/face의 합산을 거절한다. 전역 기준점 r0 [mm]에 대해 원 RF 합과 그 힘의 모멘트, 실제 확장 face의 복원 S에서 구한 stress-traction 적분값을 **서로 다른 행**으로 표시한다. RF에는 외부 절점 하중과 MPC 관련 한계가 있으며, stress traction은 복원 응력의 명시적인 후처리 추정이다. 단면 모멘트나 완전한 이산 구속 반력으로 이름을 바꾸지 않는다. 기준점 이동은 `M(r1)=M(r0)-(r1-r0)×F`다.

Post의 일반 POINTS 측정기는 확장하지 않았다. 내부 CELLS/요소별 위치를 자동 점 보간하지 않는다. 원 위치/성분을 전용 inspection API/Qt 표에서 읽는다. 결과를 이동해 새 Owner/store 없이 읽을 때에도 기존 source pins와 전체 보존 원자료를 다시 확인한다. 원 파일뿐 아니라 의미 메타데이터와 파생 표/VTK를 다시 재구성해 변조 여부를 확인한다.

CSV 표를 저장하면 같은 이름의 `.provenance.json`이 함께 만들어진다. 여기에는 CSV 바이트 해시, 원자료 pins, 선택 frame/성분/기저, 물리 정의, 행수와 빈 필드의 의미가 담긴다. CSV는 native 원자료가 아니라 조회 표의 내보내기다. 빈 관측은 빈 필드이며 0이 아니다. 두 파일 중 하나만 배포하면 원자료 관계가 불완전하다.

유도 회전 CSV는 전역 좌표계의 rad·미소 강체-fit으로, 지지 응답 CSV는 전역 힘/모멘트와
각 행의 원 RF 합 또는 복원 응력 적분 정의로 기록한다. 다른 표에서 마지막으로 선택한
응력·변형률 또는 국부 기저를 이 두 표의 출처로 쓰지 않는다.

## 오류와 재개

writer 후 READY 실패, 속성/메시/형상 변경, `.12d` 연결·축·단면 크기 불일치, FRD 조기 EOF, DAT 불완전 coverage, 시각 불일치, 50점 COORD 불일치, source 또는 의미 메타데이터 변조는 성공 결과로 재분류하지 않는다. 실행 실패의 입력과 원파일/log를 보존한다. 문서 초안 저장과 옛 결과 열람은 실행 admission과 별도다.

전용 조회 API는 기존 `shell_inspection`의 `inspect_internal`, `beam_inspection`의 `inspect_raw`와 `inspect_section_responses`다. 원 모델과 결과의 정확한 관계를 먼저 검증하는 기존 load/read_saved_run 경로를 사용한다. 현재 편집 모델을 옛 결과의 모델로 덮어쓰지 않는다.
