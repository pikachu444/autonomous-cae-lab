# 수렴 설정을 바꾸고 이전 계산을 다시 보기

FreeCAD에서 해석의 수렴 조건을 편집하고, 계산 목록에서 반복 중 잔차와 변위
보정을 확인할 수 있다. 저장한 계산은 다시 실행하지 않고 열어 볼 수 있다.

Windows의 FreeCAD 1.1.4에서 설정 적용·저장·재열기와 입력 생성을 확인했다.
수렴 허용치를 바꾼 공개 고체 모델도 CalculiX 2.22에서 계산하고 반복 이력을
다시 읽었다. 이는 해당 실행 경로의 확인이며 모든 접촉 조건이나 공학적 정확성을
보증하지 않는다. 지원 범위와 제한은 아래에 명시한다.

## 1. FreeCAD에서 수렴 설정 편집

Lab으로 사용자 `.FCStd`를 열고 **해석 모델 → 수렴 설정** 탭을 연다.
맨 위에서 적용할 **해석 / CalculiX solver**를 선택한다. 이름이 같아 보이는 다른
해석의 설정을 자동으로 섞지 않으며, solver를 바꾸면 그 대상의 초안으로 전환한다.

설정 종류를 고르면 항목·입력·기본·단위가 같은 표에 표시된다. **사용자 지정**을
켜고 입력 열을 편집한다. Tab/Shift+Tab으로 다음/이전 편집 셀에 이동한다.
아래 설명은 선택한 한 항목의 의미와 범위만 보여 준다. 미사용 위치는 편집하지 않는다.

| 설정 종류 | 적용 대상 | 저장과 입력 |
|---|---|---|
| 수렴 허용치 | NS1 정적 기계 해석 | `*CONTROLS,PARAMETERS=FIELD`의 8개 위치 |
| 반복 제어 | 기존 지원 증분 제어 | native `IterationsControlParameterIter` |
| 증분 조절 | 기존 지원 증분 제어 | native `IterationsControlParameterCutb` |
| 접촉 line search | 정적 surface-to-surface LINEAR penalty 접촉 | LINE SEARCH의 실제 사용 배율 두 개 |

**입력**은 현재 문서의 값, **기본**은 CalculiX 2.22의 해당 제어값이다.
두 열은 의도적으로 다를 수 있다. FreeCAD 1.1.4가 기본 속성 문자열에 넣는
IC=200, IG=400, IA=200과 CalculiX의 기본 16, 4, 5를 같다고 표시하지 않는다.
기존 값을 읽었다고 기본값으로 초기화하지 않는다. **증분값 읽기**는 현재 native
두 행을 읽고, **기본값 사용**은 선택한 설정 그룹의 입력 칸을 명시적으로 비운다.
사용자 지정 해제는 그 그룹의 카드 생성을 끄며, 비활성 원문도 초안에 남긴다.

빈칸은 solver의 제어값을 유지한다. 새 계산 첫 단계에서는 solver 기본값이고,
이후 단계에서는 이전 단계에서 이어진 값일 수 있다. 이번 편집기는 계산 전체에
같은 제어를 적용하며 단계별 서로 다른 FIELD/LINE SEARCH 편집은 제공하지 않는다.
단계별 초기·최소·최대 증분, 단계 구간과 하중 곡선은 기존 **해석 단계** 탭에서
편집한다. 수렴 탭의 **단계 설정…**으로 같은 편집기로 이동한다.

### 비율과 원값을 혼동하지 않기

Rn=`0.005`는 **0.5%**에 해당하는 무차원 기준이다. 입력 칸은 퍼센트 수치를 받는
칸이 아니다. Cn=`0.01`은 1%이다. Rn은 최대 잔차력/시간 평균력, Cn은 최대
변위 보정/최대 증분 변위의 기준이다. Rp는 IP 반복 이후 사용하는 대체 기준이다.
ε, Cε, Rl은 영하중·미소 잔차 예외에 관련된 별도 비율이다.

q0/qu의 단위는 현재 N–mm 체계의 N이다. q0의 제어값 0은 **평균력 0N을 관측했다는
뜻이 아니라 자동 초기화 선택**이다. 2.22의 첫 단계 초기 평균력 기본은 0.01이며
이후 단계는 이전 값과 관련된다. qu가 1e-10N 미만이면 solver가 평균력을 갱신한다.
고정 평균력 선택은 정규화 분모 자체를 바꾸므로 단순 표시 변경이 아니다.

반복 횟수는 정수이고 native I10 읽기를 위해 지수 정수 표기는 거절한다.
제품 편집 범위는 1~1000000회이다. 실수는 유한 숫자·20자 이내여야 한다.
축소 계수는 0 초과 1 미만, 확대 계수는 1 초과, FIELD 비율은 양수이고 q0/qu는
0 이상이다. 이는 제품의 입력 검증 범위이지 어느 값이 공학적으로 적절하다는
승인 기준이 아니다. 원문을 자동 반올림하거나 느슨하게 바꾸지 않는다.

면 penalty 접촉에서는 native의 반복 제어와 예외가 추가로 작동한다.
예를 들어 별도 CONTACT의 itf2f 한도가 있고, IG/IL도 내부 보정될 수 있다.
**IC 표만 바꾸었다고 면 접촉의 모든 최대 반복 제한이 바뀌었다고 판단하지 않는다.**
CONTACT 전용 delcon/alea/kscalemax/itf2f 편집은 이번 범위에 포함하지 않았다.
Da는 온도 증분 제한 관련 계수이며 정적 기계 NS1에서는 비활성이다.

### 저장과 적용

**초안 저장**은 `1e-` 같은 잘못된 입력도 원문으로 저장한다. 그 뒤 문서를 저장하면
기존 `.FCStd`/Lab 프로젝트 재열기 경로에 포함된다. 오류가 있거나 저장만 하고
적용하지 않은 초안은 입력 준비와 실행을 차단한다. 이전 정상 설정으로 몰래
계산하지 않는다. **오류로 이동**으로 해당 셀을 고친 뒤 **설정 적용**을 누른다.
이 동작도 solver를 실행하지 않는다. 화면에 적용 상태가 표시된 뒤 문서를 저장한다.

TIME INCREMENTATION은 FreeCAD의 기존 세 속성(use/두 행)에 적용한다.
FIELD/LINE SEARCH는 FreeCAD 1.1.4 기본 속성·writer에 대응 편집이 없으므로
**같은 native 문서의 Lab 메타데이터에 명시 적용하고 Lab 계산 입력에서 출력**한다.
FreeCAD 기본 FEM의 독립 Run 명령이 이 추가 설정까지 출력한다고 주장하지 않는다.
이 수렴 설정을 사용한 계산은 아래 Lab 입력 준비/실행 경로로 진행한다.

적용 후 native 속성 창에서 TIME 행이나 사용 여부를 바꾸면 적용 불일치를 표시하고
Lab 실행을 차단한다. **증분값 읽기**로 원하는 현재 값을 확인하고 다시 명시 적용한다.
solver를 바꾸거나 늦게 응답이 도착해도 다른 solver의 새 편집을 덮지 않는다.

## 2. 지원 line search와 미지원 안정화

2.22의 line search는 **정적 surface-to-surface penalty 접촉**의 보정 배율이다.
일반 Newton 알고리즘 선택이나 무접촉 J2용 범용 line search가 아니다.
무접촉 또는 tie만 있는 모델, 동적 절차에 추가 설정을 적용하면 차단한다.
지원 LINEAR/Coulomb 접촉이 있어도 첫 반복이나 접촉 요소가 없는 때는 배율이
출력되지 않을 수 있으며, 그 경우 **미기록**이다. 0 또는 1을 만들어 채우지 않는다.

최소/최대 배율을 저장하고 실제 LINE SEARCH 카드로 전달하며, 원 stdout에 있는
`line search factor`를 같은 반복의 원값 표와 그래프로 읽는다. 두 값이 1/1이면
배율을 1로 고정하는 설정이다. 활성화만으로 수렴을 보장하지 않는다.

**2.22 문서와 구현의 위치 차이:** 매뉴얼 441쪽은 두 번째/세 번째 위치를
smax/smin으로 설명하지만, 지정 소스의 `controlss.f`와 실제 소비자인
`nonlingeo.c`는 두 번째를 smin, 세 번째를 smax로 사용한다. 이 구현은
실행 소스의 위치를 따른다. 예를 들어 `,0.4,0.9,,`를 최소 0.4/최대 0.9로 쓴다.
불균등 두 값의 deck 회귀가 있으며, 설치된 Windows 실행 파일에서 같은 배율 경계를
관측하는 최종 native 확인은 Codex 인계 항목이다. 문서의 이름만 베끼지 않았다.

`STATIC,STABILIZE`는 생성하지 않는다. 그 정적 안정화 에너지도 **미지원**이다.
새로운 열전달·NS2 에너지 수렴이나 NETWORK/CFD 제어를 이 기능에 섞지 않았다.
기존 탄성 동적 경로의 TIME 두 행은 유지하지만 새 FIELD/LINE SEARCH 편집은
NS1 정적 경로로 제한한다. 기록 읽기는 기존 기계 동적 시간축을 구분할 수 있으나
그것만으로 NS2의 새 물리·제어 지원을 완료한 것은 아니다.

## 3. 입력 준비와 명시 실행

원 모델에서 재료·메시·하중·접촉·단계와 수렴 초안을 적용한 뒤 기존 **입력 준비**를
사용한다. 실제 mesh/element set 및 native 재료 검증은 그대로 작동한다.
동결된 step에는 기존 controls 두 행과 선택적으로 field_controls/line_search_controls가
포함된다. `.inp`에는 활성화한 그룹만 정확한 위치의 카드로 출력된다.

준비된 입력을 확인한 다음 기존 **실행**으로 제출한다. 설정 적용이나 Runner의
결과 열기만으로는 실행하지 않는다. JobManager의 제출·취소요청·실제 종료 및
실패/성공 상태를 그대로 사용한다. 자동 허용치 완화나 숨은 재실행은 없다.

## 4. Runner에서 반복별 수렴 보기

Runner에서 작업과 시도를 선택하고 기존 **계산 단계**를 연다.
위 표에서 단계·증분·시도를 선택하면 아래 **반복 수렴** 탭에 그 시도만 나타난다.
거절 시도와 다음 재시도를 한 정상 곡선으로 잇지 않는다.
STA 판정이 없는 CVG/stdout 시도는 **판정 미기록**으로 추가된다.
완료된 반복만으로 증분이나 전체 작업의 성공을 추정하지 않는다.

그래프 선택은 잔차력 비율[%], 변위 보정 비율[%], 최대 잔차력[N], 평균력[N],
시간 평균력[N], 최대 변위 보정[mm], 최대 증분 변위[mm], line search 배율[1]이다.
N과 mm를 퍼센트와 같은 축으로 혼합하지 않는다. **대칭 로그**는 표시 변환이며
실제 0은 0으로 남긴다. 결측값은 곡선에 빈 구간으로 남긴다.

**반복 비율** 표는 CVG 값과 접촉 요소 수, stdout의 native 판정을 보여 준다.
행을 선택하고 **원값 / 위치**를 열면 stdout 숫자 원문과 N/mm/1 단위, 기록된
절점 번호와 DOF를 본다. **원문**에는 해당 로그 줄과 읽기 진단이 있다.
**입력 기준**은 그 계산 시도의 저장 설정이며 현재 열려 있는 CAD의 새 설정이 아니다.

CVG 잔차력 비율은 `100 × 최대 잔차력 / time avg. forc`이다. stdout의
`average force`와 `time avg. forc`는 서로 다른 값이다. 후자는 solver가 증분을 따라
갱신하는 수렴용 평균이고 컴퓨터 실행 경과시간의 평균이 아니다. 낮은 정밀도로
출력된 stdout에서 CVG를 다시 계산해 원 CVG 값을 덮어쓰지 않는다.

stdout의 절점/DOF는 native가 보고한 위치 식별자 그대로이다. 현재 C3D10 기계
경로의 DOF 1/2/3을 읽되, 여기에 가상의 좌표나 다른 응력/적분점 위치를 붙이지 않는다.
2.22가 작은 잔차를 0으로 잘라 출력한 경우는 그 **기록된 0**을 유지한다.
CVG의 1e-30/1e30은 분모 극소 표식일 수 있어 표에 구별하고 그래프에서 제외한다.
열전달을 하지 않은 CVG의 flux/temp 0 열은 열 수렴 결과로 표시하지 않는다.

**입력 기준 표시**는 Rn/Rp 또는 Cn의 참고선일 뿐이다. 영하중 예외, 접촉 상태,
미소 잔차/보정 등의 판정을 그래프가 다시 계산하지 않는다. 첨부 실제 기록에는
9증분 3반복에서 보정비 1.34%인데 native가 수렴으로 판정한 사례가 있다.
이 기록을 1% 참고선만 보고 실패로 바꾸지 않는다.

정적 표의 누적 단계 진행값[1]은 하중 진행 좌표이며 물리시간[s]나 wall time이 아니다.
기존 동적 기계 기록은 물리시간[s]로 구분한다. 선택한 단계·증분·시도·반복,
그래프 물리량·표 탭·표시 옵션은 사용자 UI 설정에 저장하여 같은 계산을 재열 때
복원한다. 내부 식별자나 해시는 주 화면에 노출하지 않는다.

## 5. 기록 없음, 부분기록, 손상

| 상태 | 화면과 처리 |
|---|---|
| 파일 없음 / 빈 파일 / 반복 없음 | 별도로 표시한다. 0 잔차 곡선을 만들지 않는다. |
| 마지막 줄·마지막 반복의 EOF 절단 | 끝부분 미완성을 표시하고 실제 읽은 원값만 남긴다. 없는 값·판정은 미기록이다. |
| 내부 손상·중복·역순·닫힌 반복의 필수 원값 누락 | 해당 source를 손상으로 표시하고 그 뒤를 건너뛰어 정상 곡선을 이어 만들지 않는다. 다른 정상 source는 출처를 구분해 읽는다. |
| stdout 단계 좌표 모호함/미기록, 버전 확인 불가 | 원문 진단을 보존하되 단계에 임의 귀속해 CVG와 합치지 않는다. |
| STA/CVG/stdout 식별·좌표·반복수 충돌 | 기록 대응 오류로 표시한다. 수렴 또는 성공으로 승격하지 않는다. |

대응 키는 **STEP / INC / ATT / ITER**이다. C/Fortran 출력 버퍼 때문에 stdout의
STEP 제목이 늦게 나올 수 있으므로 줄 순서나 반복 수를 세어 단계 번호를 만들지 않는다.
저장한 단계 구간과 stdout의 전체/단계 좌표가 유일하게 대응될 때만 연결한다.

원 `.cvg`/stdout/`.sta`/`.frd`는 그대로 보존한다. 이번 변경은 수렴 로그의 파생 자료를
추가할 뿐, 앞선 FRD EOF 보존 범위를 바꾸지 않는다. 특히 9/99/999 종료마커 후속
교정도 유지했다. 부분 FRD의 마지막 실제 결과와 STA 마지막 수렴점은 여전히 별개다.

한 원 로그는 최대 32MiB, source별 반복은 20000행으로 제한한다. 초과는 읽기 제한
진단으로 남기며 전체를 확인한 것처럼 표시하지 않는다. 반복 표는 200행씩 이동한다.
이 기능은 **보존된 시도**의 모니터다. 실행 중 파일을 지속 tail하는 새 live monitor는
추가하지 않았으며 기존 Runner의 진행·취소·원로그 기능은 그대로 사용한다.

## 6. 실패 조건 수정 → 새 계산 → 이전 시도 재열기

실패/취소한 시도를 선택해 잔차·보정의 기록과 마지막 부분결과를 확인한다.
아래 **조건 수정…**을 누르면 해당 계산 당시의 편집 가능한 입력을 **새 설계로** 연다.
현재 다른 창의 모델이나 실패 폴더를 덮어쓰지 않는다. FreeCAD에서 같은 단계와
수렴 설정을 확인하고 필요한 값만 수정 → 설정 적용 → 문서 저장 → 새 입력 준비 →
명시 실행 순서로 진행한다. 허용치를 느슨하게 해 성공시키는 자동 기능은 없다.

예를 들어 최대 반복 수를 바꾸었다면 새 입력 카드와 새 계산의 **입력 기준**에
그 값이 남고, 이전 실패 시도의 표는 이전 값을 유지한다. 접촉 전용 반복 한도는
앞서 설명한 지원 차이를 확인한다. 새 계산이 성공해도 원 실패/취소 상태와 입력,
로그는 그대로 남는다. 취소 요청 후에는 실제 종료 확인 전 새 시도를 중복 제출하지 않는다.

새 계산 결과에는 `convergence_history`가 기존 실행 결과와 함께 저장되고 같은
폴더에 `convergence_history.json`도 남는다. Runner가 저장 결과를 다시 열 때
solver 없이 표/그래프를 복원한다. 새 CAE 해석이나 최적화 작업은 제출하지 않는다.

이 기능 이전에 계산하여 파생 반복 이력이 없는 경우 **입력 조건 → 보존 로그 읽기…**에서
그 시도의 `contact_execution.json`을 선택한다. 저장 입력 식별뿐 아니라 정확한
CVG/stdout 원파일 해시·크기도 대조하므로 같은 입력의 다른 재실행 로그를 섞지 않는다.
검증한 바이트를 그대로 파싱하며 원문 검증 후 다른 내용을 다시 읽지 않는다.
읽기는 메모리상의 파생 보기이고 원 실패 기록을 수정하지 않는다. 로그가 바뀌었거나
그 시도의 원파일임을 확인할 수 없으면 오류를 표시한다.

후처리 필드는 기존 **저장된 결과 열기**로 연다. 이 기능은 CVG/stdout의 수렴 로그
재열기를 추가한 것이며, 실패 결과의 FRD→Post 재생성 범위를 확장하지 않았다.
기존 `--rebuild-post-from`의 성공 시도 제한은 그대로이다.

## 7. 통합과 변경 계약

공개 기준 0548ee0에 `product.patch`를 적용하고, Codex가 **별도 `integration.patch`**의
`bridge.py`/`native_commands.py`/`connection.py` 변경을 공통 명령 등록에 통합해야 한다.
공통 패치는 `pre.fem.convergence_read/save/apply` 등록·dispatch와
Connection의 미저장 수렴 편집 실행 차단이다. 두 패치가
함께 있어야 실제 Qt panel 명령을 소유 문서에서 처리한다. 브랜치 전체를 덮어쓰지 않는다.

`convergence_drafts`는 기존 native 문서 메타데이터의 선택적 추가 목록이다.
기존 TIME 제어만 있는 프로젝트는 그대로 읽고 추가 카드를 만들지 않는다.
새 supplemental 설정을 사용한 문서는 이 기능이 있는 Lab 버전으로 계산한다.
기존 공유 schema의 버전/필수 필드는 바꾸지 않았으며, 오래된 adapter가 이해하지 못할
새 필드를 몰래 무시하게 바꾸지도 않았다. 적용 law/curve snapshot 및 FRD reader는
이번 수렴 목적 외에 수정하지 않았다.

## 8. 확인 자료와 공식 근거

첨부된 `reference_native_run` 5개 원파일을
`tests/fixtures/ns1_convergence_0548ee0/`에 바이트 그대로 보관했다. 제공자의 실제
Windows FreeCAD1.1.4/CalculiX2.22 공개 block-j2 계산이며 **25반복/10수렴 증분**이다.
마지막 반복의 CVG 잔차력은 0.003752%, 보정은 0.08743%이다.
원값·위치, 1% 예외 사례, 파일 불변성을 회귀로 검사한다. 합성 손상/실패 검사와 구별한다.

공식 [CalculiX 2.22 매뉴얼](https://www.dhondt.de/ccx_2.22.pdf) §7.24, 438–442쪽을
읽고 다음 지정 소스와 대조했다. 수렴판정 전체를 재구현하지 않으며 실제 source가
소비하는 위치·출력식을 연결했다. 특히 LINE SEARCH 위치 차이는 2절의 결정대로다.

- [controlss.f](https://github.com/Dhondtguido/CalculiX/blob/cff1bb12ec7d24ad9048a1f54ae243a18d1a0b54/src/controlss.f): 위치, 기본값, I10/F20 읽기.
- [nonlingeo.c](https://github.com/Dhondtguido/CalculiX/blob/cff1bb12ec7d24ad9048a1f54ae243a18d1a0b54/src/nonlingeo.c): 평균력·원값·절점/DOF, line search 적용 조건과 실제 최소/최대 위치.
- [writecvg.f](https://github.com/Dhondtguido/CalculiX/blob/cff1bb12ec7d24ad9048a1f54ae243a18d1a0b54/src/writecvg.f): CVG 백분율·극소 분모 표식·비활성 열.
- [checkconvergence.c](https://github.com/Dhondtguido/CalculiX/blob/cff1bb12ec7d24ad9048a1f54ae243a18d1a0b54/src/checkconvergence.c): 일반 기준과 native 예외·접촉 보정.
- [FreeCAD 1.1.4 solver.py](https://github.com/FreeCAD/FreeCAD/blob/1.1.4/src/Mod/Fem/femsolver/calculix/solver.py): 기존 TIME 속성과 FreeCAD 저장 기본값.

최종 Windows 수용 확인은 작은 기존 공개 모델에서 FIELD/증분 제어를 적용한 입력과
저장 재열기, 기존 LINEAR 접촉의 불균등 line-search 배율, 실패/취소 후 새 계산과
이전 이력의 보존만 우선 확인한다. 이 작성자의 offscreen 검사나 매뉴얼 대조를
Windows native 실행, Astra 독립 검토 또는 NS1 전체 사용자 수용으로 대신하지 않는다.
