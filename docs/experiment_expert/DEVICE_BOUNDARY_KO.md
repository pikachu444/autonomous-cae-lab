# FN35 실제 장비 인도의 남은 입력 계약

파일 수집 설정·재사용과 파일 시험→원값/교정→분석→Study/Report는 기존 기능과
이번 모듈로 계속 진행한다. 실제 장비의 모델, 유지되는 무료 driver, 통신 권한 및
physical stop 규약은 제공되지 않았다. 이번 결과에는 mock driver도 새 장비
framework도 없다. 파일 수집/모의 데이터로 실장비 인도를 완료 표시하지 않는다.

장비별 실제 연결 구현 전에 필요한 것은 다음의 구체적인 정보다.

| 항목 | 필요한 실제 정보 | 없을 때 불가능한 동작 |
|---|---|---|
| 장비 식별 | 제조사/정확 모델/firmware, 공개 통신 매뉴얼 버전 | 지원 명령·응답·채널의 정확한 선택 |
| 무료 driver | 유지 중인 공식/OSS driver의 버전·라이선스·Windows 지원·재배포 조건 | 추가 지출0 설치 및 안정적 연결 인도 |
| 통신/접근 | USB/serial/TCP 등 실제 방식, 포트/baud/encoding/timeout, OS 권한·배타 점유·읽기/쓰기 범위 | 연결/재연결/다중 프로그램 충돌 처리 |
| 측정 정의 | 채널 ID, 명시 단위·측도, clock/timebase·동기·sequence/drop 규약, 위치/방향/기준계 | 시간 정렬·표본 누락·응답 선택·공간 비교 |
| 교정/품질 | 정확 교정 revision/계수/범위/포화/유효기간, 제공 U/k/상관 또는 UNKNOWN | 교정 적용·유효 구간·지원 불확실성 전파 |
| 제어 권한 | 읽기 전용인지 actuator 명령을 허용하는지, interlock·허용 범위·작업자 승인 | 물리적 출력 제어. 파일 import 권한을 제어 권한으로 보지 않음 |
| 중단 의미 | 통신 읽기 중단, 소프트웨어 cancel, 장비 stop, E-stop 각각의 명령/실제 확인응답/timeout 후 정책 | 취소 요청을 물리 stop 확인으로 표시하는 것 |
| 복구/연속성 | 연결 단절 중 장비 동작, 안전 상태, 재연결 시 sequence/중복/누락, 파일 원자성 | 무결한 연속 측정 및 안전한 명시 재개 |

비밀번호·토큰·회사 시험자료를 이 문서/패킷에 추가하지 않는다. 장비 endpoint와
접근권한은 현장 관리 대상이다. 안전 interlock/E-stop의 장비 보증을 소프트웨어
mock으로 대신하지 않는다. 장비 연결이 결정되지 않아도 파일 기반 시험 연구는
위 표의 하드웨어 항목을 기다리지 않고 사용할 수 있다.
