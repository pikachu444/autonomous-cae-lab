# 단축 재료 시험 조건

Material 창의 **도구 → 단축 시험 조건**에서 신장비, 공학 변형률 또는 축응력 이력을
입력한다. 자유 횡변형은 목표 횡응력 yy·zz를 0으로 둔다. 횡변형 고정은 F22·F33을
1로 유지하며, 횡방향 신장비를 직접 지정할 수도 있다.

표의 시간·목표값을 편집하면 지정한 하중 이력을 미리 볼 수 있다. 제어 종류를 바꿀 때
각 종류의 입력을 따로 보존하며 값의 단위를 자동 재해석하지 않는다. `1e`처럼 아직
완성하지 않은 입력은 오류를 보여 주고 그대로 유지한다. 취소하면 Material 입력을
바꾸지 않는다.

**시험 조건 설정**은 창의 입력 편집에 반영한다. 문서 적용이나 계산을 자동 실행하지
않는다. 창에서 실행 취소·다시 실행을 사용할 수 있고, **입력 적용 → 계산 실행 → 저장**을
명시적으로 진행한다. 조건 편집 중 다른 클라이언트가 같은 재료를 변경하면 설정한
조건을 보존하고 적용을 막는다. 최신 내용을 다시 읽거나 편집 내용을 새 문서로 보관한다.

응력 제어 표는 목표 응력과 미지 변형구배의 초기 추정을 구별한다. 저장한 문서를 다시
열어도 이 구별과 조건은 유지된다. 실패한 제어 계산의 유효한 앞부분은 **실패 전 유효
구간**으로 표시하며 전체 성공 곡선으로 이어 그리지 않는다.

현재 제어 엔진의 대상은 기존 FELUPE 선형 탄성·Neo-Hooke 재료점이다. 선형 탄성은
미소변형 Cauchy, Neo-Hooke는 제1 Piola 응력을 사용한다. 이 시험 조건 메뉴는 일반
혼합 텐서 제어, 온도·속도 의존 재료, 내부상태 적분 또는 공학 승인을 제공하지 않는다.

GUI는 실제 Pro가 작성한 `material.control.uniaxial_preview`와 기존 Material owner
명령을 사용한다. 해당 서비스 API의 통합이 필요하며, 이 GUI만으로 핵심 기능이
인도됐다고 보지 않는다. 관련 Material·Plan 저장과 raw 셀 복구는 별도 교정·연결 대상이다.

검증: 기존 Material 및 새 조건 GUI의 Qt 검사 28개, 실제 loopback owner의 적용·저장,
다른 재료 창 보존, 충돌 차단, 새 owner 재열기를 확인했다. Windows 정상·좁은 창에서
실행한 별도 native 검사는 서비스 재시작·재열기까지 확인했고 solver job을 실행하지 않았다.
자유횡 엔진의 실제 FELUPE 비교는 해당 Pro 핵심 전용 검사로 별도 확인했다.
