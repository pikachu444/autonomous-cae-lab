# 재료 계수와 변형 이력 편집

Material의 계수 값과 변형구배 이력은 표에서 편집합니다. 셀을 선택하고
F2 또는 Enter를 누르면 입력할 수 있습니다. Enter는 입력을 확정하고 Esc는
입력 중인 셀만 취소합니다. 잘못된 숫자도 초안으로 보존하며 계산은 차단합니다.

Excel 등의 여러 값을 복사한 뒤 값 열이나 이력 표의 시작 셀에서 Ctrl+V를
누르면 붙여넣습니다. 계수 이름·단위나 표 밖의 범위에 붙여넣으면 전체 붙여넣기를 거절합니다.
필요한 이력 행은 먼저 추가하세요. Ctrl+C는 선택한 셀을 표 형식으로 복사합니다.

입력 적용 전에는 실행 취소와 다시 실행으로 이 창의 편집을 되돌립니다. 붙여넣기
한 번은 한 번의 실행 취소로 되돌립니다. 입력 적용 뒤에는 기존 재료 문서에
적용한 변경을 되돌립니다. 편집 메뉴에는 대상 문서와 취소할 변경 종류가 표시됩니다.

저장은 입력 중인 셀까지 확정해 같은 문서 소유자에 반영한 뒤 저장합니다.
다른 재료 창의 입력은 바꾸지 않습니다. 다른 곳에서 같은 문서가 바뀌면 입력을
그대로 보존하고 충돌을 표시합니다. 편집 내용을 새 문서로 보관하거나 최신 내용을
다시 읽을 수 있습니다. 새 문서로 보관한 내용도 저장 후 다시 열 수 있습니다.

이 표는 현재 지원하는 전체 변형구배 지정 경로입니다. 자유 횡변형 시험,
관련 Material·Plan의 부분 저장과 전체 처리 단계 편집은 별도 개발 범위입니다.

Windows Qt의 실제 두 창, Enter/Esc, 잘못된 초안 저장, 다른 곳의 변경과 충돌,
새 문서 보관과 새 서비스에서 재열기를 확인했습니다. 이번 실행 세션의 Windows
클립보드는 Qt 자체 조회에서 빈 값을 반환했습니다. 여러 셀 복사·붙여넣기는 별도
Qt 위젯 검사로 확인했으며 Windows 클립보드까지 통과했다고 하지 않습니다.
