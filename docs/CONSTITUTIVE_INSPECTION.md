# 구성식 증분 다시 읽기

구성식 증분 창의 `결과 다시 읽기`는 선택한 문서·원 계산·증분의 보존 결과를 다시
읽는다. 새 모델 평가나 섭동 계산을 제출하지 않는다. 다른 증분을 읽기 시작하면 이전
표·그래프·상태 설명을 지우며, 실패하면 같은 증분을 다시 선택할 수 있다. 원 읽기
진단은 상태의 툴팁에 보존한다.

독립 섭동은 기존 명시 확인으로 새 재료 문서에서 실행한다. 제출 응답을 기다리는
동안 증분 변경과 재읽기를 잠가 응답이 다른 선택으로 버려지지 않게 한다. 응답이
유실되면 새 문서와 작업 확인을 안내하고 자동으로 같은 계산을 제출하지 않는다.

전용 Qt 검사는 보존 결과 test double로 exact increment 재조회·이전 근거 제거와
섭동 생성 응답 유실을 확인한다. 새 물리 유효성이나 사용자 법칙의 FE 연결을 검증한
것은 아니다. 정상/좁은 Windows 렌더와 own-process 종료도 별도로 확인했다.
