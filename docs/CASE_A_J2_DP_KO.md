# 같은 시험의 J2·DP 비교

이 작업은 기존 CalculiX J2와 FELUPE DP 경로를 같은 형상·경계조건·관측량으로
비교하는 한정 인수다. 새 DP 법칙을 만들거나 합성 계수를 실제 물성으로 채택하지 않는다.
아래 합성 시험은 사전 입력과 예산을 확정한 뒤 각 조건을 한 번씩 실행했다.

## 보존한 값 읽기

Material의 기존 **구성식 증분** 창에서 실행과 증분을 선택한다. DP의 **변형과 응력**
표에는 보존된 응력·수락 상태에서 계산한 압력 p, 등가응력 q, 부호를 유지한 항복함수 f,
소성 체적변형률, 누적 편차 소성변형률 κ가 표시된다. 읽기와 선택은 계산을 제출하지 않는다.
실패 trial에 수락 상태가 없으면 이 파생 수락값도 생성하지 않는다.

압력은 `p = −tr(σ)/3`이며 압축이 양이다. DP는 기존 `DP-LINEAR-KAPPA-DEV/1`의
`f = q − αp − (k₀ + Hκ)`, `g = q − βp`를 따른다. 항복함수의 음수는 탄성 영역이나
제하에서 가능한 원값이다. Newton 수렴 잔차나 공학적 합격값으로 해석하지 않는다.
소성 체적변형률은 보존된 작은 변형 소성 텐서의 trace다. κ는 누적 편차 소성변형률이며
소성 체적변형률과 다르다.

새 DP 공간 FE 결과는 기존 실제 적분점 `(cell=0, q=0)`의 이 다섯 이력을
`ip0_pressure`, `ip0_equivalent_stress`, `ip0_yield_function`,
`ip0_plastic_volume_strain`, `ip0_kappa` 응답으로 보존한다. 좌표·적분점 선택과 원값을
바꾸지 않는다. 과거 결과에 새 응답을 덮어쓰지 않으며 기존 상태를 읽어 확인한다.

## 비교할 때 구분할 것

인장·압축 시험의 자유 횡방향은 횡응력 0이다. 횡변형을 지정한 구속 시험은 별도 조건이다.
횡변형 고정을 일정 구속압으로 표시하거나 횡방향 자유를 `F22=F33=1`로 대체하지 않는다.
CalculiX의 정적 진행 좌표는 물리 시간과 구분한다.

이번 구속 시험은 기존 전체 경계의 세 변위를 모두 지정하는 affine 조건과도 다르다.
여섯 면에 각 면의 법선 변위만 지정하고 접선 방향과 내부 절점은 자유로 남긴다.
새 `box_normal_displacement` 입력 검사는 작은 변형 DP, 대각 F, 처음의 단위 F,
상자 최소점과 같은 원점, 여섯 개의 완전한 축 정렬 외부 면만 허용한다. 전단·회전이나
재료점의 횡응력 제어를 이 조건에 섞으면 실행을 차단한다. 기존 두 경계 모드는 유지한다.

서로 다른 메시의 절점이나 적분점 번호를 대응점이라고 부르지 않는다. 원 길이와 면 집합을
명시한 같은 gauge의 변위·변형률, 면 반력과 원 면적, 명시한 균질 ROI의 같은 응력 측도를
비교한다. CalculiX FRD의 S/E/PEEQ는 절점 외삽·평균값이고, FELUPE의 공간 응답은 실제
Gauss 적분점 값이다. PEEQ 스칼라로 소성 체적변형률을 복원하지 않는다.
면 반력을 원 면적으로 나눈 값은 부호를 유지한 공칭 응력이다. 이를 전체 Cauchy 응력
텐서와 혼동하지 않으며, 표본별 q의 평균과 평균 응력 텐서에서 계산한 q도 구분한다.

J2와 압력 의존 DP의 차이는 비교 결과로 남긴다. α·β·경화의 정의가 다른 값을 맞추려고
계수·원 입력·허용치를 바꾸지 않는다. 독립 구속 시험을 학습 자료와 섞거나 결과 선택만으로
재평가하지 않는다. 실측 보정과 설계 허용 기준이 없는 합성 시험의 공학적 판단은
**미확인(UNKNOWN)**으로 남는다.

## 현재 확인한 범위

기존 DP Windows 공간 결과의 8 Hex8, 증분당 64 적분점, 네 증분을 별도 소유자에서 HTTP로
읽어 256개 원 상태의 p/q/소성 체적변형률을 대조했다. 원 결과·문서를 유지했고 새 작업은
0개였다. 이 과거 결과 읽기는 새 시험 실행과 구분한다.

새 시험은 1×1×1 mm 상자다. DP는 8 Hex8의 증분당 64 Gauss 점, CalculiX는 별도
27절점·6 C3D10 메시를 사용한다. 탄성계수 210,000 MPa, 포아송비 0.3, 초기 항복값
250 MPa와 경화계수 1,000 MPa는 합성 입력이다. DP의 α=0.2, β=0.05는 직접 계수이며
마찰각·팽창각으로 자동 환산하지 않는다. J2 재료점 보조 비교는 기존 DP의 α=β=0 환원이며,
CalculiX의 독립 J2 표 실행과 구분한다. 이 값들은 제품의 실제 물성 기본값이 아니다.

인장의 F11은 1 → 1.001 → 1.006 → 1.002, 압축은 1 → 0.999 → 0.994 → 0.998이다.
횡방향 응력은 0이다. 보류한 합성 구속 이력은 F11이 압축 이력과 같고 F22=F33을
1 → 0.999 → 0.999 → 0.999로 지정한다. 모두 독립된 처음 수락 상태에서 시작한다.
변위를 되돌린 인장·압축 마지막 단계에는 실제 역항복과 누적 κ 증가가 있었다.
이는 순수 탄성 제하나 무응력 상태의 잔류변형률 측정이 아니다.
구속 시험의 마지막 DP 증분은 κ가 증가하지 않고 항복함수 f가 약 −280.079 MPa인
탄성 복귀였다. 같은 구간의 J2 PEEQ 증가는 별도 원 관측이다. 이 차이를 같은 소성
상태나 모든 시험의 역항복으로 묶지 않는다.

DP 공간 계산 세 건, 각각의 기존 DP 재료점 비교, J2 환원 재료점 세 건, CalculiX 세 건을
실행했다. 원 DP 공간 계산과 같은 법칙의 재료점 비교에는 기존 허용값만 적용했다.
다른 솔버·법칙의 응답 차이에는 이 허용값을 확대하지 않았다. CalculiX의 정확한 정적
단계 끝점 1/2/3을 읽었고 누락 시점의 보간이나 처음 상태 0의 native 출력 생성은 하지 않았다.
독립적으로 보류한 합성 경계 이력은 실제 독립 실험의 보정 검증을 뜻하지 않는다.

첫 native 입력 준비의 연결 순서 오류와 첫 CalculiX 제출의 경로 오류도 보존했다.
기존 순열과 등록 입력의 `run` 경로를 바로잡았으며, 성공한 입력은 재실행하지 않았다.
최종 작업 수는 물리 평가 9건과 솔버 실행 전 차단된 제출 1건을 합쳐 10건이다.
입력·계수·허용값을 바꾸어 통과시키는 반복은 하지 않았다.

해석 문서의 **계산 결과**에서 선택 적분점의 p·q·항복함수·소성 체적변형률·κ를
선택해 원 이력을 확인한다. 후처리에서는 원 CalculiX 장면의 같은 정적 단계와
S/E/PEEQ 출력 위치를 확인한다. Study에는 정확히 보존한 계산과 장면을 연결하고,
재료 선택의 미확인 판단 및 필요한 다음 실측을 저장한다. 결과를 고르는 동작은 계산하지 않는다.

이번 인수에서는 여섯 계산 결과와 세 실제 저장 ParaView 장면을 한 Study에 연결했다.
저장 후 새 소유자에서 같은 저장 개정과 판단을 열어 아홉 참조의 읽기를 확인했다.
압력 성분의 미리보기 선택은 저장된 근거를 바꾸지 않았으며, 다음 실측은 계획 상태로
남겼다. 원 입력·결과·native 자료 15,749개 파일은 같았다. 문서를 다시 열 때 바뀌는
여섯 작업 중 문서의 소유자 세션 필드는 별도로 대조했다. 이 동작을 전체 저장소의
바이트 불변으로 주장하지 않는다.

다수 원본의 전체 검증은 읽기 시간이 걸린다. 동시 파일 검사 중 기존 30초 HTTP 제한에
걸린 한 번의 실패와 원 기록을 보존했으며, 다른 검사가 끝난 뒤 같은 Study를 읽어
복구했다. 이는 대규모 자료의 응답 시간 보장이 아니다.

전용 검사는 `tests/law_native/test_case_a_observables.py`, 기존 결과 HTTP 읽기는
`tests/check_case_a_retained.py`, 기존 Material의 실제 Qt 선택 검사는
`tests/check_case_a_inspection_windows.py`를 사용한다. 실행 receipt와 원 source hash는
`_workspace/case-a-20261018/`의 각 독립 출력에 보존한다.

원 식은 [기존 법칙 정의](law-native/EQUATIONS_KO.md), J2 표의 native 입력은
[고정 CalculiX plastics.f](https://github.com/Dhondtguido/CalculiX/blob/cff1bb12ec7d24ad9048a1f54ae243a18d1a0b54/src/plastics.f)를 따른다.
