# 연구팀 실행과 이어서 검토하기

Expert에서 **연구팀**을 선택하고 공통 질문, 필요한 산출물, 각 담당자의 질문·확인 항목·허용 자료와 도구를 정합니다. 등록된 역할만 참여할 수 있습니다. 역할 이름을 바꾸는 것만으로 전문 지식이나 도구가 생기지는 않습니다. 등록 설정의 지시, 자료 모음, 도구와 이번 배정의 교집합을 실제로 사용합니다. 같은 모델을 선택한 역할도 각자의 과제와 세션에서 실행하며, 분야별 학습 모델이나 전문 코퍼스가 자동 제공되는 기능은 아닙니다.

**질문하기**는 이번 단계의 초기 조사를 시작합니다. 처음에는 각 조사 담당자가 공통 문제와 자기 배정 자료를 받습니다. 다른 담당자의 이번 단계 결론을 자동으로 읽지 않습니다. 명시 선택한 이전 단계의 발언은 현재 자료 권한을 다시 확인한 뒤 출처와 함께 이어받습니다. 각 배정의 확인 항목도 실제 질문 문맥에 포함됩니다. 진행 담당자는 숨은 초기 조사를 별도로 실행하지 않습니다.

기본 예산은 한 번의 실행당 모델 처리 4회, 도구 8회, 자문 0회, 120초이며 모델 처리 상한은 8회입니다. 모델 처리 수는 호스트의 처리 단계 예약 수입니다. 실제 호스트 호출 수 및 청구 수와 같다고 해석하면 안 됩니다. 원격 호스트가 알려주지 않는 내부 요청·토큰·청구량은 확인되지 않은 값으로 남습니다. 시간·예산이 부족하면 미완료 과제를 보존하고 **계속하기**로 다음 범위만 실행합니다. 완료한 초기 조사를 다시 호출하지 않습니다.

세 조사 담당자에게 도구 읽기와 답변을 배정한 기본 예에서는 다음과 같이 진행합니다.

| 예산 | 첫 실행 | 두 번째 실행 | 세 번째 실행 |
| --- | --- | --- | --- |
| 4회 | 첫째·둘째 조사 | 셋째 조사와 실제 주장에 대한 질문 | 질문에 대한 근거 답변과 남은 지도 처리 |
| 8회 | 세 조사와 실제 주장에 대한 질문 | 지정된 담당자의 근거 답변과 남은 지도 처리 | 필요한 경우에만 명시 실행 |

질문 기록에 적힌 실제 담당자가 답변합니다. 사용자가 발언·주장과 **답할 담당자**를 선택해 작성한 질문은 그 담당자의 답변 과제로 전달합니다. 같은 대상이라도 새로 작성한 질문은 별도 과제입니다. 일시 정지, 사용자 발언 추가, 저장만으로는 모델을 호출하지 않습니다. 실행 중 새 사용자 발언이 들어오면 다음 호스트 호출 전에 멈추며, 재개 후 명시한 다음 실행에서 반영합니다.

판단에 필요한 관측을 더 얻을 수 없다면 해당 과제 메뉴에서 **미해결로 남기기…**를 선택하고 사유를 적습니다. 원 실패 상태·응답·사유를 보존하면서 초기 조사 대기 조건만 해제합니다. 모델·도구·새 작업은 실행하지 않고, 완료 응답이나 자료 접근 권한을 만들지 않습니다. 실행 중이거나 결과·프로세스 정리가 미확인인 과제는 이 방법으로 넘길 수 없습니다. 질문 자체를 미해결로 남겼다면 그 질문에 대한 답변도 생성하지 않습니다. 새 질문과 담당자를 명시해 계속합니다.

자문은 기본적으로 꺼져 있습니다. 초기 독립 조사 중에는 사용할 수 없습니다. 허용된 후속 답변에 자문을 명시하고 예산이 충분하면 호출자와 대상 담당자에게 각각 모델 처리 2회 이상을 먼저 배정합니다. 대상에게는 별도의 과제·세션·자료 범위를 적용합니다. 호출자가 대상의 예산을 가져다 쓸 수 없고, 대상 과제는 일반 진행 경로에서 자동으로 중복 실행되지 않습니다.

역할의 전체 원 응답, 제안, 실제 읽은 자료와 입력 의존성을 먼저 저장한 뒤 공유 가능 여부를 확인합니다. 인용 목록을 비워도 실제로 읽은 자료의 권한이 사라지지 않습니다. 정확한 결과 인용에는 계산·입력·결과와 선택 위치가 함께 결속됩니다. 문헌은 서지 정보, 초록, 실제 읽은 본문 범위를 구분합니다. 권한이 철회된 옛 발언은 다음 실행의 공유 문맥에 넣지 않으며, 별도로 허용된 초기 조사는 계속할 수 있습니다.

발언의 `[1]`, `[2]`는 그 응답의 확인된 출처 목록 순서에 연결합니다. 도구를 읽은 순서와 다르더라도 지도의 인용이 다른 자료를 가리키지 않게 합니다. 원 발언과 원 출처 배열은 고치지 않으며, 실제로 읽었지만 인용하지 않은 자료의 의존성도 남깁니다. 출처 목록 밖의 번호는 지도에 억지로 붙이지 않고 응답 형식 교정 대상으로 보존합니다.

지도 반영과 보고서 작성은 원 응답과 별도 작업입니다. 지도 반영이 실패해도 원 응답과 제안은 남습니다. **다시 시도**는 원 작업의 미완료 부분과 지도만 이어가며 완료 역할을 다시 부르지 않습니다. 성공한 지도 처리의 모델 응답은 정확한 원본·권한·기준 지도를 확인한 뒤 재사용합니다. 실패한 임시 지도는 현재 지도를 바꾸지 않습니다. 지도 저장은 성공했지만 반환만 유실된 경우에도 같은 발언을 두 번 삽입하지 않습니다.

형식 교정이나 미완성 응답 마무리는 별도 1회 배정으로 수행합니다. 새 도구를 사용하지 않고 같은 과제가 실제로 읽었던 원 자료만 현재 권한으로 다시 확인해 공급합니다. 다른 담당자의 영수증을 근거로 사용하지 않습니다. 취소나 자식 프로세스 정리 미확인이 발생하면 후속 지도·보고서 호출도 멈춥니다. 정리 여부가 확인되지 않은 과제를 단순 재시도로 다시 실행하지 않습니다.

**보고서 작성**은 승인된 현재 지도를 원본으로 별도 실행합니다. 원 보고서와 출처는 저장된 발언으로 열 수 있습니다. 아직 지도에 반영되지 않은 발언은 보고서의 미반영 목록으로 남습니다. 새 보고서 작성이 실패하면 이전 보고서 원문을 보존합니다. 저장·닫기·다시 열기와 연구 사본 읽기는 새 모델·검색·계산을 실행하지 않습니다. 사본에서 새로운 질문을 실행하려면 현지 역할·자료·로그인 설정과 권한을 명시해야 합니다. 인증 정보나 현재 실행 권한은 연구 사본에 복제하지 않습니다.

## 공개 실행 예

저장 예제만 만들기:

```powershell
python examples/research_team_public.py --output runs/research-team-prepared
```

명시적인 오프라인 생성 대역으로 실제 문서 명령·도구 읽기·예산·Co-STORM 단계·지도를 확인하기:

```powershell
python examples/research_team_public.py --output runs/research-team-controlled --controlled
```

두 명령 모두 새 출력 폴더를 사용합니다. `--controlled`는 공개 예제 문장을 반환하는 대역이며 실제 구독 전문가의 답변이 아닙니다. 기본 실행은 초안 저장만 합니다. 예제에는 계정·API 키·회사 자료·외부 검색·물리 계산이 없습니다. 실제 모델 연결, Qt 사용성, 공학적 타당성은 각각 별도의 검증 범위입니다. 역할의 합의나 실행 성공으로 공학적 승인이 생기지 않습니다.
