# 연구팀의 자료 읽기와 공유

연구 문서에서 질문과 필요한 산출물을 정한 뒤 각 역할이 맡을 질문과 사용할 자료·도구를 선택합니다.
기존에 가져온 공식 자료와 사용자가 선택한 자료를 그대로 사용합니다. 자료를 선택하지 않은
역할의 로컬 검색은 빈 결과이며, 프로젝트 전체를 대신 검색하지 않습니다.

## 자료를 읽고 판단하기

- 자료의 원 개정과 읽을 위치를 선택합니다. 로컬 검색은 선택 범위의 기존 BM25L이며,
  검색 점수는 업무 적합성이나 공학 승인을 뜻하지 않습니다.
- 원문에는 문서 버전·적용 조건·추출 한계가 함께 전달됩니다. 나중에 새 개정을 가져와도
  이전 발언은 처음 읽은 개정에 연결됩니다.
- 공개 논문 검색은 운영자와 현재 연구 질문, 참여 역할의 기존 허가가 모두 있어야 합니다.
  역할의 직접 검색과 검색 보조 기능은 같은 진행의 검색 기록을 사용합니다.
- 사용자가 명시적으로 시작한 한 번의 진행에서는 외부 검색을 두 번까지 시도하며 각 검색에서 논문을 네 편까지 선택합니다.
  실패와 취소도 횟수에 포함합니다. 같은 진행을 다시 시도해도 횟수는 초기화되지 않습니다.
- 검색에 성공하고 원문 읽기만 실패했다면 성공한 검색과 원문은 유지하고 실패한 읽기만
  다시 시도합니다. 제목이 같은 최신 논문이나 다른 검색 순위로 몰래 바꾸지 않습니다.
- 서지만 받았으면 서지, 초록만 읽었으면 초록으로 남습니다. URL이 있다는 이유로 전문을
  읽었다고 표시하지 않습니다. 읽은 범위와 재료·시험·도구 버전의 적용성 판단은 별개입니다.

## 발언과 보고서의 공유

인용 목록만으로 공유 가능 여부를 결정하지 않습니다. 자동으로 들어간 원문, 실제 이력,
상대에게 전달한 질문, 도구의 성공·실패 반환, 자문 결과, 이전 지도까지 실제 입력의
전체 관계를 보존합니다. 제한 자료를 읽은 뒤 인용을 비운 가설이나 계획을 써도 제한은 남습니다.

공유할 때는 현재 수신자 모두의 자료 접근과 운영자·연구 문서의 전송 허가를 다시 확인합니다.
허용 범위를 벗어나면 발언 전체를 공유하지 않으며 제목·주장·질문·계획도 함께 숨깁니다.
과거의 읽기 확인 기록이나 이전에 표시한 화면이 새 허가를 대신하지 않습니다. 철회는 저장된 발언,
다시 시도, 지도와 보고서에서도 같은 방식으로 적용됩니다.

원 사용자가 허용된 로컬 원문을 읽고 로컬 사본을 보존하는 데는 AI 모델이나 외부 전송 허가가
필요하지 않습니다. 이 경로는 기존 문서 소유자의 현재 로컬 접근 검사를 사용합니다.
원 위치로 돌아갈 수 없어도 현재 허용된 보존 내용은 읽을 수 있습니다. 접근 철회는 보존
내용으로 우회할 수 없습니다. 다른 참여자·모델·공유 지도·공유 보고서로의 전달은 별도 검사합니다.

공개 자료만 사용하는 새 답이 필요하면 새 독립 조사와 새 역할 세션을 시작합니다.
제한 응답, 그 요약·질문·이력·지도·자문을 새 공개 조사의 입력으로 재사용하지 않습니다.

## 결과 자료와 실제 계산

결과 선택은 기존 문서에 명시 첨부한 정확한 보존 결과와 응답·성분·위치·시간·행에 연결됩니다.
실제 결과 읽기와 분석의 물리 선택·단위·표본 검사는 기존 결과 reader와 전용 결과 연결이
담당합니다. 이 자료 연결은 새로운 물리 계산기나 결과 검증기를 만들지 않습니다.
메타데이터만 읽은 결과는 수치 관측의 근거로 사용하지 않습니다. 읽기 수준은 실제 반환한
선택을 따르며, 값 읽기 요청을 보냈다는 사실만으로 관측이 되지 않습니다.
도구의 반환과 검증 기록은 기존 문서의 보존 asset에 기록하고, 발언에는 같은 입력 관계를
연결합니다. 저장된 참조만으로 새 실행 권한을 얻지는 않습니다.

## 구현과 확인 범위

Pro의 연구팀 최종 교정 설계를 Sol 담당 B가 기존 KnowledgeStore, Literature/archive,
DiscussionDocuments checkpoint와 A의 단일 계약, C의 결과 선택을 재사용해 구현했습니다.
공통 SelectedRetriever 연결은 별도 최소 패치를 root가 적용했습니다.

전용 검사는 설치된 Windows 연구 runtime에서 실제 BM25·원문·archive를 사용합니다.
외부 논문 응답에는 작은 통제된 fetch 대역을 사용하며 실제 공개검색이나 모델 호출 성공을 뜻하지
않습니다. 결과 양성 검사는 기존 JobManager/문서에 보존한 통제된 수치 자료를 읽으며
solver 물리 검증이 아닙니다. 원격 검색·실제 모델·전체 Qt 수용은 통합 담당의 별도 근거를 봅니다.
