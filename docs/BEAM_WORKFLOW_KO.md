# 빔 모델 편집·계산·저장

## 예제 열기

`examples/beam/Open-Example.cmd`를 두 번 클릭합니다. FreeCAD가 열리면 **빔 → 빔 설정…**을 선택합니다. 예제는 길이 1000 mm의 직선 보, 폭 10 mm·높이 20 mm의 직사각 단면입니다. 끝 1은 고정돼 있고 끝 2에는 전체 Y 방향 모멘트 +1000 Nmm가 걸려 있습니다. 원 예제를 덮어쓰지 않는 작업 복사본에서 시작합니다.

처음에는 계산이 실행되지 않습니다. 화면에 선 형상, 선 메시, 단면·재료·방향·끝 조건이 있는지 확인하세요. 이 경로는 **3절점 B32R 선 요소**를 사용합니다. 입체 요소로 만든 보를 선 요소라고 표시하는 기능이 아닙니다.

열리지 않으면 실행 창에 나온 FreeCAD 경로 또는 시작 오류를 확인합니다. WSL이나 유료 API, AI 계정은 이 작업의 필수 조건이 아닙니다. 계산에는 제품에 설정된 CalculiX 2.22가 필요합니다. Windows의 FreeCAD 1.1.4를 기준으로 합니다.

## 단면과 끝 조건 바꾸기

**단면** 탭에서 폭, 높이, 단면 회전, 탄성계수, 포아송비를 수정합니다. 폭은 단면 **1축**, 높이는 **2축** 방향입니다. 숫자와 단면 그림을 함께 확인하고, **입력 확인** 탭의 축 성분표에서 전체 좌표계에 대한 방향을 확인하세요.

예제처럼 보가 전체 +X 방향으로 놓이면 단면 회전 0°에서 1축은 +Y, 2축은 +Z입니다. 단면만 +90° 회전하면 1축은 +Z, 2축은 −Y가 됩니다. 폭 10·높이 20이라는 치수는 서로 바뀌지 않습니다. **전체 좌표계로 지정한 하중은 단면 회전과 함께 회전하지 않습니다.** 단면 좌표계 하중은 해당 단면축을 따릅니다.

**끝 조건** 탭에서 **끝 1** 또는 **끝 2**를 고릅니다. 표의 성분 기준을 전체 X/Y/Z 또는 단면 1축/2축/길이축으로 선택하고 값을 입력합니다.

| 표의 행 | 입력 단위와 의미 |
|---|---|
| 힘 | N. 선택한 끝 절점에 작용하는 힘입니다. |
| 모멘트 | Nmm. 기준점은 선택한 끝 절점입니다. |
| 지정 변위 | mm. 빈칸은 자유, `0`은 변위 0의 구속입니다. |
| 지정 회전 | °. 빈칸은 자유, `0`은 회전 0의 구속입니다. |

**끝 고정**은 병진·회전 여섯 성분을 모두 0으로 지정합니다. **구속 해제**는 여섯 구속을 모두 자유로 만듭니다. 예제의 끝 모멘트를 바꾸려면 끝 2, 전체 좌표계, 모멘트 Y 칸을 수정합니다. 예를 들어 `1250`은 +1250 Nmm입니다.

새 사용자 모델에서는 같은 해석에 속한 실제 선 메시를 선택합니다. 모델에서 직선 모서리 하나를 선택하고 **단면 → 빔 모서리 → 선택 사용**, **설정 만들기**를 진행합니다. 양 끝 꼭짓점은 **끝 조건 → 끝점 → 선택 사용**으로 각각 지정합니다. 단면·재료·방향이 둘 이상이거나 지원하지 않는 조건이 함께 있으면 자동으로 하나를 골라 실행하지 않습니다.

## 적용하고 입력 만들기

**입력 확인**에서 단면축, 전체 좌표계로 변환된 끝 조건, 오류 목록을 확인한 뒤 **적용**을 누릅니다. 적용은 현재 편집을 FreeCAD 모델에 반영합니다. 화면을 조회하거나 단면 그림을 보는 것만으로 모델이 바뀌지는 않습니다.

입력을 먼저 확인하려면 **입력 생성…**을 누릅니다. 실제 계산용 입력이 별도 폴더에 생성되고 입력 창이 열립니다. 아직 솔버를 실행하지 않습니다. 직사각 단면의 폭·높이, 단면축, 끝 조건을 확인하세요. 끝 모멘트는 모멘트로 기록하며 임의 힘쌍으로 바꾸지 않습니다. 회전 입력의 도(°)는 계산 입력에서 rad로 변환됩니다.

수정 후 아직 적용하지 않았거나 필수 항목에 오류가 있으면 입력 생성과 계산을 사용할 수 없습니다. `1e`처럼 입력 중인 값이나 폭 `0`은 **초안 저장** 또는 **프로젝트 저장**으로 남길 수 있습니다. 마지막으로 정상 적용된 모델은 그대로 두며, 잘못된 초안을 계산하지 않습니다. 오류 항목을 선택해 해당 칸을 고치고 다시 **적용**하세요.

## 계산과 결과 확인

**계산 실행** 또는 **빔 → 계산**을 누릅니다. 현재 적용된 모델로 새 입력을 만들고 기존 계산 목록으로 제출합니다. 이전 입력·결과를 덮어쓰지 않습니다. **이전 계산 → 계산 목록 열기**에서 실행 상태를 확인합니다. 실패·취소가 발생해도 그 계산의 조건과 로그는 남습니다.

보존 결과는 **빔 → 저장된 결과 열기…** 또는 **이전 계산 → 보존 결과 열기…**에서 해당 계산의 `beam_execution.json`을 선택해 엽니다. 계산을 다시 시작하는 동작이 아닙니다. **성분 결과**에서 증분과 성분을 고르면 원 절점별 표와 길이 방향 곡선이 바뀝니다. **성분 표 저장…**으로 선택한 표를 CSV로 저장할 수 있습니다. 읽을 수 있는 완전한 증분이 없으면 원 입력과 로그를 확인하세요. 실패 상태를 성공으로 바꾸거나 누락된 값을 0으로 채우지 않습니다.

| 성분 | 단위 | 물리적 의미 |
|---|---|---|
| UX / UY / UZ | mm | 원 빔 절점의 전체 좌표계 변위 |
| V1 / V2 | N | 단면 1축/2축 전단력 |
| N | N | 길이축 축력 |
| Mt | Nmm | 길이축 비틀림 모멘트 |
| M1 / M2 | Nmm | 단면 1축/2축 주위 굽힘 모멘트 |
| RF_X_raw / RF_Y_raw / RF_Z_raw | N | 전체 좌표계 절점 RF 원출력. 지지부 합력과 다릅니다. |

이 결과는 **원 빔 절점의 2D 출력과 단면력**입니다. 원 파일에 `STRESS`라는 이름으로 저장되더라도 여기서 V1/V2/N과 Mt/M1/M2는 응력 MPa가 아닙니다. von Mises 응력으로 사용하지 마세요. M1/M2도 지지부 반력 모멘트가 아닙니다.

증분 선택에 표시하는 하중 값은 **무차원 정적 하중계수**입니다. 예를 들어 0.5와 1.0을 0.5초와 1초로 읽지 않습니다. 계산 단계·증분·하중계수를 함께 확인하세요.

등록된 결과는 기존 Post에서 열어 물리 성분과 단위를 선택합니다. 등록된 원결과 묶음에는 원 FRD, 동결 모델·메시, 단면축, 실행 입력·상태와 변환 결과가 함께 연결됩니다. 성분을 선택한 뒤 기존 Post 프로젝트 저장을 사용하면 보존된 결과를 다시 열 수 있습니다. 현재 모델을 고쳤더라도 이전 결과는 당시 단면·하중·메시에 속합니다. 파일을 임의로 교체하거나 선언을 삭제해 오류 검사를 우회하지 마세요.

## 저장하고 다음 편집 이어가기

작업을 남길 때는 빔 설정 창의 **프로젝트 저장** 또는 **CAE Lab 도구 모음 → 프로젝트 저장**을 사용하고 `.caepre` 파일 이름을 정합니다. 연결된 프로젝트와 편집 가능한 FreeCAD 모델을 함께 저장합니다. 다른 이름으로 분리하려면 **CAE Lab 도구 모음 → 다른 이름으로 저장…**을 사용합니다. 미적용 수정이나 잘못된 초안도 보존할 수 있지만, 저장 자체가 적용이나 계산은 아닙니다.

끝 조건 표에서 숫자를 입력 중이어도 현재 원문이 저장 초안에 포함됩니다. 예를 들어
미완성 `1e`는 다른 셀로 이동하지 않고 저장해도 그대로 남습니다. 저장 응답을 기다리는
동안 새로 고친 값은 유지합니다. Esc는 현재 셀 편집을 취소하며 앞서 고친 다른 값은 남습니다.

문서를 닫은 뒤 **CAE Lab 도구 모음 → 모델 열기…**에서 **방금 저장한 `.caepre`**를 선택합니다. 프로그램도 종료했다면 `Open-Example.cmd`로 제품을 시작한 뒤 같은 방법으로 저장 파일을 여세요. 예제를 다시 여는 것만으로 지난 작업이 복원되지는 않습니다.

**빔 → 빔 설정…**에서 저장한 폭·높이·회전·끝 조건을 확인합니다. 저장 과정에서 절점·요소 번호만 달라졌더라도 좌표와 방향, 연결 순서, 중간절점 역할, CAD 참조가 정확히 같고 대응이 하나로 정해지면 그대로 작업을 이어갈 수 있습니다. **번호만 바뀐 정상 모델에 매번 참조 재지정을 할 필요가 없습니다.**

예를 들어 폭을 `12`, 끝 2의 전체 Y 모멘트를 `1250`으로 바꾸고 **적용 → 입력 생성…**을 누릅니다. 새 입력은 재열기한 현재 메시 번호와 새 조건을 사용합니다. 기존 입력과 결과의 번호·조건은 그대로 남습니다. 재열기 후 아무 조건도 바꾸지 않고 입력을 만드는 경우에도 현재 메시 번호를 사용합니다.

조회·검사는 저장된 원 참조를 자동으로 고쳐 쓰지 않습니다. 정상적으로 **적용**할 때 현재 메시의 대응 자료가 함께 저장됩니다. **되돌리기 / 다시 실행**으로 적용과 참조 갱신을 함께 되돌리고 복원할 수 있습니다. 다시 실행은 이곳에서 편집의 Redo이며, 솔버 재계산 버튼과 다릅니다.

새 저장 기능을 쓰기 전에 만든 파일 중 원 메시 대응 자료가 없는 파일은 번호 변경을 자동으로 추측하지 않습니다. 이 경우에만 현재 형상·선 메시·끝점·단면·조건을 직접 확인하고 **입력 확인 → 참조 다시 지정**을 사용합니다. 이는 확인한 현재 모델을 새로 채택하는 동작이며, 이전 결과가 현재 모델의 결과라는 뜻이 아닙니다. 이 배포 예제에는 검증 가능한 원 메시 참조가 포함되어 있습니다.

## 참조 변경이나 실패가 표시될 때

형상 길이·배치, 모서리 방향, 끝점 참조, 요소 연결·중간절점이 실제로 바뀌면 번호 변경으로 취급하지 않습니다. 같은 위치에 여러 절점이 있어 대응이 모호한 경우도 차단합니다. 스케치를 고쳤다면 필요한 선 메시를 명시적으로 다시 만들거나 수정하고, 모델과 끝점 선택을 확인한 뒤 **참조 다시 지정**을 진행하세요. 참조 재지정은 메시를 자동 재생성하는 기능이 아닙니다.

단면·재료·방향·메시·끝 조건을 해석 트리에서 제거하면 문서에 객체가 남아 있어도 실행하지 않습니다. 잘못 제거했다면 **되돌리기**로 복원하거나, 해석 트리에서 필요한 객체의 소속과 종류를 명시적으로 바로잡으세요. 프로그램이 객체를 몰래 되살리지는 않습니다.

FreeCAD 속성 창에서 값을 직접 수정했다면 빔 설정의 **입력 확인 → 속성 불러오기**로 읽고 값과 대상을 확인한 뒤 **적용**합니다. 저장에 실패하면 창의 편집과 이전 저장 파일을 유지하고 경로·쓰기 권한을 확인합니다. 실패한 계산을 수정하려면 현재 모델에서 새 조건을 적용해 새 계산을 만듭니다. 이전 실패 자료를 덮어쓰지 않습니다.

## 지원 범위

현재 경로는 하나의 직선 모서리와 연결된 균일 직사각 B32R 메시, 등방 선형탄성 재료, 선형 정적 계산을 대상으로 합니다. 하중 기준은 전체/단면 좌표계를 구분합니다. 단면축이 전체축에 일치하지 않는 일부 성분만의 구속은 지원하지 않는 조합이 있습니다. 오류가 표시되면 임의로 성분을 바꾸어 통과시키지 마세요.

**회전각 결과, 지지부 합반력·합반력 모멘트, 확장 3D 단면 응력은 제공하지 않습니다.** 지정 회전 입력이 가능하다는 사실과 회전 결과를 제공한다는 것은 다릅니다. 후속 결과 경로에서는 실제 확장 메시·구속·원결과를 연결해 검증해야 하며, 변위 평균이나 절점 번호 산술로 대신할 수 없습니다.

비축정렬 빔의 모멘트·회전 구속에는 알려진 CalculiX 2.22 문제 보고가 있습니다. 기본 경로는 해당 조합을 차단합니다. **비축정렬 진단 계산 허용**은 문제를 조사하기 위한 선택이지 검증 완료나 설계 승인 표시가 아닙니다. 계산 종료와 결과 표시가 성공해도 공학적 적합성 승인을 뜻하지 않습니다.
