# 해석 결과의 변위를 다른 모델의 경계조건으로 사용하기

TR-U는 저장한 CalculiX 절점 변위 `U`를 다른 C3D10 메시의 지정 변위 경계로
전달한다. 선택한 **외부 기준면 TRI6** 위의 목표 경계만 지원한다. 내부 절단면,
최근접점 투영, 외삽, HEX 요소, 힘의 보존 전달은 이 경로의 지원 범위가 아니다.
원래 메시의 CCX 절점 순서와 절점 ID를 사용하며, 이미 적용된 native-to-deck
순열을 다시 적용하지 않는다.

입력은 원본 결과와 기준 메시의 SHA256, 저장 원본 참조, 전체 3성분 변위,
좌표계와 길이 단위, 정적 step/increment/load parameter다. 저장된 정적 프레임을
목록에서 선택하며, 정적 하중 진행값 λ는 물리적 시간을 뜻하지 않는다.
VTU는 기존 CCX writer의 단일 ASCII piece, `NativeNodeId`와
`U_mm` 배열을 읽는다. 화면에서 변형된 형상을 기준 좌표로 사용하지 않는다.

원래 외부 면과 목표 외부 면을 선택한 다음 좌표 변환, 거리/자연좌표/가중치
허용값과 반복 한도를 명시한다. 위치와 변위의 길이 변환은 각각 한 번,
변위 회전은 `u_target = s R u_source`로 한 번 수행한다. 위치의 평행이동은
변위에 더하지 않는다. 음수일 수 있는 이차 형상함수 가중치는 그대로 사용한다.

미리보기에는 목표 절점별 원본 면, 자연좌표, 원 가중치, 매핑 변위와 유효 mask가
남는다. 모서리/꼭짓점의 여러 면이 만나는 경우 실제 공통 corner 또는 quadratic
edge topology와 가중치의 수치적 일치를 함께 확인한다. 같은 변위 값만으로 서로
다른 겹친 면을 합치지 않는다. 필수 목표 절점 또는 원본 3성분 지지가 하나라도
없으면 전체 경계 적용을 차단하고 실패 미리보기를 보존한다. 실패의 일부 경계를
솔버에 적용하지 않는다.

## FreeCAD에서 변위 가져오기

수신 형상·재료·C3D10 메시가 있는 독립 선형 탄성 정적 해석을 준비한다. 미리 고정
조건을 만들 필요는 없으며, 물체나 조건의 이름도 자유롭게 정한다. 수신 해석 단계는
하나이며 사용자가 정한 단계 이름·길이·증분·출력과 다른 지지조건·하중을 유지한다.
원본은 Simulation에 저장한 성공 CCX 계산의 기준 형상과 전체 XYZ 변위다.

1. CAE Lab 도구모음의 **변위 가져오기…**를 열고 **해석 이름**에서 기존 설정을 고른다.
   그 아래 **종류**는 사용자 이름과 별개로 실제 솔버·단계 설정을 표시한다.
2. **원본 결과 → 결과 확인**으로 원본 단위·좌표계·정적 위치를 확인하고 외부 면을
   선택한다. **원본 결과 열기**는 그 저장본의 정확한 필드를 연다.
3. **적용할 면**에서 3D의 수신 물체 면을 선택한 뒤 **선택한 면 사용**을 누른다. **3D에서 확인**으로
   대상을 확인하고 지정할 X/Y/Z 성분을 고른다. 기존 조건과 겹치면 **교체할 조건 선택…**에서
   해당 조건을 명시한다. 선택한 면·성분과 겹치는 부분만 교체하며 나머지는 유지한다.
   수신 기준은 모델의 전역 좌표계, mm다.
4. 필요한 **좌표 변환과 매핑 설정…**을 확인하고 **변위 확인**으로 이동한다.
   필수 절점의 유효 상태와 변위를 확인한 뒤 **경계조건 적용**을 누른다. **편집 취소**는 현재 편집만 취소한다.
5. **프로젝트 저장** 후 **계산 관리 → 입력 생성** 또는 **계산 실행**을 사용한다. 미완성 입력은
   먼저 **초안 저장**할 수 있지만 유효한 미리보기를 적용하기 전에는 실행할 수 없다.

저장한 전처리 프로젝트를 다시 열면 정의와 적용한 미리보기를 읽는다. 새 입력을 생성할
때는 원본 파일과 현재 수신 형상·조건을 다시 대조한다. 해석을 추가했으면 **목록 다시
읽기**로 갱신한다. 미저장 편집 중에는 저장·되돌리기·다시 연결을 차단하므로 초안을
저장하거나 편집을 취소한다. 이 전달을 FreeCAD 기본 솔버 작업창에서 실행하지 않는다.

## 지원 범위와 기준 CAD

`caelab.structural_field_ports.read_ccx_vtu` 또는 `read_ccx_displacement`로 원본을
읽고, `caelab.structural_field_transfer.prepare_transfer`로 순수 미리보기를
생성한다. 이 함수는 native 프로그램이나 솔버를 실행하지 않는다. 실제 수신은
기존 native 입력 검증, contact condition/step writer와
JobManager를 통해 수행한다. 원본 열 초기장이나 원래 지지조건을 새 수신 모델에
자동 복사하지 않는다. 기존 목표 조건과의 DOF 충돌도 기존 writer의 검증 대상이다.

현재 첫 native 경로는 기존 Pre의 고정 입력을 등록한 `frozen_contact`와 Runner의
`structure.calculix.contact`를 사용한다. `receiver_from_capture`는 실제 native
capture의 기준 좌표/순서/선택 외부 면을 추출하고, `bind_transfer_model`은 미리보기의
수신 해시와 전체 필수 DOF를 다시 확인한다. 자유 DOF에는 지정 변위를 추가하고,
기존 Fixed/Displacement와 겹치는 경우 명시 선택한 조건의 해당 DOF만 교체한다.
선택하지 않은 조건과의 겹침은 실행 전에 차단한다. 부분 교체 뒤 남은 절점·성분과
그 곡선, 다른 지지와 힘·native 분배 가중치는 유지한다. 매핑 변위에는 수신 단계의
0→U 곡선을 추가하며 사용자 단계를 기본값으로 재작성하지 않는다. 같은 DOF의 비영
힘과 지정 변위 중첩은 현재 compiler의 지원 제한으로 차단한다. 원 조건·원 단계와
교체 대상은 provenance에 남는다.
`structural_transfer_snapshot.freeze_transfer`가 기존 native 입력 형식으로 보존한다.
실행 요청의 settings에는 등록된 `data_id`만 전달한다.

이 파생 입력에 동봉된 FCStd는 **형상과 메시의 기준 CAD**다. 원래 native 조건을
보존하며, 매핑된 지정 변위가 FreeCAD 조건으로 적용된 편집 모델이라고 표현하지 않는다.
계산에 실제 사용한 값은 파생 `mesh.json`의 `boundary_dofs`와 기존 writer가 쓴
`contact.inp`에 있다. 다음 편집은 위에서 저장한 원 전처리 프로젝트를 다시 열어 진행한다.
Runner의 파생 입력 문서 열기와 일반 조건 수정은 안내 후 차단한다. 파생 FCStd의 조건을
직접 바꿔 같은 전달 계산이라고 실행하지 않는다. 외부 범용 U/tensor·접촉/비선형 수신과
동적 시각·다단계 수신·주기 구속·체결·초기 상태는 이 작성 경로에 포함되지 않는다.

원본 판정과 수신의 수치 대조는 별개다. 솔버 성공이 재료·강도·구조 적합성의 승인을
뜻하지 않으며 공학 판정은 UNKNOWN으로 유지한다. 확인에 사용한 자료·명령·원 수치 실패와
실제 화면의 확인 범위는 [기능별 검증 매뉴얼](VERIFICATION_SCOPE.md#pdesimulationevaluation와-장-전달)에 있다.
