# 보고서 이동 사본의 Windows 확인

2026-10-15, 기존 Windows Python 3.12.14와 PySide6 6.9.1에서 확인했다.
실제 Pro가 작성한 보고서 전용 구현과 공통 세 파일의 패치를 통합했다.
원 Pro의 Linux 검사 기록은 보존하며 Windows 결과로 바꿔 부르지 않는다.

공개 예제에서 원 보관소와 외부 자료 폴더를 제거한 뒤, 별도 프로세스가 보고서를
읽고 제목·본문 수정, Undo/Redo, 저장과 재복사를 수행했다. 첫 사본도 제거한 뒤 다른
프로세스에서 재복사본을 읽고 저장했다. 원 보고서·보관 그림·자료 값과 성공·실패 이력은
유지됐으며 재열기로 새 계산을 만들지 않았다. 예제의 그림은 시험용 그림이다.

실제 Qt 창에서는 파일 메뉴, 미적용 설명으로 돌아가기, 저장·취소, 제목·본문의
Undo/Redo와 저장, 보고서만 선택된 연결창, 현재 원자료 열람과 창 종료를 확인했다.
사본의 그림만 보관한 경우 원래 native 프로그램을 열지 않는다. 이 화면 확인과 별도로
작업 사본 생성·편집·재복사·재열기는 실제 서비스와 공개 예제로 확인했다.

독립 검토에서 찾은 현재 원자료의 잘못된 정상 표시도 교정했다. 원자료 조회·대조에
실패하면 열기를 재확인으로 돌리고, 보관 값과 본문은 남긴다. 해당 실패·회복과 창 열기
차단의 새 국소 검사도 통과했다. 공개 원본과 원 실패 로그는 보존했다.

Windows에서 잠긴 실행 중 제어 파일을 예제의 불변 비교에서 읽지 않도록 정확한 한 경로만
제외했고, 예제 삭제 대상도 자신이 새로 만든 공개 폴더로 한정했다. 제품의 저장·검증·잠금
규칙은 바꾸지 않았다. 화면 검사 도우미의 대기·클립보드·정상 삭제 판정 실패도 기록에 남겼다.
모든 소유 Job과 서버·창을 종료했으며 솔버·AI 호출이나 추가 설치는 없었다.

문헌이 포함된 보고서, 저장 비교·피팅 후보의 전용 탐색, 손상 사본의 부분 열기와
Study·Expert·PDE·Simulation·Evaluation·CAD·후처리 프로젝트 이동은 잔여다.
이번 결과는 전체 이동 기능이나 공학적 적합성의 완료 판정이 아니다.

정확한 실행·소스와 원 실패 기록은 개발 환경의
`_workspace/delivery-install-connections/c3b-report-r1-windows/`에 보존했다.
