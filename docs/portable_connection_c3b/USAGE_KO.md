# 보고서를 다른 폴더로 옮겨 이어 쓰기

공학 입력·계산 결과와 그림이 담긴 보고서를 다른 작업 폴더로 옮겨 계속 편집할 수 있습니다. 보고서에 연결된 데이터·재료·계산 계획도 함께 선택할 수 있습니다. 문헌이 포함된 보고서의 이동과 Study·Expert·해석 문서·CAD·후처리 프로젝트 전체의 이동은 아직 지원하지 않습니다. 보고서 그림을 옮겨도 원래 3D 프로젝트를 편집할 수 있는 것은 아닙니다.

## 사본 만들기

1. 보고서 제목과 본문을 확인합니다. 설명 편집칸이 열려 있다면 **설명 적용**을 누르고 저장합니다.
2. **파일 → 작업 사본 만들기…** 또는 **Ctrl+Shift+S**를 누릅니다. 문서 연결창에 현재 보고서가 선택됩니다.
3. 보고서 원자료도 다시 열어 검토하려면 데이터·재료·계산 계획을 함께 선택합니다. 보고서만 고르면 보관된 값과 그림은 읽을 수 있지만 원자료 창으로 이동할 수는 없습니다.
4. 연결창의 **선택 문서를 새 작업 사본으로…**를 눌러 포함 목록을 확인하고, 아직 존재하지 않는 새 폴더를 지정합니다. 기존 폴더는 덮어쓰지 않습니다.

적용하지 않은 설명이 남아 있으면 그 편집칸으로 돌아갑니다. 제목이나 본문을 저장하지 않았다면 저장 여부를 묻습니다. 취소하면 입력은 그대로 남습니다. 저장을 선택해도 곧바로 복사되지는 않으므로 메뉴를 다시 열어 포함 목록을 확인하세요. 다른 창에서 편집한 내용은 그 창에서 적용하고 저장해야 합니다.

## 옮긴 사본 열기

복사가 끝나도 현재 창은 원래 작업 폴더를 계속 사용합니다. 새 폴더 전체를 함께 옮기고 시작 명령에서 그 경로를 지정하세요. 아래 예시의 경로를 실제로 만든 사본 폴더로 바꾸세요. 다른 작업 폴더를 동시에 열 때는 서로 다른 포트를 사용합니다.

```powershell
.\Start-CAE-Lab.cmd -Store 'D:\연구 사본' -Port 8767 -Tool report
```

사본에서도 제목·본문·구성을 수정하고 실행 취소·다시 실행·저장을 사용할 수 있습니다. **원자료 열기**는 함께 옮겨 검증한 자료를 엽니다. 현재 원자료를 읽지 못하면 연결을 다시 확인합니다. 보고서에 보관한 그림과 값은 계속 읽을 수 있습니다. 자료나 그림을 읽는 것만으로 새 계산이나 AI 요청을 시작하지 않습니다.

저장하고 닫은 뒤 같은 폴더로 다시 열어 작업을 이어 갑니다. 사본에서 다시 **작업 사본 만들기…**를 사용하면 또 다른 폴더로 옮길 수 있습니다. 현재는 저장된 비교·피팅 후보의 전용 탐색과 원래 CAD·후처리 프로그램을 다시 여는 연결을 지원하지 않습니다.

## 자료가 없거나 저장에 실패했을 때

원래 그림을 만든 외부 폴더가 없어도 보고서에 보관한 그림이 정상이면 읽을 수 있습니다. 보관한 그림이나 자료가 손상됐다면 해당 원본을 복구하거나 정상 사본에서 다시 옮겨야 합니다. 다른 그림으로 내부 파일을 바꿔 맞추지 마세요. 새 그림은 프로그램의 자료 추가·교체 기능으로 넣습니다.

저장에 실패해도 이미 열린 창의 본문과 이전 정상 저장본은 유지됩니다. 사본 전체가 손상돼 열리지 않을 때 일부만 여는 복구 기능은 아직 없습니다. 복사 결과를 확인하는 동안 원래 작업 폴더도 보관하세요.

공개 합성 자료로 재현하는 명령과 Python·CLI 사용법은 [개발·검사 안내](TEST_COMMANDS.md)에 있습니다. 예제에 사용한 그림은 화면 캡처가 아닌 시험용 그림입니다. Windows에서 실제로 확인한 범위는 [Windows 확인](WINDOWS_VERIFICATION_KO.md)을 참고하세요.
