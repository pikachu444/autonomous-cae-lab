# 문서를 옮겨서 계속 편집하기

연결창의 작업 사본은 선택한 저장문서, 당시 반영된 초안, 보존된 입력과 결과를 한 폴더로 옮깁니다. 이동 후에는 각 도구에서 현재 초안을 수정하고 명시적으로 저장합니다. 새 계산이나 AI 요청은 사본 만들기·열기·저장으로 실행되지 않습니다. FreeCAD와 ParaView 실행 프로그램 자체는 별도로 준비해야 합니다.

## 사본에 넣을 내용 선택

1. 문서의 **작업 사본 만들기…**를 열고 연결창에서 함께 옮길 문서를 체크합니다. 원자료나 결과가 다른 문서에 연결돼 있다면 그 문서도 직접 선택합니다. 누락된 연결은 포함 목록에서 확인할 수 있습니다.
2. **선택 문서를 새 작업 사본으로…**는 저장본과 서버에 반영한 현재 초안을 포함합니다. **선택 저장본만 새 작업 사본으로…**는 저장한 내용만 사용합니다. Study·Expert에서 저장하지 않은 편집을 두고 **저장된 내용만**을 선택했다면 연결창도 이 정책으로 시작합니다. 두 정책은 파일 메뉴에서 명시적으로 선택할 수 있습니다.
3. Data·Material·Numerical에 이미 **편집 원문 보관**한 자료가 있으면 함께 옮길 보관본을 직접 체크합니다. 선택하지 않은 미적용 셀 입력은 자동으로 가져오지 않습니다. 그 밖의 문서는 이 원문 선택창을 거치지 않고 포함 목록으로 갑니다.
4. 포함할 문서·저장본·입력·결과·파일과 오류를 확인합니다. 새 폴더를 지정하고 포함 목록을 확인한 뒤 복사합니다. 취소하면 원문서가 바뀌지 않습니다.

생성 응답을 받지 못했다면 **사본 생성 응답 확인 / 같은 요청 재시도**를 사용합니다. 이 요청이 남아 있는 동안 다른 사본 생성을 시작할 수 없습니다. 대상 폴더가 이미 있거나 검토 뒤 원문서가 바뀌었다면 오류를 확인하고 현재 선택으로 다시 검토하세요. 기존 폴더를 자동으로 덮어쓰거나 다른 최신 결과를 대신 가져오지 않습니다.

서버가 원문서 변경 때문에 사본을 만들기 전에 거절했다고 확인한 경우에는 새 포함 목록을 검토할 수 있습니다. 응답 유실·시간 초과·적용 여부가 불명확한 오류는 이 확인으로 대신하지 않으며 같은 요청을 유지합니다. 파일이 많거나 큰 저장 결과가 있으면 확인과 복사에 시간이 걸릴 수 있습니다.

응답을 받지 못한 채 창이나 서비스를 다시 열었다면, 기존 목적지 폴더를 **작업 사본 확인 / 누락 파일 복구…**에서 먼저 확인합니다. 보존 검증을 통과한 폴더는 그대로 열며 다른 사본으로 대체하지 않습니다. 폴더가 없거나 검증이 끝나지 않았다면 완료로 보지 않습니다.

## 새 위치에서 열고 저장

폴더 전체를 함께 옮겨 제품 서비스의 `--store` 대상으로 엽니다. 한글과 공백이 있는 경로도 사용할 수 있습니다. 원래 창은 원 보관소에 계속 연결돼 있으므로, 새 서비스 주소로 연 도구에서 사본을 편집해야 합니다.

기존 Python 실행 환경을 사용한다면 다음처럼 별도 서비스와 연결창을 엽니다. 폴더 경로와 사용하지 않는 포트를 지정하세요.

```powershell
python -m apps.lab.server --store "D:\공학 작업\옮긴 작업 사본" --port 8767
python -m apps.research.desktop --service http://127.0.0.1:8767 connection
```

| 문서 | 새 위치에서 이어갈 작업 | 보존 자료를 읽는 기준 |
|---|---|---|
| Data | 열·단위·매핑과 시험 정보를 편집하고 저장 | 등록된 원 CSV·보정 자료, 원 성공·실패 실행 |
| Material | 계수와 시험 계획의 현재 입력을 편집하고 저장 | 원 관측, 선택 후보·채택 근거, 단위 |
| Numerical | 현재 계획의 변수·설정을 편집하고 저장 | 선택한 실행·후보·진단의 정확한 입력과 결과 |
| PDE | 방정식·계수·경계 조건을 편집하고 저장 | 원 방정식 입력과 보존 결과 |
| Simulation | 현재 물리 모델의 설정을 편집하고 저장 | 원 실행 입력과 보존 필드·실패 상태 |
| Evaluation | 평가 단계와 연결을 편집하고 저장 | 각 단계가 참조한 원 입력과 결과 |
| Study | 질문·근거·명시 판단을 편집하고 저장 | 정확한 결과 근거와 문헌 원문·구간 |
| Expert | 보존 발언을 읽고 현재 질문을 편집·저장 | 원 발언·첨부 결과·참조; 새 답변은 별도 명시 요청 |
| Report | 본문·구성·설명을 편집·저장하고 내보내기 | 보관한 그림·표·곡선·단위·출처 구간 |
| FreeCAD Pre | 보관한 프로젝트를 해당 도구에서 열어 편집·저장 | 편집 가능한 FCStd와 선언한 프로젝트 자료 |
| ParaView Post | 보관한 프로젝트를 해당 도구에서 열어 편집·저장 | 상태 파일·reader가 선언한 결과 의존 파일 |

이 표는 문서별 작업 경로를 설명합니다. 실제 사본에 포함된 자료는 생성 전 포함 목록과 **작업 사본 확인 / 누락 파일 복구…**에서 확인하세요. 없는 결과를 새로 계산하거나 원 store에서 자동으로 찾아 채우지 않습니다. 보존된 실패와 미확인 판단은 그대로 남습니다. 입력을 바꾸어도 화면에 남은 원 결과가 새 입력의 결과로 바뀌지는 않습니다.

미적용 원문은 원문 읽기와 현재 편집기에서 이어가기를 구별합니다. `1e` 같은 미완성 값은 자동으로 숫자로 적용되지 않습니다. 원 보관본의 복구·폐기 권한도 새 사본의 권한이 되지 않습니다. 부분 저장 기록은 당시의 결과를 설명하며 완료 저장으로 바꾸지 않습니다.

## 다시 옮기기와 오류 복구

현재 편집을 저장한 뒤 같은 작업 사본 메뉴에서 다시 포함 목록을 검토해 새 폴더로 복사합니다. 다른 Python 프로세스와 새 서비스로 열어 저장한 초안과 원 결과를 확인할 수 있습니다. 원 그림이나 문헌 파일의 외부 위치가 없어도 사본에 보존된 자산은 계속 읽을 수 있습니다. 보존하지 않은 외부 파일의 누락은 별도 오류로 남습니다.

저장 중 오류가 나면 현재 편집과 기존 저장본을 유지한 상태에서 해당 도구의 요청 확인·재시도를 사용하세요. 저장 결과가 불명확한 동안 다른 문서를 덮어쓰지 않습니다. 닫기에서 취소하면 편집을 계속할 수 있습니다. FreeCAD·Post에서는 실제 열림과 저장 확인이 끝나기 전 상태를 완료로 표시하지 않습니다.
