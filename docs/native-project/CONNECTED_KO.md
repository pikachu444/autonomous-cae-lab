# 저장한 모델과 분석을 연구에서 열기

FreeCAD 모델과 ParaView 분석은 각 프로그램에서 계속 편집하고 저장합니다. 연구 서비스에 연결하면 Study·Report 등에서 근거로 선택한 저장본을 같은 프로그램으로 열 수 있습니다. 작업 사본만 사용할 때는 연구 서비스나 AI 연결이 필요하지 않습니다.

## 연구 근거의 저장본 열기

1. Study나 Report에서 원자료를 엽니다.
2. FreeCAD 근거는 **저장한 모델 열기**, ParaView 근거는 **저장한 분석 열기**를 누릅니다.
3. 별도 native 창에서 선택한 저장본을 확인합니다. 열기 요청을 보냈다는 안내와 실제 열림 확인은 구분됩니다. 확인이 늦으면 같은 버튼으로 상태를 다시 확인합니다.

열었던 창을 닫은 뒤 같은 버튼을 누르면 먼저 닫힘을 확인합니다. 안내를 읽고 버튼을 한 번 더 누르면 새 창으로 다시 엽니다. 단순 연결 끊김은 창을 닫았다는 뜻이 아니므로, 상태 확인만으로 새 창을 중복 실행하지 않습니다.

이미 열려 있는 다른 모델이나 분석은 바꾸지 않습니다. 과거 저장본을 여는 동작은 최신 작업 사본을 선택하는 동작과 다릅니다. 현재 작업을 열려면 작업 사본에서 해당 모델이나 분석을 명시적으로 선택하세요.

선택한 작업 사본이 이미 열려 있고 연결을 확인할 수 있으면 그 창을 활성화합니다. 저장하지 않은 편집은 유지합니다. 열린 창과 선택한 저장본의 대응을 확인하지 못하면 새 창을 중복으로 열지 않고 연결 확인을 안내합니다.

이미 열린 창에서 특정 부품·면이나 결과 선택을 다시 맞추는 동작은 현재 지원하지 않습니다. 현재 선택을 확인할 수 없다는 안내가 나오면 저장본을 별도 창에서 열어 대상을 선택하세요. 미저장 창의 선택을 자동으로 바꾸지 않습니다.

## 첫 저장과 저장 결과 확인

과거 저장본을 편집한 창에서 처음 저장하면 **새 작업 사본으로 저장**할지 묻습니다. 취소하면 현재 편집을 유지하며 원 저장본은 바뀌지 않습니다. 확인하면 그 창의 기존 저장 기능으로 새 작업 대상에 저장합니다.

파일 저장 뒤 연결 기록 갱신을 확인하지 못한 경우에는 **저장 연결 다시 확인**을 사용합니다. 이미 끝난 native 저장을 다시 실행하지 않고 같은 저장 결과의 등록과 연결만 확인합니다. 실행 중인 저장은 즉시 취소할 수 없을 수 있으므로 완료 상태를 먼저 확인하세요.

## 작업 사본 만들기

1. native 프로그램의 **파일 → 작업 사본 만들기…**에서 포함할 저장본을 선택합니다. 현재 편집을 포함하려면 기존 저장 기능으로 먼저 저장합니다. 마지막 저장본을 선택하면 현재 화면의 편집은 포함하지 않습니다.
2. 외부 부품과 결과 파일, 연결할 연구 문서의 포함 목록을 확인합니다. 누락된 자료가 있으면 위치를 복구하거나 누락 표시를 보존할지 명시적으로 선택합니다.
3. 새 폴더를 지정해 사본을 만듭니다. 기존 폴더와 원파일은 덮어쓰지 않습니다. 폴더 선택을 취소하면 사본을 만들지 않습니다.

사본의 파일 검사가 끝나도 모든 native 기능이나 해석 가능성이 확인된 것은 아닙니다. 지원하지 않는 부품·reader·분석 이력은 해당 위치와 필요한 조작을 확인하세요. 단위나 좌표를 자동 변환하지 않으며 사본 열기·저장은 새로운 메시·해석·AI 요청을 실행하지 않습니다.
