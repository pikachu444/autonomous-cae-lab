# 실패하거나 취소한 계산 다시 살펴보기

Runner에서 확인할 작업을 선택한 뒤 **결과 보기**로 남아 있는 값을 읽습니다.
실패·취소한 결과는 부분 출력일 수 있으며, **진행 상황**의 오류 설명과 실제 종료
상태를 함께 확인합니다. **계산 단계…**가 제공되는 계산에서는 수렴·거절 증분과
원 조건을 읽을 수 있습니다.

**입력 문서 열기**로 그 실행의 원 문서 또는 보존한 편집 사본을 엽니다.
물리 조건을 수정하고 해당 도구에서 명시적으로 새 계산을 실행하세요. 이전 실패 입력과
결과는 그대로 남습니다. Runner의 작업 선택이나 결과 읽기는 계산을 다시 실행하지 않습니다.

**실행 취소**는 누를 때 선택한 작업에 적용합니다. 이후 다른 작업을 선택해도 취소
대상은 바뀌지 않습니다. **취소 요청됨**은 아직 실제 종료를 확인하기 전의 상태입니다.
**취소 완료**는 실행 서비스가 종료를 확인한 상태입니다. **프로세스 종료 미확인**은
끝났다고 단정할 수 없는 상태입니다.

Runner 창을 닫아도 계산은 자동 취소되지 않습니다. 다시 열면 기존 실행 상태를
조회합니다. 닫기 전에 시작한 조회 응답은 다시 열린 창의 선택이나 결과를 바꾸지 않습니다.
새로 **결과 보기**를 눌러 저장 결과를 읽을 수 있습니다.

이력의 제외 표본은 곡선에서 빈 구간으로 표시합니다. 앞뒤 값을 이어 붙이거나 0으로
채우지 않으며, 원값과 유효성은 표에 남습니다. 유효하다고 기록된 값이 잘못되었거나
유효성 표시가 불완전하면 곡선을 그리지 않습니다. 곡선 열람은 실패 상태를 바꾸거나
제외 구간이 있는 이력을 피로 계산에 사용할 수 있다는 뜻이 아닙니다.

구조 동해석의 실제 restart 기능은 별도 구현 중입니다. 마지막 출력 시각이 있다는
이유만으로 계산을 이어갈 수 있는 저장점으로 표시하지 않습니다.
