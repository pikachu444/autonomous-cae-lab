# 시간 측정과 시험 곡선 비교

이 경로는 **Post에 저장한 시간 이력 또는 접촉 힘 이력**과 **Data에 저장한 시험 채널**을 비교합니다. 두 Post 시간 측정을 비교하거나, Data에서 가져온 두 시험 곡선을 같은 Post 문서에서 비교할 수도 있습니다. 새 해석·CAD·AI는 실행하지 않습니다.

## 먼저 준비할 자료

- ParaView에서 결과를 열고 실제 점을 선택하여 시간 이력을 측정합니다. 측정을 적용하고 Post 문서를 저장합니다.
- 시험 CSV는 독립 Data에서 열어 응답 열·성분·단위·위치와 가로축을 명시하고 가져오기 결과를 저장합니다. 원행 제외와 품질 표시를 여기서 지정할 수 있습니다.
- 수치가 같아도 X 힘과 Y 힘, 응력 XX와 YY, 크기와 한 성분은 같은 응답이 아닙니다. 같은 관측량과 기준계인지 확인합니다.

## 비교하기

1. Post의 **분석 추가 → 시간·시험 곡선 비교…**를 선택합니다. **저장 곡선 읽기**는 실제 저장된 위치와 열을 읽습니다.
2. **시험 Data 가져오기…**에서 저장 Data·결과·물리량을 선택합니다. 이 작업은 이미 저장된 채널의 복사본을 고정합니다. 새 가져오기 계산이나 물리 계산은 제출하지 않습니다. 취소하면 비교 초안을 바꾸지 않습니다.
3. **기준 곡선 A**, **비교 곡선 B**에서 위치·성분·축을 선택합니다. 같은 시간표에 여러 위치가 있으면 각각 별도 선택지로 표시됩니다. 여러 블록을 한 곡선으로 이어 붙이지 않습니다.
4. **물리량·가로축 확인…**에서 빠진 의미를 명시합니다. 이미 확인된 단위·측도·성분은 바꿀 수 없습니다. 과거 자료의 미확인 관측량은 사용자가 명시해야 차이를 계산합니다. 전체 벡터 없는 한 성분에 좌표 회전을 적용하지 않습니다.
5. **축 정렬·구간…**에서 공통 응답 단위, 축의 물리 의미, A/B 원점, B 원점 이동량을 정합니다. B 축은 먼저 A 축 단위로 변환한 후, **A 축 단위의 이동량**을 더합니다.
6. 정확히 저장된 표본끼리 대응하거나 **두 표본 사이 보간**을 명시적으로 선택합니다. 보간에는 최대 간격을 입력합니다. 시작/마지막 행으로 단조로운 가지를 선택할 수 있습니다. 화면의 행 번호는 1부터 시작하며 마지막 행을 포함합니다.
7. **미리보기 → 측정값 읽기 → 비교 곡선…**에서 원 A, 원 B, 공통 단위의 대응값과 차이를 읽습니다. 표와 그래프의 점을 선택하면 같은 원행을 확인할 수 있습니다. B를 보간한 행은 양쪽 원행·좌표·가중치를 함께 보존합니다.
8. 원하는 비교만 **적용**합니다. **편집 되돌리기**는 미리보기를 버리고 마지막 적용 설정으로 돌아갑니다. 적용 취소/다시 적용은 기존 Post 이력을 사용합니다.
9. **저장** 후 같은 Post 문서를 새 ParaView 프로세스에서 엽니다. 조회 범위에서 **적용 전 미리보기 값 읽기**를 끄고 저장된 비교를 읽습니다. 저장 결과를 읽는 동안 원 시험을 다시 가져오거나 새 해석을 실행하지 않습니다.

## 결과를 읽을 때

**원곡선**은 이 비교에서 변환하기 전의 저장 채널 값입니다. Data에서 이미 교정한 채널이면 교정값의 원 단위를 유지합니다. 센서 원 취득값, 교정식과 원행 품질은 고정한 Data 자료에 별도로 보존하며 교정을 두 번 적용하지 않습니다.

차이는 공통 단위에서 **B − A**입니다. 변화율은 **100 × (B − A) / |A|**이며 A=0이면 변화율만 미정입니다. 절대온도 °C/K는 수치 변환 후 차이를 계산할 수 있지만 변화율은 제공하지 않습니다. 온도차와 절대온도를 혼용하지 않습니다.

결측, 계산 제외, 품질 실패는 보간 끝점이 될 수 없습니다. 숨김은 계산 제외가 아닙니다. 숨긴 표본도 원행과 계산 포함 상태를 보존합니다. 원행 번호가 건너뛰었다는 이유만으로 간격을 추측하지 않으며 실제 저장된 구간과 제외행을 따릅니다. 반대로 결측 구간, 허용 간격보다 넓은 구간, 범위 밖으로는 선이나 보간값을 만들지 않습니다. ParaView의 보존 차트는 표본 마커를 사용하고 Qt 그래프는 유효한 연속 구간만 선으로 잇습니다.

중복 축이나 하중/제하의 비단조 이력이 있으면 비교할 원행 가지를 선택합니다. 자동 정렬·중복 평균·외삽은 하지 않습니다. 해당 대응이 불가능해도 원곡선은 미리보기에서 계속 볼 수 있고 이전 적용 결과는 유지됩니다.

변환 결과가 수치 범위를 넘으면 원값을 보존하고 그 대응값만 미정으로 표시합니다. 자료 가져오기는 표와 원행 파일을 완성한 뒤 등록하므로 실패한 중간 자료가 목록에 남지 않습니다.

원자료를 옮겼거나 일부 파일을 잃어버린 경우에는 기존 Post의 복구 열기를 사용합니다. 저장한 곡선값은 확인된 보존 파일에서 읽을 수 있습니다. 같은 바이트의 자료를 명시적으로 다시 연결해도 이전 결과를 자동 재계산하지 않으며, 새 비교는 다시 미리보기·적용합니다.

정적 하중 계수는 물리시간이 아닙니다. 액추에이터 변위를 시편 변형률로 환산하지 않습니다. 동일 차원의 단위 변환만 수행하고, 원점의 실제 의미는 사용자가 명시합니다.

## 공개 작은 예제와 실행 방법

다음 예제는 실제 Data CSV 가져오기를 수행하고, 해석 없이 만들어진 작은 공개 힘 필드를 준비합니다. **시험·해석의 물리적 타당성이나 공학 승인 예제가 아닙니다.** 새 빈 출력 디렉터리를 사용합니다.

프로젝트의 연구 Python:

~~~powershell
python -m examples.post_curves C:\cae-tests\curve-example
python -m pytest tests/test_post_curves.py tests/test_post_curve_snapshot.py tests/test_post_curve_editor.py tests/test_post_curve_recovery.py -q
~~~

설치된 ParaView 6.2의 Python으로 생성·저장:

~~~powershell
& "C:\Program Files\ParaView 6.2.0\bin\pvpython.exe" tests/check_post_curves_native.py --create C:\cae-tests\curve-example\input.json
~~~

별도 새 프로세스에서 읽기:

~~~powershell
& "C:\Program Files\ParaView 6.2.0\bin\pvpython.exe" tests/check_post_curves_native.py --reopen C:\cae-tests\curve-example\receipt.json
~~~

원자료 누락 시 보존 결과 읽기와 동일 바이트 위치 복구도 별도 프로세스로 확인할 수 있습니다. 공개 예제 사본에서만 실행합니다. 이 명령은 입력 sidecar 하나를 잠시 옮겼다가 종료 시 복구하며, 새 계산은 하지 않습니다.

~~~powershell
& "C:\Program Files\ParaView 6.2.0\bin\pvpython.exe" tests/check_post_curves_native.py --repair-retained C:\cae-tests\curve-example\receipt.json
~~~

실제 설치 경로에 맞춰 실행 파일 경로만 바꿉니다. examples.post_curves가 출력한 input.json에는 Data의 별도 store 경로가 있습니다. GUI에서 그 Data를 다시 선택하려면 같은 store의 서비스를 사용합니다.

첫 native 명령은 실제 PlotSelectionOverTime 측정 → 저장 Data 등록 입력 추가 → ms/s 및 kN/N 변환 → 명시한 원점 이동 → 보간 → 적용/취소/저장까지 진행합니다. 두 번째 명령은 보존된 값·원행·마스크·선택행만 재열며 다시 계산하지 않습니다.

## 구현 선택과 범위

| 항목 | 이번 연결 |
|---|---|
| 소유권 | 기존 Post Workspace의 comparison recipe v3, history, dependency/graph guards, Apply/Undo/Save 사용 |
| Data 전달 | 기존 Data 결과 참조의 입력·결과 hash를 검증하고 기존 inputs에 VTT와 정확한 원행 sidecar를 저장 |
| 새 서비스 접점 | post_curve_snapshot(reference, response) 한 메서드 및 HTTP 경로. 호출자가 행·파일 경로·대체 단위를 제출할 수 없음 |
| Native 접점 | 읽기 전용 post.curve_catalog capability. 기존 post.source_add에 서비스가 발급한 native_curve만 추가 허용 |
| Native 출력 | 기존 프로젝트 exports에 VTK binary table을 고정. 문자열 원행 식별과 NaN을 유지하며 거대한 표를 proxy Script/완료 응답에 넣지 않음 |
| 호환 | 기존 v1/v2 공간 비교, 원 measurement의 CSV 저장, Data/Numerical의 기존 비교 함수와 문서 저장을 변경하지 않음 |
| 관측량 | 기존 observable 표현과 원 성분·크기·차이 정의를 유지. 서로 다른 관측량은 차이만 차단 |
| 지원 축 | 실제 시간표의 축과 Data가 명시한 단일 축, 단위 변환·명시적 원점 이동·원행 구간 |
| 지원 대응 | A 원표본 기준 exact 또는 B의 인접 유효 두 표본 사이 bracket, 최대 간격·허용오차 명시 |
| 남은 제한 | 시간별 서로 다른 위치 추적, 자동 시간 동기화, 비단조 가지 자동 분할, 확률/오차대역 전파, 주파수/위상 비교, 없던 물리량·벡터 재구성은 제공하지 않음 |
| 크기 | 입력당 최대 20,000행/16 MiB, 결과 표는 페이지 단위로 읽기. 일부만 성공한 것처럼 잘라 저장하지 않음 |

작성 환경의 실행 서버가 연결되지 않아 위 Python/Qt/ParaView 검사는 **NOT_RUN**입니다. 소스 작성과 문자 수준 점검을 실행 통과로 표시하지 않습니다. 설치 환경에서의 실제 확인은 별도 통합 결과로 기록해야 합니다.
