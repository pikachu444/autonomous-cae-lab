# 새 세션 시작 안내

Codex 시작문은 [CODEX_START.txt](../CODEX_START.txt) 하나를 사용한다.
현재 목표·상태·다음 행동은 [CURRENT_STATE](../CURRENT_STATE.md), Pro/Codex 역할과
Pro 시작 방식은 [CODEX_WORKFLOW](CODEX_WORKFLOW.md)에 있다. 이 문서는 별도의 시작
명령이나 작업표를 소유하지 않는다.

예전의 전수 요구 감사·Phase 직렬 수행·고정 모델·주 담당 직접 구현 명령은 당시 기록이다.
[통합 전 원문](https://github.com/pikachu444/autonomous-cae-lab/blob/b3fa9188490ea42399974ae07c10e83521f14d1d/docs/NEXT_SESSION_PROMPT.md)은
보존되며 새 세션의 현재 배정을 덮어쓰지 않는다.
