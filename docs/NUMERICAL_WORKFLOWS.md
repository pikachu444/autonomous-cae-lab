# 수치 연구: 계획, 실제 결과, 다음 연구

정수·이산값·범주·고정·종속식은 [혼합 변수 편집](NUMERICAL_MIXED_GUI.md)의 순서로 설정합니다.

이 문서는 D6 첫 연결 소스 묶음의 사용법과 남은 범위를 설명합니다.
기준은 59a42f1 및 SPEC-NUMERICAL-002입니다. 작성 환경의 실행 서버가
연결되지 않아 이 묶음의 Python/Qt/Windows 실행은 **NOT_RUN**입니다.
아래 후속 교정의 검사는 제출한 실행 경로이며 작성자 실행이나 사용자 화면 수용이
아닙니다. 첫 게시본 3dd93ea는 Codex가 Windows에서 실행했습니다. 실제 FELUPE
학습 3점/검증 2점 → 저장 RBF → E=1100 예측 → 같은 점 실제 평가 예제가
완료됐고, 저장 결과의 Qt/HTTP 재열기는 새 작업을 만들지 않았습니다.
첫 8개 검사 중 7개 통과, 1100×780 차트 높이 검사는 실패했습니다.
아래 레이아웃 교정은 그 실패에 대한 후속 소스이며 Windows 재확인 전입니다.
기존 D5 결과를 재검증하거나 무효화하지 않습니다.

## 시작

기존 환경에서 Start-CAE-Lab.cmd -Tool numerical로 독립 창을 엽니다.
CAD나 Expert를 먼저 실행할 필요가 없습니다. 계산하려면 선택한 평가기의
필요 패키지만 있어야 합니다. SciPy는 기존 numerical extra,
FELUPE는 material extra, Sobol은 sensitivity의 SALib 1.5.2를 사용합니다.

**계획**에서 목적과 방법을 정하고 **모델 선택…**으로 저장한 Material,
PDE, Simulation 또는 Evaluation을 선택합니다. **변수 추가…**에는 그
평가기의 실제 선언이 표시됩니다. 이번에는 FELUPE의 현재 계수와 단위를
선택표에 연결했습니다. 표시되는 하한/상한은 편집할 탐색 범위이며
모든 조합의 물리 유효성을 보장하지 않습니다. 모델 법칙 검사는 유지됩니다.

독립 계획에서 모델 A 다음 B를 선택하면 **모델 열기**와 새 실행의 채택 검토는
B를 사용합니다. 같은 계수를 가진 다른 문서도 구별합니다. Expert/Study에서 만든
계획은 원래 대화/연구로 반환하면서 선택한 평가 모델을 별도로 보존합니다.
시험 프로토콜 선택을 취소하면 모델 참조를 포함한 초안 전체가 그대로입니다.
이전 실행의 후보를 선택할 때에는 현재 편집 중인 모델이 아니라 그 실행의
저장 모델을 채택 대상으로 사용합니다. 어떤 선택도 모델에 자동 적용하지 않습니다.

등록된 평가기가 없는 수학식을 임의로 실행하는 제품 기능은 추가하지 않았습니다.
검사의 algebra callable은 명시적 테스트 대역입니다. 독립 사용 예제는
제품에 등록된 실제 material.felupe를 사용합니다. Material은 이 예제의
선택 모델일 뿐 다른 연구의 선행조건이 아닙니다. 저장 결과의 회귀·RBF
분석은 그 결과만으로 시작할 수 있습니다.

새 모델의 응답은 먼저 **모델 평가**를 명시적으로 실행하고 저장한 뒤,
그 실제 응답의 단위·성분·위치·축약을 선택합니다. native Simulation
선택자는 기존 선언/위치 선택기를 재사용합니다. display array를
미래 평가기의 응답으로 추측하지 않습니다.

## 계획과 결과

- **계획:** 변수, 목표/제약 또는 판단 기준, 선택 자료, 해당 방법의 설정.
  지수 표기와 1e 같은 미완성 편집을 보존합니다. 잘못된 초안은
  저장하고 고칠 수 있지만 실행은 차단됩니다.
- **결과:** 실행 이력, 원 후보 행, 그래프, 선택한 결과로 만드는 다음 계획.
  행과 그래프점은 같은 candidate를 가리킵니다. 실패 행도 남습니다.
- **현재 계획 실행**은 현재 적용한 계획을 실행합니다. 이전 결과를 보는
  동안 수정한 계획과 이전 실행 입력은 서로 다릅니다. 이력의 관계 표시와
  기술 상세에서 제출 입력을 확인할 수 있습니다.
- 화면 재읽기나 탭 이동은 새 계산을 하지 않습니다. 계수 채택은 기존
  변경 검토/확인 명령으로만 실행됩니다. 예측은 실제 후보 채택 대상이 아닙니다.

새 계획은 계획 탭, 저장 실행이 있는 문서는 결과 탭으로 처음 열립니다.
이후 polling은 탭을 바꾸지 않습니다. 기존 단일 초안 버퍼를 공유합니다.
계획의 긴 입력은 그 탭 안에서 스크롤하며 결과 탭의 창 높이를 늘리지 않습니다.
결과는 짧은 실행 이력, 후보 표와 조절 가능한 큰 차트 영역을 사용합니다.
1100×780과 1440×900의 실제 창 크기·차트 최소 공간 검사는 유지했습니다.
값 없음은 —로, 숫자는 읽기 쉬운 자리수로 표시하지만 저장값과 편집 정밀도는
변경하지 않습니다. 정확한 값은 셀 상세에서 읽을 수 있습니다.

분포 관계·근거·응답 보존·2차 효과 등은 한국어 선택명으로 표시하고 기존
canonical itemData 값을 저장합니다. 같은 표시명을 가진 항목도
선택한 실제 항목을 유지하며 목표 축약/위치를 선택명에 표시합니다. 알 수 없는 기존 값과 미완성 숫자는 지우거나
정상값으로 바꾸지 않으며 저장한 뒤 고칠 수 있습니다.

표의 편집할 셀부터 여러 행·열의 값을 붙여넣을 수 있습니다. 탭은 열, 줄바꿈은
행으로 읽으며 숨겨진 내부 식별자 열은 건너뜁니다. 읽기 전용 셀을 포함하거나
표 범위를 벗어나면 전체 붙여넣기를 거절하고 기존 입력을 유지합니다.
Enter는 셀 편집을 확정하고 Esc는 그 셀의 미확정 편집을 취소합니다.
**되돌리기/다시 실행**은 먼저 이 창의 적용 전 편집에 작동합니다. 적용한
뒤에는 기존 문서의 Undo/Redo를 사용합니다. 다른 Plan이나 Material 창의
미확정 편집은 함께 확정하지 않습니다. 결과를 다시 읽어도 되돌린 편집의
다시 실행 기록은 남습니다.

## DOE와 회귀 영향도

1. 실험계획(DOE), 모델, 변수 범위, 표본 수/시드를 정합니다.
   **후보 직접 지정…**에서 실제 평가할 좌표를 추가·수정·삭제합니다.
2. 적용 → 현재 계획 실행 → 결과에서 행과 응답 곡선 확인 → 저장합니다.
3. 다음 작업의 **회귀 영향도 → 이 결과로 계획 만들기…**를 선택합니다.
4. 실제 응답/축약을 고르고 실행합니다. 표준화 회귀계수와
   rank/condition, 사용·제외 행 수를 읽습니다.

회귀 영향도를 Sobol 또는 인과 효과로 부르지 않습니다.
실패 행은 원 평가에 남고 회귀 제외 이유도 보존됩니다.

## Sobol

1. **영향도 표본**에서 순서가 있는 변수, 기본 표본 수, 시드, 2차 효과를 정합니다.
2. 실행하고 저장합니다. 이 단계는 모델 평가를 하지 않습니다.
3. 결과의 **Sobol 표본 평가**로 계획을 만듭니다. 실제 모델을 선택하고
   표본 전체 예산을 확인한 뒤 실행합니다.
4. 평가 결과를 저장하고 **Sobol 분석**으로 넘겨 실제 응답을 선택합니다.

기존 sample_sensitivity → DOE → sensitivity의 정확한 결과 참조를 사용합니다.
A/B/crossed 표본의 원 순서·변수 순서·ID·좌표를 유지합니다. 실패 행 삭제,
일반 LHS로 대체, 표시 정렬 후 분석은 허용하지 않습니다. S1/ST와 CI를 표시하고,
2차 지수에서 계산되지 않는 삼각 영역은 null로 저장합니다. 0이나 임의 대칭
값으로 채우지 않습니다. 표에는 원 순서의 A/B/변수별 crossed 역할과
분석의 1차/총효과/2차 효과 및 불확실도를 표시합니다. 변수 순서·단위·범위도
원 표본과 대조합니다. 다중 표본 수 수렴 비교 화면은 아직 남아 있습니다.

## UQ

**분포와 상관…**에서 각 변수의 분포와 파라미터를 정합니다.
독립/물리 정규 상관을 명시적으로 고르고 분포 근거와 자료 또는 가정을 적습니다.
응답의 한계와 관계는 **기준 추가…**로 선택합니다.

독립 uniform/normal/truncnorm/lognormal은 기존 엔진을 재사용합니다.
정규·로그정규 꼬리를 범위 안으로 자르지 않습니다. 평가 범위 밖 표본이면
범위를 고치거나 명시적으로 절단정규를 선택해야 합니다. 절단정규의 범위는
변수의 평가 bounds입니다.

상관 모드는 물리 정규 주변분포로 한정해 구현했습니다. 순서가 정확히
맞는 변수명, 대칭/대각 1/PSD 행렬을 확인하고 inverse-CDF 표본의
정규 score를 변환합니다. 희망 상관과 실제 표본 상관은 별도로 보존합니다.
변환 뒤에도 주변별 stratification이 그대로인 것을 보장하지 않습니다.
다른 결합분포/copula/공분산 단위 편집은 지원 범위로 주장하지 않습니다.
**상관 제거** 후 확인하면 독립 선언으로 돌아갑니다. 변수 목록이 저장 행렬과
다르면 그 행렬을 다른 변수명으로 재표기하지 않습니다. 기존 선언을 보존하고
새 행렬 전체를 입력하거나 명시적으로 제거할 때까지 실행을 차단합니다.

결과 CDF는 유효 응답에 조건부입니다. 전체 32개 중 8개가 실패하고
유효 24개 중 8개가 한계를 넘으면 전체 실패율은 8/32, 조건부 초과율은 8/24입니다.
표본 행은 모두 남습니다. 실패가 분포를 편향할 수 있으며 이를 성공확률로
자동 해석하지 않습니다.

## 대리모델

1. 실제 DOE 결과에서 **대리모델 학습**을 선택합니다.
2. 학습 자료와 다른 저장 검증 자료, 실제 응답/축약을 고릅니다.
   ID만 다른 동일 물리점을 독립 holdout으로 허용하지 않습니다.
3. 커널/평활화/차수와 필요하면 예측할 점을 정해 실행합니다.
4. 검증 관측/예측, RMSE, 실패 제외, 지원 범위 밖 상태를 읽고 저장합니다.
5. **저장 모델로 예측**은 보존된 계수로 새 점을 예측하는 별도 계획입니다.
6. 예측점 한 행 → **예측점 실제 평가** → 명시 확인으로 원 학습 당시
   평가기·설정·좌표의 새 DOE 계획을 만듭니다. 다시 **현재 계획 실행**해야
   실제 평가가 제출됩니다. holdout을 새 확인 실행으로 이름만 바꾸지 않습니다.

저장 모델은 기존 결과 안에 숫자 배열/설정/변수/응답/지원 bounds와 SciPy 버전을
보존합니다. pickle, 실행 코드, 별도 모델 저장소를 쓰지 않습니다.
SciPy 1.17.0 global RBF의 solved state를 검사한 뒤 기존 __setstate__로
복원합니다. 재열기나 새 점 예측에서 다시 학습하지 않습니다.
버전이 다르면 명시 재학습을 요구하며 자동으로 재학습하지 않습니다.
neighbors 모드는 새 점마다 local solve가 필요하므로 기존 명시 학습 결과는
읽되 '학습 없는 저장 모델'로 제공하지 않습니다.

실제 확인 계획은 원 training의 generic request 평가기 설정이 보존된 경우에
연결됩니다. 예전 unpinned job 또는 specialized draft만 있는 기록은
재사용 설정 부재를 명시합니다. 확인 계획의 실제 결과 한 행에서
**예측과 실제 비교…**를 누르면 저장 예측/실제 응답/차이를 같은 물리 좌표와
단위로 비교합니다. 이 읽기는 새 학습·예측·평가를 하지 않습니다.
실패한 실제 값은 사용 불가와 원래 이유로 남습니다. 저장·재열기 뒤에도
동일 예측 참조와 원 학습의 고정 평가 조건을 확인합니다. 선택한 실제 실행의
평가기/고정 설정/변수 순서·단위·변환/저장 모델이 다르면 같은 모델 확인 비교는
거절합니다. 현재 미적용 편집은 과거 실행의 비교 조건을 바꾸지 않습니다.
조건이 다른 실제 결과와 원 예측은 모두 남아 각 원 결과에서 읽을 수 있습니다.
이전 기록용 평가기 재선택은 잔여입니다.
두 원 결과는 보존됩니다.

## 다목적과 분야 연결

다목적 탐색에서 목표 방향, 주 목표, 보조 목표별 한계 조합, 총 평가 예산을
정합니다. 기존 epsilon/DE가 자식 검색 전체의 실제 평가수로 예산을 사용합니다.
전체 후보와 feasible 비지배 후보를 구분하고 자식별 상태·평가수를 보존합니다.
그림의 두 축만으로 Pareto를 재계산하지 않으며 전체 목적의 기존 archive를
사용합니다. 실패·제약 위반·검색용 penalty를 물리 응답으로 바꾸지 않습니다.
목표가 세 개 이상이면 결과 그래프의 **가로/세로** 선택에서 볼 목표를 바꿀 수
있습니다. 각 축은 계산 당시의 응답·단위·방향을 표시하며, 현재 계획 편집은
과거 결과의 축 의미를 바꾸지 않습니다. 축을 바꾼 뒤에도 점과 표는 같은
후보를 선택합니다. 두 축으로 보는 동안 비지배 여부는 모든 목표의 기존
판정을 유지합니다.
**주 목표**는 응답명/성분/단위/방향으로 고릅니다. 주 목표를 바꾸거나 목표를
제거하면 그대로 남은 보조 목표의 한계값만 보존합니다. 새 보조 목표의
한계값은 비어 있으며 사용자가 지정해야 합니다. 기존 숫자를 다른 목표에
순서대로 붙이지 않습니다. 고급 편집에서도 같은 연결을 지킵니다.

기존 Evaluation의 순차 분야 평가를 모델로 선택할 수 있으며 후보별 원 단계
결과 열기와 명시 채택/충돌 처리를 재사용합니다. 반복 결합 MDO,
통합 adjoint/gradient, design synchronization은 이 소스만으로 완료되지 않습니다.

## 작성 범위와 확인

주 변경은 RequestPlanWindow와 방법별 편집/그래프 모듈입니다. 공통 변경은
surrogate 입력의 닫힌 model 참조 대안, 기존 결과의 수치 artifact,

저장·재열기에도 유지됩니다. 기존 문서와 알 수 없는 편집값은 보존합니다.
JobManager/owner/저장소는 그대로입니다.

- 제출 검사: 저장 예측 → 새 확인 계획(이 단계 계산 0) → 명시 실제 평가 →
  저장/새 창 → 두 저장값 비교(이 단계 계산 0).

### 통합 실행 후 마지막 연결 교정

Codex가 f62c37b를 Windows에서 실행해 해당 두 파일의 17개 통과/1개 실패를
전달했습니다. 작은 창, 상관/한계값, 한국어 선택, 반환처, 저장 예측/실제 비교는
그 실행에서 통과했습니다. 남은 실패는 실제 FELUPE 후보의 채택 검토에
필요한 bind_inputs가 없었던 것입니다.

이번 후속은 FELUPE adapter의 순수 bind_inputs를 기존
evaluation_definition.bind_values의 Material 경로에 연결합니다.
계수명/유한값/재료 법칙을 기존 검증으로 확인하며 단위·시간·변형 이력과
다른 설정을 복사 보존합니다. 채택은 기존 domain_candidate/Material owner의
명시 확인·새 입력 개정·명령 영수증 경계를 그대로 사용합니다. 채택된
Material의 저장은 열린 원 도구의 **저장**으로 수행합니다. 계산은 추가하지
않습니다. 같은 표시명의 목표 선택과 방법별 모델 참조 복원도 이 후속에
포함됩니다. 이 마지막 후속의 작성자 Python/Qt 실행은 NOT_RUN입니다.

## UQ 분포와 원후보 구간 선택

저장된 UQ 계산을 선택한 뒤 **보기 → 분포와 구간…**을 열면 해당 실행의 응답별
히스토그램과 원후보 표를 함께 볼 수 있다. 응답의 단위와 명시된 축약을 유지하며,
평균·표준편차·분위수는 실행에 이미 보존된 값을 표시한다. 실패·예측·단위가 다른
표본을 유효 값으로 채우지 않는다. 통계는 성공한 평가에 조건부이다.

막대를 누르면 그 막대에 속한 원후보들이 선택된다. 마지막 막대는 우측 끝값을
포함하고 나머지 막대는 우측 경계를 제외한다. 숫자 구간의 **구간 선택** 또는
Enter는 양끝을 포함한다. 표에서 선택한 표본 수는 주황색으로 겹쳐 표시되어
막대 전체 표본 수와 구별된다. 이 창은 열린 실행의 복사본을 읽으며, 선택·응답
전환·재열기는 모델 평가나 새 job을 만들지 않는다.
