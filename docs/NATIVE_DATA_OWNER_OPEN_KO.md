# 같은 자료 문서 다시 열기

설치된 Data는 기존 LabPlot 작업면을 사용합니다. 같은 연구 연결에서 같은 자료 문서를
다시 열면 먼저 열린 창을 앞으로 가져옵니다. 문서 이름이 같아도 다른 보관소의 문서는
별도 창으로 열립니다. 창 전환은 자료 준비나 계산을 실행하지 않습니다.

1. 연결 창에서 저장한 자료 문서를 선택해 **열기**를 누릅니다.
2. 표의 행이나 채널을 선택하고 편집합니다. 같은 문서를 다시 열어도 현재 창의 선택과
   적용하지 않은 편집은 그 창에 남습니다.
3. 닫기에서 **취소**하면 기존 창을 계속 사용합니다. **저장하지 않음**을 선택해 닫은 뒤
   같은 문서를 열면 보존된 입력을 새 창에서 읽습니다. 저장할 때는 기존 **자료 저장**을
   사용합니다.

Data 안에서는 **자료 > 자료 문서 열기…**로 다른 자료를 고릅니다. 그 자료가 이미 다른
창에 열려 있으면 해당 창으로 이동하며, 현재 자료의 선택과 적용하지 않은 편집은
현재 창에 남습니다. **저장된 작업 열기…**로 연결된 `.lml` 파일을 여는 경우도 같습니다.
열기를 취소하거나 Core 연결 대상 확인에 실패하면 현재 자료를 계속 편집할 수 있습니다.

**새 작업**이나 프로젝트 닫기를 확정하면 그 프로젝트의 자료 창 연결도 끝납니다.
이후 같은 자료를 다시 선택하면 저장된 입력을 새 창에서 읽습니다. 닫기 확인에서
**취소**하면 현재 프로젝트와 편집을 유지합니다.

원래 창이 열리는 중이거나 응답하지 않으면 임의의 두 번째 창을 만들지 않습니다.
기존 창의 상태를 확인하고 같은 문서를 다시 선택하세요. 다른 세션의 창이 응답해도
현재 문서의 창으로 인정하지 않습니다.

Python 호환 Data 창은 `python -m apps.research.desktop data --pyside`로 명시해서 엽니다.
기본 Data 실행과 구별하며 같은 자료의 기본 편집 창이 이미 열려 있다면 그 기존 창을
활성화합니다. 편집기 종류를 바꾸려면 현재 창을 닫고 다시 여세요. 명시 처리·취득 도구는
같은 자료의 별도 보조 창입니다. 선택한 작업에 필요하지 않은 CAD나 AI 프로그램을 먼저
열 필요는 없습니다.

개발 확인은 `tests/check_native_data_owner_windows.py`에서 기존 저장 자료의 사본으로
실제 설치 실행 파일, HTTP 문서 읽기와 로컬 활성화를 사용합니다. 수치 계산·자료 재수입·
provider 호출을 금지한 상태에서 같은 문서 재사용, 세션 거절, 닫기 취소, 다른 보관소와
닫은 뒤 재열기를 확인합니다. 창 캡처와 지정한 창의 닫기 이벤트 검사는 전체 OS 입력의
사용성 검증을 뜻하지 않습니다. 실행 로그와 실패 자료는 별도 인수 기록에 보존합니다.

`tests/check_native_data_owner_lifecycle_windows.py`는 현재 편집 중인 자료에서 이미 열린
다른 자료로 이동하는 경우와 **새 작업**의 취소·확정, 연결된 `.lml` 파일의 새 창 시작을
추가 확인합니다. 저장된 파일은 내용과 연결 정보를 바꾸지 않고 재사용합니다.
