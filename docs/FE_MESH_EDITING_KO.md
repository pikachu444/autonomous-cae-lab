# 부품별 메시 설정 바꾸기

**해석 설정 → 메시**에서 부품의 메시를 선택하고 최소·최대 요소 크기와 차수·차원을
바꿉니다. **메시 설정 적용**은 선택한 메시의 설정만 바꿉니다.
실제 메시를 새로 만들려면 **메시 생성**을 누릅니다.

국부 크기는 **영역과 조건**에서 현재 부품의 영역을 만든 뒤, 메시 탭에서 그 영역과
국부 크기를 선택한 뒤 **국부 크기 적용**으로 반영합니다. 전역 설정과 국부 크기는
별도로 적용합니다. 전역 설정을 적용해도 국부 입력을 적용한 것으로 처리하지 않습니다.

기존 설정을 고치려면 **국부 크기 설정**에서 해당 항목을 선택합니다. 저장된 영역과
native 메시의 실제 크기를 읽어 표시합니다. 적용 영역이 사라졌거나 저장된 대상과
현재 형상·면이 다르면 자동 연결하지 않습니다. 영역을 다시 선택한 뒤 크기를
명시적으로 적용하세요. 크기만 고쳐서는 대상 불일치를 해소하지 않습니다.

국부 입력을 바꾼 채 다른 국부 설정을 선택하면 적용·버리기·취소를 선택합니다.
이 선택은 국부 설정만 처리하며 미적용 전역 설정은 유지합니다. 응답을 기다리는 동안
국부 입력을 다시 바꾸면 이전 설정에 머물며 새 입력을 보존합니다. **새 국부 크기 설정**은
영역을 선택하지 않은 1 mm 입력으로 시작합니다.

아직 적용하지 않은 설정이 있을 때 메시 선택 목록에서 다른 부품을 고르면 다음 선택지가
나옵니다.

- **적용 후 선택:** 현재 부품에 전역·국부 설정을 순서대로 적용한 뒤 다른 메시를 엽니다.
- **버리고 선택:** 적용하지 않은 입력을 버리고 선택한 부품의 메시를 엽니다.
- **취소:** 현재 메시와 입력을 유지합니다. Esc도 취소입니다.

다른 부품의 메시를 열면 국부 적용 영역을 다시 선택합니다. 이전 부품의 국부 크기 입력은
새 부품으로 옮겨지지 않습니다. 처리 중에는 다른 메시를 선택할 수 없습니다.
적용이 실패하거나 응답을 기다리는 동안 입력을 다시 바꾸면 현재 메시와 새 입력을
유지합니다. 새 입력을 확인하고 다시 적용하세요.

**메시 생성**에도 미적용 설정이 있으면 적용·버리기·취소를 선택합니다.
적용을 고르면 설정 적용이 끝난 뒤 메시를 생성합니다. 기다리는 중 새 입력이 생기거나
해석 설정 패널을 닫으면 이후의 자동 생성·선택 전환을 중단합니다.
이미 접수된 명령을 취소하는 동작과 패널을 닫는 동작은 서로 다릅니다.

해석 설정 패널만 닫았다가 다시 열면 같은 문서의 입력을 유지합니다. 문서나 앱을
닫은 뒤 새로 여는 경우의 미적용 메시 입력 저장은 아직 공통 저장 관문에 연결되지
않았습니다. 현재 문서에 반영할 설정은 적용한 뒤 기존 프로젝트 저장을 사용하세요.

메시 생성 중에는 기존 취소 기능을 사용합니다. 생성 실패·취소나 오래된 형상의 메시를
정상 메시로 표시하지 않습니다. 설정 적용·메시 생성 성공은 공학적 품질 승인과
별개입니다.
