# 사용자 관점의 인수 조건

| 경로 | 완료 확인 |
|---|---|
| 독립 진입 | 기존 평가기/저장 결과에서 연구 시작, 다른 앱의 선행 진입 불필요 |
| 계획 편집 | 방법에 맞는 입력/단위/범위, 미완성 입력과 Undo/Save/reopen 보존 |
| DOE/영향도 | 실제 행/점/원 평가 동일, 일반 DOE와 Sobol 설계 구별 |
| 최적화/역해석 | 목적·제약·관측·마스크 해석, 실패와 penalty 구별, 정확한 후보 채택 |
| UQ | 분포 가정/출처와 전체·실패 수, 조건부 통계/초과확률, 표본 선택 연동 |
| 대리모델 | 학습/holdout 중복 방지, 예측/실제 계산 구분, 저장 모델과 명시 확인 평가 |
| 다목적 | feasible Pareto와 실패/제약위반 구별, 총 예산과 정확한 선택·도구 연결 |
| 취소/재개 | 실제 중지 상태와 새 실행 구별, 이전 결과와 실패 보존 |
| 화면 | 작은/넓은 실제 Qt 창에서 표·그래프 중심, 한글·단위·선택·오류 읽기 가능 |

작은 기존 실제 평가기를 사용한 실행과 관련 단위 검사로 확인한다. 대역만 실행한
경로는 표시한다. 수치 참조 비교는 관련 기능의 의미에 맞게 제한하며 화면 검사 통과를
공학 승인으로 확대하지 않는다. FN-20~24 미지원 요구와 전체 D6 잔여를 따로 보고한다.
