# 사용자 관점의 인수 조건

| 경로 | 완료 확인 |
|---|---|
| 독립 진입 | 기존 평가기/저장 결과에서 연구 시작, 다른 앱의 선행 진입 불필요 |
| 계획 편집 | 방법에 맞는 입력/단위/범위, 미완성 입력과 Undo/Save/reopen 보존 |
| DOE/영향도 | 실제 행/점/원 평가 동일, 일반 DOE와 Sobol 설계 구별 |
| 최적화/역해석 | 목적·제약·관측·마스크 해석, 실패와 penalty 구별, 정확한 후보 채택 |
| UQ | 분포 가정/출처와 전체·실패 수, 조건부 통계/초과확률, 표본 선택 연동 |
| 대리모델 | 학습/holdout 중복 방지, 예측/실제 계산 구분, 저장 모델과 명시 확인 평가 |
| 다목적 | feasible Pareto와 실패/제약위반 구별, 총 예산과 정확한 선택·도구 연결 |
| 취소/재개 | 실제 중지 상태와 새 실행 구별, 이전 결과와 실패 보존 |
| 화면 | 작은/넓은 실제 Qt 창에서 표·그래프 중심, 한글·단위·선택·오류 읽기 가능 |

작은 기존 실제 평가기를 사용한 실행과 관련 단위 검사로 확인한다. 대역만 실행한
경로는 표시한다. 수치 참조 비교는 관련 기능의 의미에 맞게 제한하며 화면 검사 통과를
공학 승인으로 확대하지 않는다. FN-20~24 미지원 요구와 전체 D6 잔여를 따로 보고한다.

## 요구와 인수 경로 연결

- AC-NUMERICAL-002-001: REQ-NUMERICAL-002-001 — 독립 진입과 방법별 계획 편집.
- AC-NUMERICAL-002-002: REQ-NUMERICAL-002-002 — 명시 실행, 정확한 단위/예산 및 오류 위치.
- AC-NUMERICAL-002-003: REQ-NUMERICAL-002-003 — 같은 행/점/원 평가 조회와 계산 없는 재열기.
- AC-NUMERICAL-002-004: REQ-NUMERICAL-002-004 — UQ 실패 수·조건부 통계와 가정.
- AC-NUMERICAL-002-005: REQ-NUMERICAL-002-005 — 일반 영향도와 Sobol 설계 구별.
- AC-NUMERICAL-002-006: REQ-NUMERICAL-002-006 — 저장 모델·독립 holdout·명시 확인 평가.
- AC-NUMERICAL-002-007: REQ-NUMERICAL-002-007 — 실제 목적/제약/실패 및 정확한 후보 채택.
- AC-NUMERICAL-002-008: REQ-NUMERICAL-002-008 — 취소·지원 재개·새 실행 구별.
- AC-NUMERICAL-002-009: REQ-NUMERICAL-002-009 — 기존 무료 실행 경로와 방법별 지원 상태.

## 구현 확인 범위 — 2026-10-16

`de7de4e`의 통합은 AC-004의 결합분포·전체/유효/실패 분모, AC-005의 같은 실제 평가
조건을 보존한 Sobol N/2N 비교, AC-006의 국소 RBF 저장·명시 새 점 예측·저장 모델
추천 후 실제 한 점 확인을 포함한다. 기존 SciPy·SALib·차분 진화·문서 소유자와 실행기를
재사용했다. 실제 Windows 대수 계산·Qt 입력/취소/선택·두 별도 프로세스의 이동 후
재열기를 확인했고 독립 Astra 통합 검토를 마쳤다. 실제 예측을 계산값으로 채택하지 않는다.

사용 순서와 실제 화면은 [수치 확장 안내](../../../docs/NUMERICAL_EXTENSIONS_KO.md),
원 실행·미확인 경계는 CURRENT_STATE가 연결하는 Numerical 인도 기록을 따른다.
전체 다목적·MDO·미분·물리 평가기 조합 또는 공학적 자격 완료를 뜻하지 않는다.
