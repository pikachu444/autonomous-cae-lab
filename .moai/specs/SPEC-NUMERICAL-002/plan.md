# 구현 순서와 재사용

1. FN-20~24의 현재 코드를 대조하고 지원/미지원과 실제 누락을 구분한다. 기존
   RequestPlanWindow, NumericalDocuments, numerical/research_operations의 엔진을 재사용한다.
2. 방법별 설정과 실제 실행·후보 표/그래프·상태를 한 사용자 흐름으로 연결한다.
   현재 UQ/대리모델/민감도/다목적의 고급 JSON 편집 의존을 먼저 해소하되 기존 DOE,
   최적화, 역해석과 D5 재료 피팅을 퇴행시키지 않는다.
3. 같은 결과의 원 도구 열기/명시 채택/Study 연결과 저장·재열기를 완결한다.
4. 기존 요구의 상관·이산·gradient·복수 분야 확장을 삭제하지 않는다. 제공되는
   adapter/engine의 실제 경로에 연결하고 구현되지 않은 항목은 이유와 다음 개발을 남긴다.

한 방법의 입력 폼만 배달하지 않고 사용 가능한 작업 묶음으로 인도한다. 관련 동작만
작게 실행하고 보존 자료를 활용한다. 과거 CAD/solver campaign 전체의 반복은 하지 않는다.
원격에서 실행하지 못한 검사는 NOT_RUN으로 전달하고 Codex가 Windows에서 확인한다.
