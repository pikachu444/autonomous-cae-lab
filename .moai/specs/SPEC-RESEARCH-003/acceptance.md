현재 지원 범위는 구현표와 구분해 표시한다. 미지원 일반식·사용자 법칙·다른 mesh
mapping은 삭제하지 않으며 실제 adapter가 없으면 해당 항목은 미완료다.

개발 중에는 변경된 편집/저장/오류 처리와 선택 결과의 연결을 작은 Qt/owner 검사로
확인한다. 실제 법칙·PDE·장 전달을 새로 지원한 경우에만 해당 최소 수치 기준을 실행한다.
기존 열→구조는 Kelvin, metre/P1, 동일 mesh, 구조 소유 Tref와 자유 팽창 기준을
재사용한다. 온도차를 두 번 적용하지 않는다. 접선 비교는 같은 초기 상태로 복원한
독립 perturbation과 정의가 같은 성분만 비교한다. 오래된 전체 solver campaign은
이 화면 작업의 선행조건이 아니다.

각 도구에서 시작해 다른 도구로 넘어갔다가 저장한 같은 결과를 다시 여는 경로를
확인한다. 실패/미수렴 결과를 성공으로 바꾸지 않고 실제 계산과 시험 대역을 구별한다.
작은 창과 넓은 창의 실제 Qt 렌더를 읽으며 OS 입력 확인의 한계는 별도로 기록한다.
