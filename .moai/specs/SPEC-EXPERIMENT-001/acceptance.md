## 개발 중 작은 확인

- AC-EXPERIMENT-001-01 (REQ-EXPERIMENT-001-001/002/008): 합성 공개 전압 채널과
  명시한 선형 교정 `y = a*x+b`에서 a의 출력/입력 단위와 b의 출력 단위가 맞는지
  독립 계산으로 대조한다. 같은 원행의 처리 전후 값, 범위 밖/포화 마스크, 관측 시각,
  교정 원본 참조를 저장·재열기한다. 알려지지 않은 불확실성에 0을 자동 입력하지 않는다.
  새 교정 저장 후 이전 비교가 옛 교정을 유지하고 영향받은 계획을 구별하는지 확인한다.
  2 mV와 0.002 V의 물리적으로 같은 입력에 계수·영점 단위를 맞춰 같은 결과를 얻고,
  교정식 범위와 센서 포화의 별도 사유가 유지되는지 확인한다. 제공 불확실성의 종류·
  단위·포함인자·상관 정보는 저장되고 미제공 부분을 가정으로 채우지 않는다.
- AC-EXPERIMENT-001-02 (REQ-EXPERIMENT-001-003): 같은 결과의 시각·게이지 두 위치와
  방향을 선택하여 파일 측정과 비교한다. 길이/힘/변형률 단위와 시간 오프셋을 보존하고,
  actuator 변위를 specimen strain으로 암묵 변환하거나 없는 orientation을 가정하지
  않는다. 교정 원본이 없으면 원자료는 읽히고 종속 변환만 명확한 이유로 제한된다.
- AC-EXPERIMENT-001-03 (REQ-EXPERIMENT-001-004): 준비한 두 합성 문제에서 식별 가능한
  경우와 계수 조합만 정해지는 경우를 구분한다. 진단 방법·스케일·사용한 응답과 범위를
  명시한다. 고정 계수는 식별 성공으로 세지 않는다. 결과 선택→다음 시험 기록→저장→
  재열기가 숨은 재계산 없이 같은 결과와 연결된다. 실제 시험의 타당성은 별도다.
  fit/holdout의 원본 행 겹침 차단을 유지하고 작은 잔차만으로 식별 성공을 표시하지 않는다.
- AC-EXPERIMENT-001-04 (REQ-EXPERIMENT-001-005/008): Study 없는 독립 결과와 문헌만
  있는 Study 각각에서 보고서를 만들고 섹션 포함·정렬·설명 편집·Undo·저장 후 재열기한다.
  표시한 field/time/row와 출력의 값·단위·그림이 같고 페이지의 원자료 열기가 해당
  선택을 연다. PDF/Markdown 내보내기가 solver/provider를 호출하지 않는다.
  원 창에서 시각을 바꿔도 보고서에 적용한 frame은 바뀌지 않는다. 없는 .03 frame을
  인접 .02/.04로 대체하지 않는다. 새 Study 적용의 편집 섹션 교체는 Cancel/Undo로 복구된다.
- AC-EXPERIMENT-001-05 (REQ-EXPERIMENT-001-006): 누락 원자료, 사용자가 취소한
  내보내기, 쓰기 실패에서 초안과 이전 출력이 보존된다. 실패값·UNKNOWN·미승인 상태가
  성공으로 바뀌지 않는다. 다른 새 결과로 자동 대체하지 않는다. 현재 글꼴에서 한글,
  긴 표·그림·페이지 잘림을 확인한다.
- AC-EXPERIMENT-001-06 (REQ-EXPERIMENT-001-007): 장비 없이 채널 설정과 기존 파일을
  열고, 불완전 수치 초안을 저장·고친 뒤 재열기한다. 요청 sampling 값으로 가짜 live
  sample을 생성하지 않는다. 장비 연결/종료 미확인은 계산 Job의 완료와 구별한다.

## 기능 통합 뒤 확인

실제 Windows에서 Data→Post 비교→Numerical→Study→보고서의 동일 선택을 한 번
연결한다. 독립 진입과 저장·재열기도 확인한다. 이미 변하지 않은 솔버·메시 검증은
다시 실행하지 않는다. 새 물리 계산 없이 보관된 결과와 작은 합성 자료로 연결을
확인할 수 있는 부분은 그렇게 수행하고 계산 정확성과 구분해 기록한다.

실물 장비 인수는 모델·프로토콜·교정·권한·허용 동작과 물리 종료 확인 조건이 제공된
후에만 수행한다. 그 전 상태는 NOT_RUN이며 파일 경로 확인으로 대체하지 않는다.
화면의 offscreen 렌더와 실제 OS 입력, 소프트웨어 동작과 공학적 판단을 따로 보고한다.
