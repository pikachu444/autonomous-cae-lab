# 작업별 완료 조건

| 기존 작업 | 사용자가 끝낼 일 | 관련 요구 |
|---|---|---|
| FN-16-01 | 자기 모델의 단위·초기 자세·속도 모드·접촉·시간/출력 제어를 편집하고 지원 범위에 맞는 native 입력을 만들며 저장/재열기 | 001, 002, 007 |
| FN-16-02 | 실제 충격 계산의 시각·힘·가속도·질량·에너지와 실패 위치를 읽고 같은 결과를 Post/Study에 전달 | 003, 007 |
| FN-17-01 | 지원 계면 법칙과 벌크 반응을 구분해 편집·실행하고 opening/slip/damage·재닫힘·에너지 결과를 원 mesh와 함께 비교 | 004, 005, 007 |
| FN-17-02 | 지원 cyclic law와 시험 범위에 따라 누적손상/수명을 계산하거나 없는 조건을 UNKNOWN으로 남기며 한 cycle과 수명을 구별 | 006, 007 |

개발 중에는 변경한 입력 모드, 단위, 미지원 card 차단, 저장·재열기와 정확한 결과 연결을
집중 확인한다. 실제 해석을 추가한 경우에만 해당 운동/충돌 또는 법칙의 독립 기준을 고른다.
메시·시간 간격 민감도, 손상 에너지와 물리 시험 수용은 필요한 자료·구현이 준비된 뒤
수행하며 관련 요구에서 삭제하지 않는다. 기존 실패와 수치 허용치를 바꾸지 않는다.

전체 D8 또는 물리적 제품 수용을 판정하려면 네 작업의 실제 구현과 조건을 각각 확인해야
한다. 강체 예제, 폼, 대역 결과 또는 문서의 존재만으로 완료 표시하지 않는다.
