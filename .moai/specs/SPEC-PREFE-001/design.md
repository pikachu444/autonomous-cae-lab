# 화면과 공통 연결

제품 화면을 새 웹 폼으로 만들지 않는다. FreeCAD native 트리/3D/Tasks와 기존
Lab 도킹 패널, ParaView와 독립 Qt Runner/Simulation을 재사용한다.

| 작업 | 화면의 중심 | 사용자가 다음 행동을 정하는 표시 |
|---|---|---|
| CAD 변수 | native 모델 트리·선택 치수와 변수 표 | 현재값/단위, 종속/누락 구분, 대상 다시 지정. 내부 ID는 상세에서만 |
| 조립 | native3D와 관절·구동 표, 경로 그래프 | 설계/미리보기 자세 구분, 적용/복원, 오류 관절 선택, 같은 프레임 표/곡선 연결 |
| FE 표현 | 선택 영역과 표현별 속성 Tasks | solid/shell/beam에 필요한 값만 표시. 다중선택은 추가/제거, 단위는 값 옆 |
| 메시 | 3D불량요소와 지표 분포/국부크기 | 실제 선택요소, 검사 범위, 이전/새 메시 비교와 명시 적용 |
| 접촉 | A/B면 강조와 법칙별 설정 | 면 역할·법선/거리, 지원 이유, 바뀐 형상 수리, 단계표와 쌍 선택 |
| 비선형/Runner | 단계·곡선, 진행/증분, 선택 시도 | 시간과 하중계수 구분, 실패한 단계로 이동, 원입력/부분결과 열기 |

주기 경계는 접촉 법칙 선택에 섞지 않고 별도 경계조건으로 제공한다. 원래 FN-14의
잔여표에 함께 있었더라도 물리 의미를 구분하며 추적 ID만 유지한다.
물리 입력은 Domain, 공통 문서/명령/결과는 Core, native card·파일은 Adapter가 소유한다.
M1/M2, E1/E2/E3, N3/C5/E6의 공유 입력형식은 두 작성자가 동시에 고치지 않는다.
필드가 없다는 이유로 임의 기본값을 solver에 넣지 않는다. 불완전 값은 초안에 남기고
사용자가 그 위치에서 수정할 수 있게 한다.
