# 무엇이 되어야 작업을 닫는가

각 AC는 spec.md의 같은 번호와 대응한다. Given/When/Then은 테스트 파일 개수나
버튼 존재가 아니라 사용자가 얻는 결과다. 신규 물리 정확성은 기존 reference 허용치를
유지하여 별도로 확인한다. CI 성공만으로 공학적 승인이라고 하지 않는다.

| AC | Given: 시작 자료 | When: 사용자가 하는 일 | Then: 반드시 남아야 하는 결과·실패 복구 |
|---|---|---|---|
| AC-01 | fixture 외 native CAD 두 모델과 등록 치수 | 치수 변경·구속 순서 변경·대상 삭제 후 다시 지정, 저장 후 새 창 열기 | 동일 의미의 살아있는 대상은 유지, 삭제/모호한 대상은 자동 추정 안 함. 복구 취소는 기존 등록 유지, 적용 후 실제 치수 재편집 가능. imported BRep에 없는 스케치를 만들어 표시하지 않음 |

| AC-09 | C1–C6의 실제 지원 모델 및 누락/모호한 대상, C3의 비순환 A→B→C와 순환 조정 사례 | 면/법칙/단계/변환·조정순서를 편집·적용→입력준비→저장/재열기 | 각 plan행의 법칙·영역·단계·경계식과 연쇄조정의 실제 초기좌표가 입력에 대응. 지원 대상으로 명시한 solver/version/element/law 조합이 미지원이면 배정은 미완료. 범위 밖 조합은 원요구와 잔여 ID로 추적. 미지원 순환조정은 명시 거절, 법칙 바꾸기/취소는 이전 초안 보존 |

| AC-11 | 접촉면이 분할/삭제/법선 변경된 저장 모델 | 옛/새 면 비교→일대다 미리보기→취소/적용→재메시 | 취소는 기존 선언 보존, 적용만 새면 연결. old mesh는 계속오래됨으로 표시. 이전 계산은 원면/원결과로 열리고 새모델 결과처럼 표시되지 않음 |
| AC-12 | NS1재료 곡선, NS2초기조건·감쇠, N3정적→동적 단계 | 값/단계 순서·비선형 허용오차·line search/안정화 선택→저장→실패조건 열어 수정 | curve 정의/단위/시간 의미·상태전달과 지원 수치 제어/안정화 에너지 요청을 실제 입력에 보존. 수렴기준 변경은 새입력, 옛 실패값·기준 보존. 지원되지않는 혼합순서는 실행차단 |

## 22개 개발 묶음별 직접 확인할 사례

아래 수치는 공개 시험 모델을 만들기 위한 입력 예시다. 실제 제품의 재료값이나
공학적 허용치가 아니다. 입력값·대상·단위·저장 내용 비교와 물리 정확성 비교를
구분한다. 물리 응답을 비교할 때는 기존 기준 문제의 원래 허용치를 사용하고,
근거가 없는 허용치를 새로 정해 통과시키지 않는다.

모든 행은 정상 작업뿐 아니라 **수정 후 재실행, 취소, 저장 후 새 창에서 재열기**까지
묶는다. 실행하지 않고 보존 결과를 다시 볼 수 있어야 한다. 이번에 지원할 솔버·버전·
요소·법칙, 시험 파일, 비교할 출력과 기준은 배정 전에 plan의 착수 카드에 확정한다.
무료 실행 경로가 미확정인 행은 조사 결과와 선택을 먼저 남긴 뒤 구현을 배정한다.

| 묶음 | 사용자가 따라 할 시험 | 합격 결과와 반드시 확인할 실패 |
|---|---|---|
| M1 종속 구동 | 기준을 90도/초, 종속을 2mm/도로 설정한 뒤 기준을 45도/초로 변경 | 끝 자세가 180mm에서 90mm로 바뀜. **시간별 경로는 별도 조건**으로, native frame의 실제 시각과 짝지은 0·0.5·1초 값을 비교. 끝 자세만 맞고 시간표가 어긋나면 경로 부분은 미완료. 순환·단위 불일치·한계 초과는 해당 행에서 수정 |
| M2 중첩 조립 | 두 단계 조립에 같은 원부품 A/B를 놓고 A만 구동·추적. 강체/가동 하위 조립을 각각 열기 | A의 선택 경로와 움직임이 대응하고 B 및 원부품 배치는 불변. 강체 내부는 독립 구동되지 않음. A 삭제 후 재열면 다른 부품으로 자동 연결하지 않고 재지정·취소 가능 |
| M3 닫힌 기구 | 공개 4절 링크의 유효 구동, 중복 구동, 도달 불가능 자세를 차례로 계산 | 유효 사례는 기존 native 기준 자세/경로와 대조. 실패 사례는 문제 관절과 마지막 정상 결과를 표시하며 실패 구간을 정상 곡선으로 잇지 않음 |
| M4 해석 후보 | 조립의 한 자세를 선택해 별도 후보를 만들고 메시·조건 지정 후 재열기 | 후보의 부품 배치와 조건 대상이 선택 인스턴스와 일치. 원조립 불변. 조립의 고정 부품을 FEM 고정조건으로 임의 변환하지 않음. 후보 생성 실패 시 원조립 계속 사용 |
| E1 셸 | 공개 평판에 두께 2mm, 법선, 재료·압력을 지정. 두께를 3mm 및 0mm로 변경 | 2/3mm가 native 셸 입력에 각각 반영되고 상·하면 결과 위치 구분. 0mm는 입력 행에서 실행 차단하되 초안 저장 가능. 방향 변경 뒤 하중 방향도 확인 |
| E2 빔 | 직사각 단면 10×20mm와 국부축을 지정한 보에 끝 힘/모멘트 적용, 축 회전 | 단면·국부축·힘/모멘트의 native 입력과 결과 성분이 대응. 잘못된 단면과 축은 수정 위치 표시. 전역/국부 성분을 섞지 않음 |
| E3 적층 | 서로 다른 재료의 0/90도 두 층을 만들고 순서 변경→Undo→저장 | 층별 두께·각도·순서와 총두께가 native 입력 및 결과 층 번호와 대응. 누락 재료/0두께 층 차단. 균질 셸로 바꿔 실행하지 않음 |
| E4 장·초기조건 | 같은 면에 총힘과 압력을 각각 지정하고 단위를 변환. 온도/초기상태를 별도 영역에 지정 | 힘과 면적당 힘이 구별되고 단위 변환 전후 물리량이 같음. 적용 영역/단계가 실제 입력과 일치. 모순 조건을 몰래 삭제하지 않고 수정 위치 표시 |
| E5 연결요소 | 두 점 사이 병진 스프링과 회전 스프링을 각각 지정해 상대 변위/회전과 힘/모멘트 읽기 | 병진·회전 계수 단위와 축이 구별됨. 첫 선형 스프링 경로는 F=kΔx 또는 M=kθ의 단위 변환까지 대조. 같은 점 두 번 선택/0길이 축은 명시 수정 |
| E6 체결 하중 | 조임→유지→외력 세 단계를 만들고 조임 방식·축을 바꿔 저장 | 각 단계 native 제어와 축력/반력이 대응. 유지 단계가 초기화되지 않음. 중복 절단면/누락 축은 실행 차단. 토크만 입력했다고 임의 조임력 생성 금지 |
| C1 비관통 | 서로 떨어진 두 면을 접근·접촉·분리하고 마찰 없음/Coulomb를 선택 | 선택 법칙의 실제 native 입력과 열린/접촉 상태를 읽음. 미출력을 압력 0으로 표시하지 않음. 지원하지 않는 조합은 입력 보존·실행 차단이며 이 묶음 완료로 세지 않음 |
| C2 응집 | 공개 계면을 인장·분리·압축 재접촉시키고 강도/파괴 에너지를 변경 | 법칙에 맞는 손상/분리/재접촉 결과와 단위를 연결. 실제 사용하는 표면 방식/계면요소 방식 명시. 없는 채널은 없다고 표시하며 임의 보간한 손상률로 대체 금지 |
| C3 접합 조정 | 곡면의 내부/모서리/복수 후보와 A→B→C 연쇄를 미리보고 적용 | 예상 이동 절점·이동량과 solver 초기좌표가 대응. 선행 조정이 후행 대상에 반영. 순환/모호한 후보는 이유 표시·수정 가능. 취소 및 실행 실패 시 원 CAD/메시 불변 |
| C4 미끄럼·법선 | A/B 교환, 법선 확인, 작은/큰 미끄럼 방식을 변경 후 동일 결과 선택 | 실제 native formulation이 메뉴와 대응. 부호 정의와 면 소속을 화면에 표시. 단순 화살표 변경을 solver 법선 변경으로 표시하지 않음 |
| C5 활성·해제 | 세 단계 중 둘째에서 접촉 활성, 셋째에서 지원하는 접합 해제를 지정 | 단계 입력과 상태 전환이 대응. 해제를 재접합 또는 원형상 복원으로 바꾸지 않음. 미지원 해제는 해당 단계에서 차단하며 저장한 다른 단계 보존 |
| C6 주기 경계 | 이동 주기 면 또는 회전 주기 면의 대응을 미리보고 노드 하나의 대응을 제거 | 변환 후 좌표와 DOF 관계가 실제 경계식에 대응. 일치하는 노드 수만 보고 통과하지 않음. 빠진/중복 대응과 잘못된 축을 표시하고 실행 차단 |
| R1 접촉장 | 한 절점이 두 접촉쌍에 속한 결과에서 쌍·시각·압력·간극을 바꾸기 | 3D/표/곡선의 쌍·시각·단위가 동일. native가 쌍을 구분하지 못하면 그 제한 표시. 미발생·미출력·읽기 미지원 구별. 마지막 선택 재열기 |
| R2 합력·전달 | 같은 쌍을 중복 선택하고 실패 전 마지막 증분까지 힘/모멘트 곡선을 Numerical로 보내기 | 합력이 두 배로 증가하지 않음. 모멘트 기준점과 단위 보존. 실패 이후 값은 빈 구간이며 0으로 채우지 않음. 전달 취소 시 수신 문서 불변 |
| NS1 재료 비선형 | 사용자 solid의 J2 곡선 편집→STATIC/NLGEOM 실행→소성 결과→조건 수정 후 새 실행 | 실제 모델/곡선/단위와 S·E·PEEQ 등 지원 출력 대응. 단일 solid 무접촉과 기존 접촉 조합의 지원 범위를 각각 판정. 수렴 실패의 원입력/부분 결과 보존. 아래 첫 재료 변환 추가 조건도 충족 |
| NS2 동적 계산 | 초기속도·밀도·감쇠를 지정하고 시간별 결과를 읽은 뒤 재개 요청 | 변위/속도/가속도의 실제 시각과 단위 대응. 진짜 restart와 새 초기조건 계산을 구별. 지원하지 않는 restart를 자동 새 계산으로 바꾸지 않음. 실패 전 마지막 시각 재열기 |
| N3 단계 전달 | 정적 선행하중 뒤 동적 단계, 하중 유지/해제를 각각 설정 | 단계 경계의 변위·재료/접촉 상태가 지원 native 방식으로 이어짐. 단계 시각과 전체 시각/하중계수 구별. 미지원 순서는 차단하고 초안 보존 |
| S2 Code_Aster | 같은 사용자 mesh/집합/재료를 Aster 경로로 실행하고 실패 설정 재열기 | 사용자 집합과 native 입력·출력 위치가 대응. 지원 차이는 실행 전에 표시. 미설치 환경에서도 편집/저장/기존 결과 읽기 가능. CalculiX 성공을 Aster 성공으로 대신하지 않음 |

### 배정 시 빠뜨리면 안 되는 비교 위치

- M2는 공개 모델의 A/B 전체 경로와 추적점의 부품 내 좌표를 고정한다. 세계좌표
  기대값은 상위 조립부터 선택 부품까지의 배치 변환을 순서대로 적용해 비교한다.
  참조 재지정 취소는 이전 선택을 유지하고, 적용 후 재열기도 같은 인스턴스를 가리켜야 한다.
- E1은 실제 요소명·native 카드·offset 기준면과 상/하면 채널을 먼저 확정한다.
  `1e`처럼 미완성인 두께도 초안 저장·재열기가 가능해야 하며 실행만 차단한다.
- NS1은 비교할 원출력의 절점/요소, 단계/증분, 채널과 단위를 지정한다. 실패한 R0의
  조건을 고쳐 새 R1을 실행해도 R0의 원조건·마지막 수렴값·실패 상태가 유지돼야 한다.
- Q2는 기존 품질 검사기의 지표명·정의·검사 범위·기준 출처와 불량 요소를 지정한다.
  재메시 성공과 품질 개선을 별도로 판정한다. 악화됐다면 그대로 표시하며, 실패/취소는
  이전 메시를 보존하고 CAD 변경 후의 옛 메시를 유효하게 표시하지 않는다.

### NS1 첫 재료 변환의 추가 조건

첫 대상은 CalculiX 2.22다. Astra가 실제 소스의 읽기 제한을 확인해 아래를 추가했다.
후속 구현의 수정 결과를 확인하기 전에는 이 조건을 통과한 것으로 표시하지 않는다.

1. 소성변형률 `1.234567891234567e-5`를 저장·내보냈을 때 native의 20자 숫자
   읽기에서도 지수가 잘리지 않아야 한다. 출력 정밀도와 반올림 정책을 명시하고
   그 정책에 맞는 왕복 비교를 검사한다. 원래 입력 곡선은 그대로 저장한다.
2. native가 200점을 넘으면 재보간하므로 첫 지원은 **실행 곡선 200점 이하**로 한다.
   200점은 지원하고 201점 초안은 저장·재열기하되 이유와 함께 실행을 막는다.
   자동으로 점을 삭제하거나 재보간하지 않는다. 향후 명시적인 단순화 기능은 별도 작업이다.

근거는 CalculiX 2.22 소스의 `plastics.f` 숫자 읽기와 `plcopy.f` 곡선 재보간이다.
이는 앱의 입력 손실 방지 조건이며 재료 모델의 공학적 검증 완료가 아니다.

## Q1 발견 결함의 직접 확인 사례

| 사용자가 하는 일 | 작업을 닫기 위해 확인할 결과 |
|---|---|
| 등록한 Sketcher 치수의 순서를 바꾸고 목록 열기 | 같은 이름의 살아 있는 치수를 유지하며 다른 치수로 바뀌지 않음 |
| 등록 치수 하나를 삭제하거나 이름을 바꾸고 목록 열기 | 해당 행에서 연결 끊김을 표시. 정상 행은 계속 조회·편집 가능하며 자동 재지정하지 않음 |
| 끊어진 행에서 새 치수를 선택한 뒤 취소 | 기존 등록·범위·모드와 문서 내용 불변 |
| 현재 형상에서 변경 효과를 확인하고 새 치수에 적용 | 변수 ID·이름·범위·모드를 유지하고 선택한 치수를 실제로 수정할 수 있음. Undo는 이전 등록으로 복원 |
| 오래된 확인 결과, 이미 등록된 치수, 종속/읽기 전용 치수 또는 맞지 않는 단위·범위를 선택 | 적용을 거절하고 원인을 표시. 실패가 등록 일부만 바꾸지 않음 |
| 중복 이름·키·실제 대상이 있는 목록 열기 | 모호한 행 모두에 문제 표시. 첫 행을 임의로 정상 처리하지 않으며 관계없는 행은 유지 |
| 복구 후 저장하고 새 문서 소유자로 열어 치수 재편집 | 복구한 대상과 범위·모드가 유지되고 실제 형상에 변경이 반영됨 |
| 필수 등록 참조가 끊어진 채 그 변수를 사용하는 후보 생성 요청 | 기존 엄격한 검사가 실행을 거절. 편집·저장 가능한 초안을 실행 가능한 모델로 오인하지 않음 |

## 개별 인도와 최종 통합

개별 배정은 plan.md의 해당 ID와 여기 AC 안의 해당 사례만 확인한다. M1 하나를
인도할 때 무관한 다른 묶음 전체를 실행하지 않는다. 변경한 동작의 정상경로와 데이터 손실/잘못된
결과 위험이 있는 실패경로를 작은 단위·Qt 검사로 확인한다. native 연결을 새로
지원한다고 할 때는 관련 작은 공개 모델의 실제 입력/실행/저장 경로를 한 번 확인한다.
이미 남아 있는 같은 소스의 실행 근거를 재사용하며 변경 없는 캠페인은 반복하지 않는다.

최종 D2 통합은 CAD변수→조립자세→표현/조건→메시→접촉/비선형→Runner→Post→
후보 비교→별도 편집 설계 채택을 해당 지원 조합으로 연결한다. 모든 AC를 원 요구와
대조하고 미지원/미확인 범위는 잔여로 남긴다. 외부 무료 solver가 없는 PC에서도 독립
편집·저장·보존 결과 읽기는 가능해야 한다. 폭넓은 수치/실험 검증은 이 기능 구현 이후다.
