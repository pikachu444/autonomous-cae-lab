# 무엇이 되어야 작업을 닫는가

각 AC는 spec.md의 같은 번호와 대응한다. Given/When/Then은 테스트 파일 개수나
버튼 존재가 아니라 사용자가 얻는 결과다. 신규 물리 정확성은 기존 reference 허용치를
유지하여 별도로 확인한다. CI 성공만으로 공학적 승인이라고 하지 않는다.

| AC | Given: 시작 자료 | When: 사용자가 하는 일 | Then: 반드시 남아야 하는 결과·실패 복구 |
|---|---|---|---|
| AC-01 | fixture 외 native CAD 두 모델과 등록 치수 | 치수 변경·구속 순서 변경·대상 삭제 후 다시 지정, 저장 후 새 창 열기 | 동일 의미의 살아있는 대상은 유지, 삭제/모호한 대상은 자동 추정 안 함. 복구 취소는 기존 등록 유지, 적용 후 실제 치수 재편집 가능. imported BRep에 없는 스케치를 만들어 표시하지 않음 |
| AC-02 | 유효 치수·표현식 종속 치수·오류값·관측에 무반응인 속성 | 입력·명시 효과 확인·Undo·초안 저장 | 오류/종속/이번 관측의 무반응을 따로 표시. 잘못된 CAD의 실행은 막고 수정 가능한 초안은 재열림 |
| AC-03 | M1 두 구동, M2 두 깊이+반복 Link, M3 닫힌4절기구, M4 후보 모델 | 관절/경로점 편집→계산→미리보기→선택→저장/재열기 또는 후보 준비 | 각 plan행의 대상/단위/오류 조건 충족. 원 조립과 후보 분리, 복원 실패 차단, 원경로 재계산 없는 읽기. native 거절을 숨기거나 동작없는 폼으로 완료 처리하지 않음 |
| AC-04 | 설계 P0, 미리보기 P1, 이후 명시 채택한 P2 | 일시정지·정지·저장·FEM전환·늦은 옛 복원 | 일시정지만 P1 유지, 일반 저장/FEM은 확인된 설계 자세. P2 채택 뒤 옛 P0 복원이 P2를 덮지 않음. 복원 실패 시 해당 전환 차단·현재내용 유지 |
| AC-05 | 두 body와 면/점/모서리의 서로 다른 조건 | 선택·Add/Remove·방향/단위 편집·취소/적용·입력 생성 | 표/native강조/deck set이 같은 대상. 총힘/압력·국부/전역방향 구분. 누락/중복 조건이 자동 삭제되지 않고 재열어 수정 가능 |
| AC-06 | E1–E6 각 해석 표현과 유효/잘못된 속성 | 모델에 할당→미리보기→저장/재열기→선택 solver 입력 준비 | 각 plan행의 속성/방향/DOF/단위가 실제 입력에 보존. 잘못된 두께/단면/층/축/초기값은 해당 행을 표시. 서로 다른 표현을 solid/고정조건으로 몰래 바꾸지 않음 |
| AC-07 | 불량 요소를 포함한 이전 메시와 품질지표 정의 | 요소 행 선택·강조/격리/확대→국부크기→재생성→비교→저장 | 선택한 실제 요소 위치가 일치. 이전/새 품질은 같은 정의와 검사 범위로 비교. 개선이 안 되면 그대로 표시. 실패 생성은 이전 메시 유지, 변경 CAD에 옛 메시 자동 적용 없음 |

| AC-09 | C1–C6의 실제 지원 모델 및 누락/모호한 대상, C3의 비순환 A→B→C와 순환 조정 사례 | 면/법칙/단계/변환·조정순서를 편집·적용→입력준비→저장/재열기 | 각 plan행의 법칙·영역·단계·경계식과 연쇄조정의 실제 초기좌표가 입력에 대응. 지원 대상으로 명시한 solver/version/element/law 조합이 미지원이면 배정은 미완료. 범위 밖 조합은 원요구와 잔여 ID로 추적. 미지원 순환조정은 명시 거절, 법칙 바꾸기/취소는 이전 초안 보존 |
| AC-10 | 접촉쌍 둘, 여러 시각, 정상/부분실패 결과 | 쌍/시각/압력·간극·slip·상태·힘 선택→측정→Numerical 전달→저장 | 원 native 값·위치·단위·부호/정의와 같은 결과. 미출력/읽기미지원/미발생 구별. force집계 중복 없음. 실패 전 값과 선택은 solver 없이 재열기 |

## 개별 인도와 최종 통합

개별 배정은 plan.md의 해당 ID와 여기 AC 안의 해당 사례만 확인한다. M1 하나를
인도할 때 무관한 다른 묶음 전체를 실행하지 않는다. 변경한 동작의 정상경로와 데이터 손실/잘못된
결과 위험이 있는 실패경로를 작은 단위·Qt 검사로 확인한다. native 연결을 새로
지원한다고 할 때는 관련 작은 공개 모델의 실제 입력/실행/저장 경로를 한 번 확인한다.
이미 남아 있는 같은 소스의 실행 근거를 재사용하며 변경 없는 캠페인은 반복하지 않는다.

최종 D2 통합은 CAD변수→조립자세→표현/조건→메시→접촉/비선형→Runner→Post→
후보 비교→별도 편집 설계 채택을 해당 지원 조합으로 연결한다. 모든 AC를 원 요구와
대조하고 미지원/미확인 범위는 잔여로 남긴다. 외부 무료 solver가 없는 PC에서도 독립
편집·저장·보존 결과 읽기는 가능해야 한다. 폭넓은 수치/실험 검증은 이 기능 구현 이후다.
